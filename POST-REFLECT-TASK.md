## Harden /sc:reflect Wave-3 reviewer spawning against repository mutation (six defense layers + falsifier suite)

## Task Overview

`/sc:reflect` fans out Wave-3 heterogeneous reviewer subagents to audit completed work. Today those reviewers are spawned with all-tools personas (`analyzer`/`qa`/`refactorer`/`architect`, backed by agent files `quality-engineer.md` / `root-cause-analyst.md` / `refactoring-expert.md` that carry NO `tools:` line and therefore inherit Bash/Edit/Write/Task/NotebookEdit). A reflect reviewer can thus MUTATE the very repository it is auditing — the incident vector. The reflect Tier-1 audit child and the adversarial Mode-A scorer are ALSO launched via `ClaudeProcess` with `--dangerously-skip-permissions --tools default`, compounding the exposure.

This task adds six defense-in-depth layers and a falsifier-disciplined test suite:

- **L1** — a NEW restricted read-only agent `src/superclaude/agents/reflect-reviewer.md` whose `tools:` allowlist excludes every mutator (Bash/Edit/Write/NotebookEdit/Task and all serena/memory mutators).
- **L1b** — a ClaudeProcess restricted profile that drops `--tools default` + `--dangerously-skip-permissions` for the reflect REVIEW children (Tier-1 audit at `runner.py:430`, adversarial scorer at `ensemble.py:340`), while the remediation executor (`runner.py:465`) retains write tools. The precedence reconciliation with the existing `tool_write_mode` flag is a `needs_human_decision` HALT.
- **L2** — a reviewer-isolation snapshot gate: probe `audit_tree_dirty`, STOP on a non-committable target (`stopped-precondition`), else create a `git worktree` snapshot and ground every reviewer in it (never the live shared worktree); emit `reviewer_isolation` / `audit_tree_dirty` / `reviewer_grounding_root` telemetry; teardown in a `finally`.
- **L3** — extend the §6.1.1 `execute_shell_command` no-mutation denylist (defense-in-depth) with the read-but-forbidden git verbs (reset/stash/checkout/clean/rebase/merge/worktree/restore) and strengthen the sole-shell invariant.
- **L4** — an advisory `## Constraints (READ-ONLY)` preamble in the reviewer brief spec + a Step 3B.0 prohibition on embedding live-exec instructions in briefs; repoint the reviewer rotation to the fixed `reflect-reviewer` agent-type in BOTH SKILL.md §7/§7.1 AND reviewer-spec.md `## Composition`.
