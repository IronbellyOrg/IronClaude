# How We Work

Which IronClaude command or skill to use for each kind of work, in what order, and with which safe flags, is written down in one place: the IronClaude guide [`HOW-WE-WORK.md`](../../src/superclaude/core/HOW-WE-WORK.md). It sorts every job into six levels, from "ask a question" to "write a full specification", sets the hard limit on how much change may skip a written plan, gives step-by-step workflows for building, fixing, investigating, reviewing, and resuming work, and ends with the routing table that `/sc:recommend` reads. `/sc:help` prints only its level table. `superclaude install` copies the guide to `~/.claude/HOW-WE-WORK.md`, so you can open it from any project; run `superclaude update` after upgrading to refresh that copy. `superclaude update` overwrites every file it ships, including an edited `~/.claude/CLAUDE.md`, and keeps no backup. It also deletes and re-copies each shipped skill folder in `~/.claude/skills/`, so any file you added inside one is lost. Copy any file you changed or added before you run it. If you are still unsure which tool fits your job, run `/sc:recommend "<what you want to do, and why>"`.
