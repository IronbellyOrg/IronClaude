# Skill migration: source-first sync workflow (MIG-001)

> **Status:** Phase 8 reference doc for the MultiModelSwarm `sc-bare-review`
> thin-caller migration (T08.04 / R-138 / MIG-001 / D-0119). Applies to
> every contributor editing the migrating skill while the legacy shell
> dispatch path is still in tree.

## Scope

This doc is the migration-specific binding of the project-wide
source-of-truth rule recorded in
[`CLAUDE.md` § Component Sync](../../CLAUDE.md#-component-sync) and
elaborated in [`docs/dev/sync-discipline.md`](./sync-discipline.md). The
`sc-bare-review` skill is being rewritten as a ~60-line thin caller over
`superclaude swarm run --lens bare-review` (T08.01); during the migration
window the canonical source stays at
`src/superclaude/skills/sc-bare-review/` and the
`.claude/skills/sc-bare-review/` mirror is regenerated by `make sync-dev`.
**Never edit the mirror directly.**

The rule it inherits is unchanged:

**Edit `src/superclaude/`, then run `make sync-dev`. Never edit `.claude/`
directly.**

This doc records the migration-specific surface — which paths matter,
where MIG-003 will delete shells, and the focused pre-commit assertion
that pins parity for the migrating skill — without restating the broader
contributor flow already documented in
[`docs/dev/sync-discipline.md`](./sync-discipline.md).

## What lives where (migration paths)

| Path | Role |
|------|------|
| `src/superclaude/skills/sc-bare-review/SKILL.md` | Source — thin caller body. Edit here. |
| `src/superclaude/skills/sc-bare-review/refs/` | Reference markdown and templates. Edit here. |
| `src/superclaude/skills/sc-bare-review/scripts/*.sh` | Legacy shell dispatch — source-of-truth here until MIG-003 (T08.07) deletes them post-parity (T08.11). |
| `.claude/skills/sc-bare-review/` | Generated mirror. **Do not edit. Do not stage.** |

Everything under `.claude/skills/sc-bare-review/` is gitignored output of
`make sync-dev`. The project-wide
`block-claude-generated-mirrors` pre-commit hook
([`scripts/precommit_block_claude_mirrors.sh`](../../scripts/precommit_block_claude_mirrors.sh))
rejects any commit that stages a path under `.claude/skills/…`. The
allowed exception (`.claude/settings.json`) is unrelated to this skill.

## Migration sync steps

1. **Edit the source.** Open a file under
   `src/superclaude/skills/sc-bare-review/…` and make the change.
2. **Run `make sync-dev`.** Regenerates the mirror at
   `.claude/skills/sc-bare-review/` so Claude Code picks the change up in
   the running session.
3. **Run `make verify-sync`.** Must exit 0 before staging. Drift means
   either a direct mirror edit or a missed step 2 — fix the source side
   and re-run `make sync-dev`.
4. **Stage only `src/`.** The `.gitignore` rules,
   `block-claude-generated-mirrors`, and the
   migration-specific `verify-bare-review-mirror-matches-src` hook (§
   below) all reject staged mirror paths. The staging is the bug, not
   the rejection — never `git add -f` a path under `.claude/skills/…`.

If you accidentally edited `.claude/skills/sc-bare-review/` first
(Claude Code reads from `.claude/`, so this happens during an iteration
loop), recover by copying the edited files back to
`src/superclaude/skills/sc-bare-review/`, re-running `make sync-dev`,
and re-verifying. See
[`docs/dev/sync-discipline.md` § "If you accidentally edited `.claude/` first"](./sync-discipline.md#if-you-accidentally-edited-claude-first)
for the full recovery flow.

## Migration-specific pre-commit gate

In addition to the project-wide
`block-claude-generated-mirrors` hook (which blocks staged mirror paths),
the bare-review migration installs a focused mirror-parity assertion:

- **Hook id:** `verify-bare-review-mirror-matches-src`
- **Script:**
  [`scripts/precommit_verify_bare_review_sync.sh`](../../scripts/precommit_verify_bare_review_sync.sh)
- **Trigger:** any commit staging a path under
  `src/superclaude/skills/sc-bare-review/`.
- **Behavior:** diffs `src/superclaude/skills/sc-bare-review/` against
  `.claude/skills/sc-bare-review/` (excluding `__pycache__/`, `*.pyc`,
  `__init__.py`) and exits non-zero on drift, prompting the contributor
  to run `make sync-dev`. The diagnostic message names both directories
  so the redirect is unambiguous.

This hook narrows the project-wide
`make verify-sync` check into a fast local pre-commit assertion on the
migration surface only — it does not replace the CI run of
`make verify-sync`, which remains the authoritative gate against every
component. Local contributors who need to commit WIP can still bypass
with `git commit --no-verify`; the PR's CI run will catch the drift.

## MIG-003 shell retirement (T08.07)

When T08.11's A/B parity gate is green, MIG-003 deletes
`src/superclaude/skills/sc-bare-review/scripts/*.sh`. The deletion is
source-first like every other edit:

1. Delete the source files under
   `src/superclaude/skills/sc-bare-review/scripts/`.
2. Run `make sync-dev` so the mirror's `scripts/` directory empties.
3. Run `make verify-sync` — it must be clean.
4. Stage only the `src/` deletions; never `git rm` a mirror path.

The migration pre-commit hook above stays valid through the deletion —
once the source side has no shell files, the mirror side must not
either, and the diff assertion enforces that.
