# SuperClaude dependency allow-list (AC3 / R-015 / T01.17)
#
# This file enumerates every top-level Python package that may appear in
# `uv pip list` after installing `superclaude[dev]`. The list is the union of:
#
#   1. The baseline snapshot taken before the eval CLI lands its runtime deps
#      (pre-eval-CLI tree, captured 2026-05-20).
#   2. The AC3 allow-list of additions permitted while the eval CLI lands:
#        - pexpect    (transitive via vendored ptytest)
#        - jsonschema (already a transitive dep; promoted to direct in pyproject)
#
# Comparison is name-only — versions are not pinned here. Lines starting with
# `#` and blank lines are ignored. Package names are case-insensitive and
# normalised via PEP 503 (underscores → hyphens, lower-cased).
#
# To regenerate after a deliberate dep addition that has been approved:
#   uv pip install -e ".[dev]"
#   uv pip list --format=json \
#     | python -c "import json,sys; \
#         names=sorted({p['name'].lower().replace('_','-') for p in json.load(sys.stdin)}); \
#         print('\n'.join(names))" \
#     | tee /tmp/new_baseline.txt
# Then merge changes into this file and update the spec at
# .dev/releases/current/cliEval/artifacts/D-0015/spec.md.
#
# Removals do not fail the check (a dev tool can be dropped without ceremony).
# Additions outside this list MUST fail CI.
