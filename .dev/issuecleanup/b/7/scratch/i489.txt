## Why this follow-up exists

The #346 review-loop experiments (branch `346Claude-ab-experiment-artifacts`) built a multi-model reviewer panel and a spec for a re-useable eval framework (#487). Both name the ccsession gateway tiers directly. #488 reorganises those tiers: today's Tier 3 becomes **Tier 2b**, a new **Tier 3** holds GLM 5.3, Grok 4.7 and Qwen 3.8, and Tier 4 adds Claude Haiku 5.5. When the experiment work is implemented and merged, everything we push that names a tier must be updated to the new layout. This issue tracks that update so it is not forgotten.

**Do this after both of these have landed:** (1) the experiment/framework work from #346 and #487 is merged, and (2) #488 is deployed (the Coder `defaults.sh` change must be live before the IronClaude JSON, per the merge order in #488).
