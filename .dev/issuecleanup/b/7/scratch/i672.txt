## Bug Summary

Delegated agents sometimes refuse required saved report handoffs because they report a conflicting instruction, interrupting feature work. The source and authority of that instruction are not established.

## Environment (OS, version)

- OS: Not known yet
- Version: Not known yet

## Current Behavior

Multiple delegated agents across different personas reported an instruction prohibiting report files, and several stopped before investigation because their assigned handoff required one. Other agents successfully wrote reports. One agent interpreted `.txt` as permitted; others treated it as forbidden circumvention. The coordinator repeatedly redispatched incompatible work and repeated the alleged rule, compounding the interruption. After the user approved a reply-only review, the feature was eventually completed.

A prior limited search of local configuration and project files found no matching phrase; that is not proof of absence elsewhere. Complete startup input for the affected agents has not been inspected. A hidden or injected instruction, conflicting instructions, an unsupported agent assertion, and propagation through later prompts are possibilities, not established causes.

## Expected Behavior

Workers should receive compatible, auditable instructions and complete the required saved handoff when authorized. If a real conflict exists, the coordinator should identify its provenance and handle it according to the applicable policy instead of repeatedly assigning incompatible work. Reply-only handling must respect the applicable policy and any required user approval.

## Steps to Reproduce

1. Assign delegated agents an investigation that requires a saved report handoff.
2. Observe whether an agent reports a conflicting report-writing prohibition or successfully writes the handoff; the precise conditions and a reliable reproduction are not known yet.
3. If a refusal occurs, compare the earliest refusal with later redispatches and a successful worker, preserving sanitized evidence of their effective startup instructions.
