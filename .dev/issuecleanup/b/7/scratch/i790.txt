    - S04-F22: The worker's first prompt is built from one template with fixed, ordered sections (identity of the issue and worktree, goal, the Orca task fields, rules, chain, reporting and stop condition), and a test pins the order.

    - S04-F26: The handoff template tells the worker never to print or commit secrets, tokens or credentials.
    - S04-F28: The text that opens the pull request uses `Fixes` only for a pull request that fully addresses its issue and `Refs` otherwise, so a partial pull request cannot close the issue at merge.
    - S02-F27: The handoff prompt names the repo's regression gate command and the worker must run it and report its result in `worker_done`.
    - S07-F25: Put the `Fixes`/`Refs` rule into the worker brief template and state in the skill that no script checks it.
