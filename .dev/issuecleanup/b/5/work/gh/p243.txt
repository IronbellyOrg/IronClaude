<summary><b>🤖 Augment PR Summary</b></summary>

<br>

<b>Summary:</b> This PR distinguishes a fully silent Augment review from a review that has begun but has not completed.
<br>
<b>Changes:</b>
<ul>
<li>Adds Augment-attributed activity and successful-poll detection to the review classifier.</li>
<li>Introduces <code>--silence-timeout</code>, defaulting to 300 seconds and clamped to the main timeout.</li>
<li>Adds a silence re-request state and an L3-only, write-ahead, strict-once <code>augment review</code> poke.</li>
<li>Adds <code>TERMINAL_AUGMENT_NO_RESPONSE</code> plus matching run-log event and idempotency state.</li>
<li>Extends the poll script so failed comment fetches cannot be mistaken for observed silence.</li>
<li>Allows Wave 8 CI waiting after the new terminal, while explicitly disabling CI auto-fix there.</li>
<li>Updates command/skill/reference documentation and retrigger script body handling.</li>
<li>Adds fixtures and tests for silence, partial activity, polling failures, idempotency, and CI arm behavior.</li>
</ul>
<b>Technical notes:</b>
<ul>
<li>Partial Augment activity continues to use the existing timeout terminal.</li>
<li>The new status is preserved when CI completes, so CI success is not reported as an Augment-clean review.</li>
</ul>
