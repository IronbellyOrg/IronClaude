1. **High: planned raw paths are published as if backed by retained output.** `src/superclaude/cli/swarm/commands.py:1063-1080` unconditionally assigns `.raw.md` alongside final/meta paths, without writing raw bytes or taking a retention argument. Its production call is `commands.py:2099-2104`, followed by normalization at `2116-2120`. `normalize.py:278-305` prefers the transport's in-memory body, so successful normalization does not prove a raw file exists. The normalizer writes final output and metadata (`normalize.py:455-471`); metadata contains recipe, status, byte count and salvage reason, not a copy of raw output (`normalize.py:344-358`). The reducer passes these worker records into the output contract (`reduce.py:677-702`). Searches for `raw_path`, `retain_raw`, `.raw.md` and write operations across the package found no raw-file writer in the inspected lifecycle. This is static evidence of the current advertised-path gap, not a new runtime reproduction.
2. **Medium: fresh and resumed artifact discovery have different truth rules.** `commands.py:2273-2308` searches only top-level canonical metadata names and recovers the raw path only when the sibling exists. Thus empty raw-path fields after resume are consistent with missing retained files and do not establish deletion. Redispatched results are reindexed and passed to normalization without fresh path preparation (`commands.py:2594-2610`). Address both phases and saved naming policy in the existing fix, not just the reducer's output text.
3. **Medium: retention documentation is internally inconsistent.** The CLI reference promises per-worker raw files (`src/superclaude/skills/sc-swarm-wizard-protocol/refs/cli-contract.md:91-95`), while `models.py:408-417` describes raw retention on the metadata sidecar and defaults it to true. The inspected sidecar emitter does not store the raw body. The test guide already identifies the advertised-but-unwritten raw path (`docs/testing/v5.0.0/user/D14-swarm.md:32`). No `tests/swarm/*raw*` file exists in this checkout; this filename search does not prove other tests have no related assertions.
