(T04.04) implements `Expect.settings_json(path, key_path, equals,
exists)` resolving paths against `HomeIsolation.home_path` rather than
the real `~/.claude/`, navigating dot-separated `key_path`s with

honouring `exists` and `equals` (including null-vs-unset distinction and
list / dict value equality), and surfacing invalid JSON payload errors;
20 tests in `tests/cli/eval/test_expect_settings_json.py` cover the
matrix. COMP-010.4 (T04.05) implements `Expect.exit_code(equals,
in_set, not_equals)` with default `equals=0`, a `_SENTINEL`-based mutual
exclusion guard (explicit `equals` + `in_set` raises `ValueError` at
construction while the default `equals=0` does not collide with
`in_set`), list / tuple / empty-iterable handling for `in_set`, and
combinable `not_equals`; 20 tests in
`tests/cli/eval/test_expect_exit_code.py` cover the matrix including
the declarative `from_mapping` thread-through for both `in_set` and
`not_equals`.
