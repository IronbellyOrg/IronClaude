## Clean-host contract

`superclaude eval run --suite real --eval E1` MUST succeed end-to-end on
a clean Linux dev machine whose only setup is `make dev`. Specifically:

* No environment variables beyond a default UV/Python install.
* No binaries beyond the `required_binaries` declared in
  `suites/real.yaml` (currently `claude`, `make`, `jq`, `git`).
* No manual file edits, no hand-rolled HOMEs, no pre-warmed caches.

The smoke test invokes the literal AC command via `subprocess.run` so
the entry point exercised matches what an operator types at the shell.

## Invocation

```
uv run superclaude eval run --suite real --eval E1 --output-dir <tmp>
```

`--output-dir` is supplied so the test can locate the per-run directory
without parsing autogenerated run-ids from stdout. The path points at
`/tmp/eval-runs/<unique>/`, which the AC12 scratch-root allowlist
admits. The same `summary.{md,json}` artifacts MUST appear regardless
of whether `--output-dir` is supplied — pinning the path here is purely
hermeticity for the test, not a contract on the invocation itself.

## Asserted outputs

After the subprocess exits 0, the test asserts:

| Path | Check |
|------|-------|
| `<output-dir>/summary.md` | exists, non-empty |
| `<output-dir>/summary.json` | exists, non-empty, parses as a JSON object |

Schema fidelity for `summary.json` is owned by TEST-007 (T04.17). FR-G6
only verifies that the harness produces the canonical summary pair at
the process boundary.
