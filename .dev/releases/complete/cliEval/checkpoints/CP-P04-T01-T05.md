`src/superclaude/cli/eval/expect.py` — 7 primitive static methods

mapping form (`{exit_code: {equals: 0}}`) and the programmatic form
(`Expect.exit_code(equals=0)`) produce equivalent results via the
shared `_invoke_primitive` dispatch.

COMP-010.1 `Expect.file` (T04.02) implements the 5 named arguments
`path,exists,contains,regex,equals`; failure ExpectResults carry a
unified `difflib` diff in `ExpectFailure.actual` for the `equals`
mismatch path. COMP-010.2 `Expect.jsonl` (T04.03) iterates JSONL rows
with `path,line_count,filter,assert_each,assert_any`; the filter
narrows rows before line counting, `assert_any` succeeds when at least
one filtered row matches, and invalid JSON fails with the offending
line number. COMP-010.3 `Expect.settings_json` (T04.04) resolves
relative paths against `HomeIsolation.home_path` (never the real
`~/.claude/`), navigates dot-separated `key_path` over nested dicts,
and supports `equals` + `exists` short-circuiting on missing
intermediates. COMP-010.4 `Expect.exit_code` (T04.05) defaults to
`equals=0`, supports `in_set` and `not_equals`, and raises `ValueError`
when both `equals` and `in_set` are explicitly passed.
