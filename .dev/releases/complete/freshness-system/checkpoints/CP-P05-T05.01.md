## Addendum — 2026-05-13: FileChanged removed post-probe

**Trigger:** T02.05 probe execution. See `TASKLIST_ROOT/artifacts/D-0008/probe-finding.md` for the full write-up.

**Summary:** The probe captured zero events because Claude Code's `FileChanged` matcher accepts only `|`-separated literal filenames (not regex / not "watch all"). Our design's `matcher: ".*"` was silently watching a file literally named `.*`. The `FileChanged` event has been removed from `src/superclaude/hooks/hooks.json` and from the live `~/.claude/settings.json`.
