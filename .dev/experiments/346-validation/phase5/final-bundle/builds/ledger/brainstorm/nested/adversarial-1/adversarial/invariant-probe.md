## Recommended resolution per UNADDRESSED item

- **INV-001:** Add `init --archive-existing`, which renames the old ledger folder to `<stem>.review-ledger.aborted-<UTC timestamp>/` and records the rename in the new header; the experiment protocol requires it (never a manual delete) before any rerun.
- **INV-002:** The sweep runs on a copy of the accepted snapshot placed in a fresh temporary directory with no ledger, and the sweep prompt names only that copy; V1-ledger additionally fails a sweep report that cites any ledger row id.
- **INV-003:** The sweep reads the accepted snapshot only (copied as in INV-002); `sweep` records live `D` versus snapshot hash, and a mismatch is reported as post-terminal edits, not as an integrity ESCALATE of the loop.
- **INV-004:** Add a `terminal` phase: after any terminal loop decision, `begin`, `answer`, `find` and `verify` refuse with `E-TERMINAL` and a JSON body naming the decision and "do nothing further"; `status` reports post-terminal edits by hash.
- **INV-005:** Define idempotency by request digest within the same phase and round, independent of op id: a new op id carrying a payload already committed returns the original result with `replayed: true`, and only a different payload under a stale `--expect-seq` is refused.
- **INV-006:** Either disclose a one-sentence reviser-brief change ("run the Reviser brief's `answer` command before `worker_done`") as a treatment deviation, or have `begin` auto-claim, with `claimed_by=script-location`, any hunk overlapping exactly one blocking row's mapped span when no answers exist, refusing only the rest; report the auto-claim count as a compliance metric.
- **INV-007:** Pick one rule: the verify session may run `revert-unclaimed` only on hunks overlapping no blocking row and only after the preimage check, and every revert is logged with bytes discarded; if the preimage check fails, `begin` commits a `cannot-verify` round result instead of stalling.
- **INV-008:** Limit a claim span to the row's mapped span plus a fixed margin (for example the enclosing paragraph or 10 lines), refuse wider claims with `E-CLAIM-WIDE`, and make `caused_by` a list so a hunk claimed by two rows attributes a child row to both.
- **INV-009:** `answer fixed` must name at least one hunk that changes or deletes text inside the row's mapped span, else `E-NO-CHANGE`; a reviser who changed nothing must answer `not-fixed` or `disputed`.
- **INV-010:** Let the reviser record gaps as structured `gap` entries in its `answer` input; the next verify plan lists them, and the verifier may file each as a new row with `origin=reviser-gap` anchored on unchanged text, counted separately in M3 and the headline.
- **INV-011:** `sweep` (or, when the sweep is skipped, the last `close`) re-checks the tail of every prior report against the recorded verdicts, and the V1-ledger analyst step runs `status` once after the last dispatch and records the result.
- **INV-013:** Publish the deferred CRITICAL or MAJOR floor as its own number, pre-register whether the bar is applied with or without it, and compute the control's comparable number (control MAJOR findings with no concrete wrong outcome) so both arms are measured on the same population.
- **INV-014:** Fix the convention in the spec: all spans and hunk ranges are half-open `[start, end)` lines on a named snapshot; a zero-width deletion at position p overlaps `[s, e)` when `s <= p <= e`; spans are relocated into the old-side snapshot of a diff before any overlap test; add a fixture for each edge.
- **INV-015:** The script only proposes `dup_of` candidates; a blinded analyst rules duplicate, child or challenge; the headline uses the adjudicated count and publishes raw and auto-matched counts as bounds.
- **INV-017:** State that `find` accepts an empty rows array and that the report tail then prints the zero table and `verdict: PASS`, and add a fixture for it.
- **INV-018:** The fix-cycle counter increments only on a committed `begin` that admitted at least one claimed hunk; a zero-hunk round still counts as a review, its new-defect check is recorded `complete-empty`, and the round result lists "no edits admitted".
- **INV-019:** For admission only, compare paragraphs (runs of non-blank lines joined with single spaces), so a pure rewrap produces no unclaimed hunk; keep raw line hunks for evidence and `HUNKS_LARGE`.
- **INV-021:** Disclose a brief change for the three review briefs: the PASS or FAIL acceptance item and the "any finding of any severity is FAIL" rule are replaced by "the script-written verdict line"; if the briefs must stay unchanged, `close` must instead accept a reviewer verdict line and append the script verdict as the authoritative last line, and the analyst records disagreements.
- **INV-022:** Either replace "look for new defects" in the review-2 and review-3 briefs with the verify scope (disclosed), or have `verify` accept out-of-hunk allegations as `scope=outside` rows that never block the loop but are counted in the headline with the sweep rows, so nothing lives only in prose.
- **INV-023:** Make the blinded `wrong_outcome` audit mandatory and pre-register a cut-off (for example more than 30% of MAJOR-blocking rows judged filler) that marks the replicate "grading not honoured", the same way V1-ledger marks non-compliance.
- **INV-024:** Fix the strings: a loop-terminal report before the sweep ends `loop: PASS (sweep pending)` with no `verdict:` line; only the sweep report, or the review-1 report when the sweep is skipped, ends `verdict: PASS` or `verdict: FAIL`, where ESCALATE maps to FAIL.
- **INV-025:** The round counter and fix-cycle counter advance only on a committed `begin`; a `begin` that finds edits with no answers and no auto-claim (INV-006) refuses with `E-NO-ANSWERS` without consuming the round, so the coordinator can re-dispatch the reviser.
- **INV-026:** The variant command refuses a standalone `--unattended` token with one printed line ("spec-panel-ledger has no unattended mode") before any work, and the drift test asserts that line exists.
- **INV-027:** Pre-register B1, r1 and r2 as measured per replicate, report P3 against B1 x r1 x r2, and state in the spec that the ledger is not claimed to change r; the claim "ledger alone meets the bar" is falsified if measured B1 x r1 x r2 exceeds 3 in either replicate.
- **INV-028:** Run the baseline sweeps on the six existing finals before any ledger replicate; if their mean CRITICAL or MAJOR count is 3 or more, declare in advance that the combined bar cannot be met by the ledger alone and report P3 and the sweep separately as the primary result.
- **INV-029:** Add Arm B as the primary comparison for the ledger's own effect (P3s below 3.5 and growth at most 30.0%), keeping the control comparison only for the combined ledger-plus-427 claim.
- **INV-030:** Report discarded bytes from `revert-unclaimed` and deferred-span bytes beside growth, and treat a growth gain explained mostly by discarded bytes as "not attributable to better fixes".
