# Invariant Probe Results
## Emerging consensus
- Base is disputed: A argues for itself (debate-r2-A §5); B and C both name B, in its R2 report-resident form (debate-r2-B §5, debate-r2-C §5). Either way the merged design is the same set of parts: B's storage and coverage, A's lifecycle guards, C's failure semantics.
- Storage: the report file is the only file written. The ledger is a fenced block inside the report, there is a sentinel, `finalize` writes the last line and refuses a hand-typed verdict, and `check` runs at every review including a final PASS. B's `/tmp` scratch was withdrawn in favour of in-report mode (debate-r2-B §3.4). C's 13-file run tree and A's loop dir were dropped (X-001).
- The reviewer's `claimed` severity label stays for reporting only. Every form-valid finding goes to the grader whatever its label (X-006, debate-r2-A §1 B-2).
- Quote+outcome form rule plus one counted repair (exit 3 once), which also covers uncovered changed hunks (X-014, X-015).
- Hunk coverage: every changed hunk needs a claim or a `checked` line. An uncovered hunk after the repair gives FAIL with reason `incomplete`/`unconfirmed-only`, not a confirmed defect.
- Ratchet: changed-line overlap (A), not B's span novelty. B's Q2 stays as advisory data only (debate-r2-B §1 A-5). C's prior-link hash rule is added: identical outcome hash and either identical quote hash or a changed anchor (U-027).
- Carried confirmed blockers are frozen and never re-graded (X-003). A's `verify-prior` and prior-status guard are kept (U-002, U-003).
- Late-found claims go to the grader in the same batch for visibility. They never block (X-004 to C).
- Independent grader: a declared agent with a pinned model. `same-class` is recorded when it applies (X-016 to A). B's canaries ride in the same batch.
- Binary verdict only. FAIL carries a reason code (`confirmed`, `unresolved-prior`, `incomplete`). Unconfirmed items never enter the fix list. An incomplete-only FAIL dispatches no reviser. More than one incomplete review invalidates the replicate (X-002 to B, debate-r2-B §1 C-1).
- Audit: at a PASS candidate, a fresh full-spec auditor checks every demotion, and a reinstatement recomputes FAIL (X-007 to A). Offline, a two-sided sample covers both confirmations and demotions. The seed is `sha256(nonce||review||ledger)`.
- Reviser routing: the script numbers confirmed ids first and contiguously. The coordinator fills T08 `{{R2_FIRST_ID}}-{{R2_LAST_ID}}` and `{{R2_CITATION_COUNT}}` from the script's brief, stated as part of the treatment (debate-r2-A §3.1).
- Metric precedence: the coordinator and the metric read only the script's last line. The brief's "any finding of any severity is FAIL" verdict is recorded as a covariate (debate-r2-A §3.6, debate-r2-B §3.2). C says this does not settle instruction authority (debate-r2-C §3.5).
- FR-8/FR-9 "MAJOR severity minimum" floors are edited in the copy, bullet 2 is replaced, and FR-10 is kept (X-005 to A).
- Install: the `-protocol` skill name, plain install without `--force`, skill and agent published before the command, absence checks, and A's computed-diff drift test (X-008, U-006). A missing skill fails closed with `E-SKILL-MISSING` (X-013).
- Cap 3, never lifted inside a loop. A user-authorized restart is a new run with a parent run id (X-012 to C).
- Measurement: the 472-line Arm B base (X-009), Arm B briefs with `--re-review/--baseline` (`ratchet=off` if missing, X-010), the offline replay gate, and the M1c unmodified probe.
- Predictions: both advocates' replays put a control-style R3 at about 4-5 surviving blockers. The bar is reachable only if the stoprule arm behaves like Arm B. The chance that both replicates come in at or under 3 is about 0.5. Growth is expected to stay under 44.4% (debate-r2-A §3.3, debate-r2-B §3.6).
