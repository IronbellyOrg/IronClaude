# Inserted coordinator step: after each review, and the fix cycle (stoprule arm)

Placeholders: `<spec>`, `<report>`, `<N>`, `<run dir>` as in `coordinator-before-review.md`; `<Bn>` a batch id printed by `grade-prep`; `<k>` the reply attempt (1 or 2); `<disposition file>` the reviser's disposition file (`review/disposition.md` after review 1, `review/disposition-round2.md` after review 2). `<skill base>` is `~/.claude/skills/sc-spec-panel-stoprule-protocol`.

Owner ruling: every call below that writes the report runs here, in the coordinator session, as its own step; the reviewer and the reviser run only calls that write no file.

1. Seal: `uv run --no-project python "<skill base>/scripts/stoprule.py" seal --report <report> --spec <spec>`. On exit 3 run the same command once more: the second seal is final and records still-failing claims as `minor-form`. Exit 5: stop.
2. Grade: run `uv run --no-project python "<skill base>/scripts/stoprule.py" grade-prep --report <report>`. For every printed batch make one Agent call, all calls in one message, with `subagent_type: finding-grader` and the prompt equal to the batch text from its `=== BATCH <Bn> ===` line to its `=== END BATCH <Bn> ===` line, unchanged. Save each reply verbatim as `<run dir>/grader-r<N>-<Bn>-<k>.txt` and apply it: `uv run --no-project python "<skill base>/scripts/stoprule.py" apply-grades --report <report> --batch <Bn> --reply <run dir>/grader-r<N>-<Bn>-<k>.txt`. On exit 3 run `grade-prep` again and re-send only that batch once (k = 2). If the Agent tool is unavailable, apply nothing: those claims stay `unconfirmed` and the verdict is FAIL `incomplete`.
3. PASS-time audit, only when `uv run --no-project python "<skill base>/scripts/stoprule.py" verdict --report <report>` prints reason `incomplete` or `none` with no confirmed claim and no open prior (`audit-prep` refuses otherwise): run `audit-prep --report <report> --spec <spec>`, make one fresh general-purpose Agent call whose prompt is the printed `=== AUDIT ===` block, save the reply as `<run dir>/auditor-r<N>.txt`, and run `apply-audit --report <report> --reply <run dir>/auditor-r<N>.txt` (omit `--reply` if the auditor was unavailable).
4. Finalize: `uv run --no-project python "<skill base>/scripts/stoprule.py" finalize --report <report> --grader-model sonnet --reviewer-model <reviewer model>`.
5. Check: `uv run --no-project python "<skill base>/scripts/stoprule.py" check --report <report> --spec <spec>`. On exit 6 stop: the report is non-compliant and no reviser is dispatched. Record the last line of the report as the review's verdict.
6. Stop the loop when the last line is `verdict: PASS`, or when `<N>` is 3 and the last line is `verdict: FAIL`: then hand the user the report's `## Escalation to the user` section. Never dispatch a fourth review.
7. Before the reviser runs, save the spec this review saw: `cp <spec> <run dir>/baseline-r<N>.md`. It is the `<saved copy>` of the next review.
8. Re-run step 5's `check` on the report (the report must not have changed since step 5). Then fill the reviser template's finding range from the report's Reviser brief: the `Reviser range:` line gives `D1-Dk`, or `NONE` with the brief's sentence "No confirmed blocking findings: make no spec edit". The reviser is pointed only at D1-Dk; the minor notes and the prose findings are not instructions.
9. Dispatch the reviser with its template brief (`T06-R1-reviser-L10-3bb70411.txt` after review 1, `T08-R2-reviser-L10-66468bab.txt` after review 2) and the filled range. A reviser that writes a fix map writes it only inside its own disposition file.
10. After the reviser: `uv run --no-project python "<skill base>/scripts/stoprule.py" check-disposition --report <report> --disposition <disposition file>`. Record every id it lists as applied outside D1..Dk (reported, never blocking). Then run `coordinator-before-review.md` for review `<N>+1`.
