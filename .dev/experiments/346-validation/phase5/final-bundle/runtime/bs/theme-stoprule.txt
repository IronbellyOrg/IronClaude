THEME "stoprule": severity discipline and a mechanical stop rule. Severity labels drift upward between rounds and the verdict is the reviewer's own judgement, so a loop never has to end. Design: a FROZEN severity rubric stated once and copied unchanged into every round's brief; a rule that a finding is blocking only if it quotes the offending text and states a concrete wrong outcome or failing example (no quote and no outcome means minor, mechanically); independent confirmation of every blocking finding by a second grader that sees only the quote and the rubric, not the report (a finding the second grader calls minor is demoted); a ratchet so that a blocking finding in review N+1 must anchor in lines changed in cycle N or cite a prior finding id, otherwise it is demoted to `late-found`; and a verdict COMPUTED from the finding list (any confirmed blocking finding means FAIL, none means PASS) rather than written by the reviewer, plus a defined cap-hit outcome (what is escalated, in what format, and what is explicitly not looped on). Work out: where the computation and the confirmation live (script, second agent call, or both), what it costs per round (extra agent calls), how the second grader is kept independent (fresh context, different model class if available, no access to the report), and how to measure demotion accuracy so the grader cannot silently wipe out real defects (a sampled audit).
