# Invariant Probe Results
## Round 2.5 - Fault-Finder Analysis

Consensus as reconstructed from the Round 2 final tables (round-2-advocate-1..3.md, section 5) and convergence-tally.md:

1. One bash and `jq` script `launch-level-guard.sh`: UserPromptSubmit (bind, approve), UserPromptExpansion (approve; Advocate 2 dissents), PreToolUse with the anchored matcher `^(Bash|Skill|Agent|Task|Edit|Write|NotebookEdit|Monitor|Workflow|RemoteTrigger|Cron[A-Za-z]*|Schedule[A-Za-z]*)$|^mcp__.*merge`.
2. Binding: the claim script writes `~/.claude/state/launch-level/pending/<nonce>` (one word: `worktree`, `full`, `full-submit`); the launch prompt carries `[sc-launch:v1:<32 lowercase hex>]`. The first marker anywhere in an unbound session's prompt with a record is `mv`ed to `sessions/<sid>`; a marker at the very start with no record writes `worktree` under `set -C`; later markers are ignored; no age check; `session_id` must match `[A-Za-z0-9._-]+`.
3. Approval: `touch sessions/<sid>.ok`, only at `worktree`, from a whole-prompt `approved` or a typed `/sc:implement` or `/task` (prompt prefix, or expansion `command_name` after stripping `/` and `sc:`); payloads with `agent_id` ignored; unlocks IMPL only, for the session's life.
4. Tamper (governed sessions only): tokens store path (built from two parts), `.claude/settings`, `.claude/hooks`, `disableAllHooks`, `alias.` in a git segment, `.gitconfig` and `.git/config` on edit paths; checked on the decoded command and path fields, never on content.
5. Bash and Monitor: segment split, character sweep to `[A-Za-z0-9._/=:@+~-]`, basename compare for git, gh, claude, orca, ccsession; skip values of `-C -c --git-dir --work-tree --namespace --config-env`; `commit`, `push` gated below submit; `merge`, `pull` blocked always; at submit a push needs `origin`, named refspecs whose destination (after `+`, last `:`, `refs/heads/` stripping) is not master, main, HEAD, @ or empty, none of `--all --mirror --repo --receive-pack --exec`, no `$` or backtick.
6. gh: `pr merge` and `api .../merge` never; `gh <group> create` (and `pr ready`) blocked below submit; at submit `gh pr create` needs an explicit `--repo`/`-R` word, no name compared.
7. Escapes: `orca` subcommand list, `claude`/`ccsession*` with `-p --print --resume --continue --bare --settings --dangerously-skip-permissions`, Agent `isolation: remote`, Cron, Schedule, Workflow, RemoteTrigger blocked always; Monitor scanned like Bash.
8. Fail-closed: `compgen -G` empty-store fast path, then `jq` for `session_id` (regex only without `jq`, failing toward governing); once governed, default deny (last line `exit 2`) plus an EXIT trap mapping other codes to 2; `jq` missing blocks governed calls; unknown level reads as `worktree`; the claim script refuses to launch without `jq` or a registered guard.
9. Proof: literal-payload tests from an independent table, T-SPD-3 relative speed guard, OB-H1 (U1 ship gate) and OB-H2 mandatory before real use.
