# Description given to /sc:issue --create

"Evaluate the value, implications and unlocks or rethinks related to /sc:orchestrator having a Sub-Orchestrator or Coordinator mode" Agent claiming issue should /sc:analyze the ```/orchestration skill``` as well as the specs and work on the new ```/sc:orchestrator``` - Objective: To evaluate the value of having a sub-orchestrator primitive that can be called with a --sub option in instances where the work being done in the worktree calls for aggressive parallization in separate sessions and a greater degree of autonomy within the worktree -- This mode would impose a variation of the set of prescribed behavior attributed to an orchestrator -- The variation on behavior would relate to the need and benefits that come with delegating and orchestrate agents below it as well as reporting up and following orders from above.
