## DIRECTION-SELECTED (between R0 and R1)

- **Evidence:** a dated selection record written by the owner, never an agent. Names the date, option and decider, and where the owner's statement lives (agents may cite, never write it). Holds: default while no question rows exist, default after QUESTION-OBSERVATION, post-link choice or explicit deferral, fallback date, stack confirmation, command name, confirmed production-integration reading.
- **Input:** R0 renders of A, B, C at 160/116/80 marked synthetic, with degraded versions and C's find-and-inspect task.
- **Missing:** no production integration; R0 work continues.
- **Stale:** a later gate that changes what a direction can show, or the fallback date passing, triggers a re-confirm. Expiry never grants permission to switch direction.
- **Contradictory:** a selection whose data gate has not passed ships only an owner-accepted gated fallback with the reason on screen, or stays blocked. A selection never clears a gate; a gate is never bypassed to honour a selection.
- **Acceptance:** reviewer check AC-S (`acceptance-tests.md`); never reported as an automated test.

## Production integration: two readings (both UNVERIFIED as the issue's intent)

1. **Reading 1 (V1):** the first change that registers `superclaude observe` in the shipped CLI, or lets the adapter run a live Orca subprocess outside the fake runner.
2. **Reading 2 (V3):** the first change that wires or enables the observer in the shipped product; separately authorized read-only capture counts as research.

Until the owner confirms one in the selection record, the stricter reading applies: offline work only (R0).

- **Proof (a), withdrawn as worded (REPORT 2.1).** The old wording said that `--run` narrows `--all`; that claim is withdrawn. The read returns only the mailbox of the Run the caller is bound to. A caller bound to another Run is fenced: `{"ok":false,"error":{"code":"consumer_fenced", ...}}` with the message "This caller is bound to Run <A>, not Run <B>. Nothing changed." (exit status 1). So `--run` is a fence, not a filter. Basis: two-Run evidence on probe Run A (`run_c1badaa6576b`) and probe Run B (`run_14cfcbd8edf2`), 2026-11-11 (REPORT 2.1, evidence files 01, 02, 03, 04, 23).
