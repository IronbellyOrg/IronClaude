# Integration evidence and open questions

## Verified in this environment

Installed Orca version and its version-matched documentation were read. Worker-list exposes read-only paging and scope, while terminal resource accounting remains separate from task outcome. A live bounded fleet observation returned explicit totalCount and truncation; no message contents or credentials were captured. Source and installed IronClaude worker contracts were read separately.

The source test suite pins a P0 converted-command set, while the installed contract describes P1 conversion for sixteen commands. Sampled installed analyze, brainstorm and workflow definitions have Unattended mode sections not found in sampled repository counterparts. This supports a copy-specific rollout difference, not a claim that every documented phase is deployed. The design never uses worker_done alone as report validation or admission.

## Not established

1. Complete durable, non-consuming decision/message enumeration beyond the inspected 100-row CLI view.
2. Authoritative mission/owner/task/session/worktree joins across all hosts. Workspace co-location alone is not ownership.
3. A population-wide coordinator admission record, revision-pinned verification feed and explicit human-owner linkage.
4. Provider cost and resource telemetry with complete coverage, currency, observation time and deduplication identity.
5. Durable event replay and ordering across host restarts, plus source-loss recovery.
6. Native deep-link formats for the intended UI. No custom schemes or clickable live destinations are invented.

## Proposed only

The fixture schema, derived metrics, display buckets, source identifiers and navigation interactions are local design constructs. Original tools retain task lifecycle, retries, scheduling, worker management, approvals and Git/worktree ownership. Every UI interaction is inspection or local filtering only.

## Missing-data behavior

Display unavailable/stale/unknown explicitly. Keep last-known values qualified. Global counts must name scope and collection completeness; a selected filter must state its denominator. Source loss does not resolve questions, fail sessions, unlock a policy freeze or authorize retries. A partial result with complete files is inspectable but not necessarily admitted.

## Next experiment after design choice

Use one chosen composition in a supervised synthetic walkthrough: find a cross-owner decision, distinguish a stale test from a failed worker, locate a frozen worktree and identify incomplete cost coverage. Record user observations. Only then investigate a small read-only adapter against confirmed source contracts, with no operational controls and no LLM polling loop.
