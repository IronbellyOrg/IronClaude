# Qualitative Scoring, Pass 1 (input order: V1, V2, V3)

## Method

- Scorer: independent qualitative scorer, Step 3 Pass 1 of `/sc:adversarial`, 2026-11-02. Not an advocate. `scoring/qual-pass-2.md` was not read.
- Rubric: the 30-criterion additive binary rubric in `~/.claude/skills/sc-adversarial-protocol/SKILL.md` ("Qualitative Scoring Layer", lines 1666-1741). Each criterion is MET (1) or NOT MET (0). No partial credit. A MET verdict without a specific citation defaults to NOT MET.
- Variants, in input order: V1 = `variant-1-original.md` (option a, explicit flag); V2 = `variant-2-original.md` (option b, detect Orca); V3 = `variant-3-original.md` (option c, flag plus worker-session guard). The variant text as written is scored. Round concessions count against the conceding variant; Round 1 and Round 2 corrections do not earn credit for the original text.
- Evidence keys: `V1:N` etc. = line N of the variant file; `DA:N` = `diff-analysis.md`; `R1-Vn:N`, `R2-Vn:N` = `rounds/r1-variant-n.md`, `rounds/r2-variant-n.md`; `INV-NNN` = `invariant-probe.md`; `SPEC:N` = `.dev/orca-command-refactor/specs/orca-worker-contract-spec.md:N`; `CAPS:N` = `.dev/orca-command-refactor/inventory/orca-capabilities.md:N`.
- Sources re-read for this pass: SPEC 40-84, 145-214, 230-274, 310-399; CAPS 45-74, 124-151. These confirm the citations relied on below, including the DA spot-check verdicts (CAPS:47 says nothing about the preamble; SPEC:207's AC-C1 pattern would not match detection text).
- Each evidence cell gives the CLAIM (whether the criterion is met), then the EVIDENCE. The verdict column gives the VERDICT.
