**Smallest rule change for each HIGH UNADDRESSED finding:**

- **INV-006.** Change P1(b)'s trigger to "any writer other than this worker may write outside `.dev/` in that worktree during the run": another worker, the coordinator, the person, a user-taken-over terminal or a hook. In practice, every implement worker whose retry ladder can revert gets its own worktree, unless the coordinator records the checkout as having W2's "no other writer" for the whole run.
- **INV-024.** Add to G1 and to the worker preamble: under `--unattended` a worker never runs `git add`, including `git add .dev/tasks`. Staging `.dev/tasks` belongs to the coordinator in C1, or to a granted worker in W6. Amend the "always staged" lines in implement, workflow and reflect to defer staging under `--unattended`.
- **INV-025.** Move "merge into a shared branch" under C1's conditions. The merge runs only in the worktree where that branch is checked out, only when the placement map shows no other writer there, with the porcelain check, and it stops and reports on a hook failure or conflict.
- **INV-026.** Extend G1's list of spec changes. D4 (a) covers local commits only (W1-W6). Post-release's commit, push and PR steps, and auggie-review's `--post-pr`, are refused under `--unattended` (D4 (b) for outward actions). Amend `SPEC:123`, `SPEC:136` and `SPEC:345-348` to match.
- **INV-032.** Add a gate that G1 needs before it can hold: a test that scans the installed primitives for git and gh write verbs (`add`, `commit`, `push`, `merge`, `worktree add/remove`, `stash`, `update-ref`, `gh pr`, `gh api` posts). It fails unless each hit is allowed by G1 or refused under `--unattended`.
