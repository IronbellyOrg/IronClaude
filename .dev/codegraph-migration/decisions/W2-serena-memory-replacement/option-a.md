# Option A: plain files in a SuperClaude-owned repo-local folder
Replace each Serena memory tool call with native tools on `<project>/.superclaude/memory/<name>.md` (Write for write_memory, Read for read_memory, Glob for list_memories, Edit for edit_memory). Same shape as Serena's own store (flat markdown, topics via subfolders), so prompts change by tool name only. `.superclaude/` is already gitignored. /sc:save and /sc:load stay as commands (description says "file memory" instead of Serena). crash-recovery investigator reads `.superclaude/memory/` instead of `.serena/memories/`. Tracked `.serena/memories/reflect/deviation-patterns-IronClaude.md` moves to `.superclaude/memory/reflect/` (or docs/memory/ if it must be shared via git).
Pros: zero dependency, portable to every project and harness, mechanical edit across ~15 primitives, offline, testable. Cons: per-project not cross-project; gitignored so not shared across worktrees (each worktree has own copy unless path is resolved to main checkout); no schema/index (list = Glob).
