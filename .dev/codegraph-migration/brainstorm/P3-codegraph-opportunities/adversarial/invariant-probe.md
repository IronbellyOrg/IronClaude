## Emerging consensus (bullets)

Derived from the three Round 2 "Updated per-point positions" tables (agreed = at least 2 of 3 name the same superior approach; "A+B" = "B+A"; differently worded combinations with the same parts count as one). **62 of 65** S/C/X points agree (59 on a named approach, 3 on "none": S-002, S-011, X-020). No agreement: **C-029** (A / A+B / B), **C-031** (A+B / B+C / A+B+C), **X-021** (A / none / B).

- **Scope:** go beyond the 1:1 Serena swaps; C's swap ideas are cut (C-001 A+B).
- **Access in v1:** the CLI in orchestrators that can run Bash. Orchestrators compute artifacts (at most 40 rows and 6 KB) and pass them to agents by path. No agent `tools:` line gets `mcp__codegraph__*` (C-002, X-001 B). MCP classes come later, and only after measurement; the trigger is a logged count of about 100 serial CLI calls per run (C-002).
- **No `CODEGRAPH_MCP_TOOLS` listing in v1.** Measure the schema overhead first (C-003, X-003 B).
- **Allowlists:** one pattern per read-only subcommand, never `Bash(codegraph *)` (C-004, X-002 B). Bundled scripts get exact-path patterns, and the subcommand and mutation grep also covers script bodies (round2-B NE3, round2-C #8).
- **One shared seam skill** (C-005 A+B+C). A supplies the capability map and the closed `graph:*` vocabulary. B supplies the probe, the provenance check, the `parse_failed` state and `resolve-callsite.sh`. C supplies the PROBE→CALL→VERIFY→DEGRADE text as the skill body.
- **Run state:** availability and provenance are latched once per run. `status` freshness is checked again before any query batch that follows an in-run write, and that check clears cached rows. Pending files mean `stale: true` and the rows are leads only (C-007 B; A-006 REJECT by all three).
- **Who may change the index:** no primitive runs `sync` (X-006 B+C). Only a user-typed `/sc:graph init` runs `init`, and it refuses in a nested worktree unless `--worktree-local` is passed (C-023, X-005 A). `/sc:load` gets a read-only status line (X-016 A). No new hooks (C-022, X-007 B).
- **Foreign index:** answers from another worktree's index are discarded (`index_root == realpath(toplevel)`, A-010; C-006 A+B).
- **Citations:** each row is typed (`def-line`, `call-site-verified` or `unresolved`). The resolver searches only inside the `query --json` `startLine`/`endLine` span and must match `(file, startLine == def_line)`, otherwise the row is `unresolved`. A failing row is dropped, never repaired. evidence-validator stays `Read, Grep, Glob` and is not edited (C-009, C-010, X-004).
- **Explore:** no primitive step names explore (grep test), plus a routing block against unprompted calls (C-008, X-014 A+B).
- **Test selection:** an advisory delta first. `changed-area ∪ affected` enters VG-1 only after the NFR-08 backtest (at least 20 changes), which is extended with collection-error and zero-collect rates. Union paths are filtered with `git ls-files` and a collect-only pre-pass. Files are passed as positional args (C-013, X-008 B; C-014 A).
- **Reflect severity:** counts distinct production caller symbols, using the runtime-surface table. No new contract field; only `degraded_components` entries (C-017, C-018, X-013 B).
- **auggie-review:** the blast radius ships as context only first. The `dependent-impact` exemption runs in shadow mode and is enabled on counts (C-012, X-009).
- **implement:** pre-edit impact is a warning and an input to Q3, and does not widen edits. A post-edit check runs on the actual diff (C-011 A+B).
- **cleanup-audit:** asymmetric rule. Nonzero callers move DELETE to REVIEW; zero callers prove nothing. Orchestrator only, after a spike (C-019, X-012 C).
- **Planning:** the tasklist stays deterministic. The workflow step is informational and runs only when the symbols already exist. Graph numbers go to the ledger and reviewer package, not to the task file (C-016, X-010, X-011 A+B).
- **Candidates:** the seam skill, `/sc:impact` (A's modes and caps plus B's prod/test split; `--diff` and the `file` pin wait on a `--help` capture), `/sc:test-scope` and `/sc:graph` (C-027, C-028). reuse-auditor is deferred (C-020). Onboarding gets light edits only (C-021).
- **Rollback:** a release-level header switch (a source edit plus a release) and a runtime switch where an absent binary means the native path (C-033 A+B).
- **Ranking and risks:** Layer 0 prerequisites first, then a confidence-weighted score (S-007, C-024). Named risks: telemetry on the CLI path, Markdown repos get no graph signal, and allowlist blast radius (C-032 A+B).
