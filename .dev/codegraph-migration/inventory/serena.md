### 3.2 Options and choice

Options (files in `.dev/codegraph-migration/decisions/W2-serena-memory-replacement/`):

- **A. Plain files in a SuperClaude-owned folder `.superclaude/memory/`** with the native Write/Read/Glob/Edit tools. Keeps `/sc:save`, `/sc:load`, pm-agent lifecycle.
- **B. Claude Code's built-in per-project auto-memory** (`~/.claude/projects/<slug>/memory/`). Harness-specific, path owned by Anthropic, outside the repo, breaks the plugin use outside Claude Code.
- **C. Drop memory**: delete `/sc:save`, `/sc:load` and the pm-agent/mode memory calls.

Method: adversarial quick compare (`/sc:adversarial --compare ... --depth quick`). Final recommendation: `decisions/W2-serena-memory-replacement/adversarial/merged-recommendation.md`; scores and debate in `adversarial/adversarial/base-selection.md` and `debate-transcript.md`. Scores: A 0.6664, C 0.6540, B 0.5825 (the A-C margin sat inside the 5% band, so the debate tiebreak decided it, 9 points to 1); the advocates for B and C both ended up recommending A as the store or fallback. Convergence was 89.5% (17 of 19 points) with storage location and cross-worktree sharing unresolved, so the run's contract status is `partial`. The run also corrected two inputs: Option A's claim that prompts change "by tool name only" is false (Serena-only calls such as `think_about_*` and `summarize_changes` must be deleted, item 8), and `context.md` wrongly said pm-agent has 25 lines (25 is its match count; the file is 722 lines).

**Chosen: Option A, with the adversarial run's incorporated strengths:**

1. Store: `<project root>/.superclaude/memory/<key>.md`, flat markdown, subfolders for topics (same shape as Serena's folder, so prompts change by tool name only: `write_memory` -> Write, `read_memory` -> Read, `list_memories` -> Glob, `edit_memory` -> Edit).
2. The first write creates `.superclaude/.gitignore` (content `*`), because `.superclaude/` is ignored only in this repo (`.gitignore:114`); in another project the notes would show as untracked.
