## B. Claude Code documentation facts (code.claude.com docs, via context7)

1. PreToolUse stdin JSON: `session_id`, `cwd`, `hook_event_name`, `tool_name`, `tool_input` (Bash: `command`). (hooks-guide)
2. Exit code 2 blocks the tool call; stderr is shown to Claude; exit 2 wins even if JSON says allow. Exit 0 = no objection, normal permission flow. JSON alternative: `hookSpecificOutput.permissionDecision` = allow | deny | ask | defer, with `permissionDecisionReason` (for deny, shown to Claude); `updatedInput` can rewrite the tool input. When several PreToolUse hooks disagree: deny > defer > ask > allow. (hooks)
3. `UserPromptSubmit` can block a prompt with `{"decision":"block","reason":...}` (reason shown to the user, not added to context). The input has `prompt`. A typed `/model sonnet` slash command is a prompt, but it is a built-in client command: UNVERIFIED whether UserPromptSubmit fires for it.
4. `SessionStart` input has optional `model` (active model id) and `source` (startup|resume|clear|compact|fork) and `agent_type`. It can be omitted (e.g. after /clear). SessionStart can add context but a model cannot be rejected there except by making later events fail. `SubagentStart` input has `agent_id` and `agent_type` only: NO model field.
5. Agent tool model resolution order (sub-agents doc): (1) per-invocation `model` parameter (alias only: sonnet, opus, haiku, fable; no full id, no inherit); (2) subagent definition `model:` frontmatter; (3) env `CLAUDE_CODE_SUBAGENT_MODEL` (default only since v2.1.251; `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1` makes it win, v2.1.257+); (4) the main conversation's model. A family alias in param/frontmatter can resolve to the main conversation's model in two documented cases. An installed "mod" with an `agent.spawn` hook can replace the model.
6. `--model` flag overrides the `model` setting and `ANTHROPIC_MODEL`. `modelOverrides` setting maps Anthropic model ids to provider strings. Alias env vars `ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU,FABLE}_MODEL` redirect an alias to another model id.
7. NATIVE ALLOWLIST: `availableModels` (array of aliases or ids; also `deniedModels`, `availableModelsMatch`, `enforceAvailableModels`) restricts `/model`, `--model`, `ANTHROPIC_MODEL`, the `model` setting, resume, alias env redirects, subagent frontmatter, the Agent tool `model` parameter, `CLAUDE_CODE_SUBAGENT_MODEL`, skill and command `model` frontmatter, the advisor, background agents. Scope "any file". A managed-settings list REPLACES lower layers (cannot be extended by user/project/local); without managed settings, lists from user, project and local settings are concatenated (so a project list cannot subtract a user list). A model id entry such as `claude-opus-5` also permits later versions extending it (use `deniedModels` or `availableModelsMatch` to be exact). `enforceAvailableModels` (managed only) makes the "Default" option resolve inside the list. This is process-wide and static: it cannot express "Opus allowed for stage X only".
8. `claude --bare` skips auto-discovery of hooks, skills, commands, subagents, plugins, MCP, CLAUDE.md. So a `claude --bare` child session runs no hooks. Headless `claude -p` (not bare) does load settings hooks; `permissionDecision: "defer"` works only with `-p`.
9. Hook `timeout` is per registration in seconds. Non-zero exit other than 2 is a non-blocking error (the call proceeds): this is the fail-open default of the platform, so a hook that must fail closed has to convert its own errors to exit 2.

## E. Jev facts (from `.dev/research/346-review-loop-experiments/p22/JEV-OUTSIDE-USES-AND-PROPOSALS.md` and p15/p22 harness)

- Jev = TypeSafe-style small System-One judgment model that answers typed questions: Noul = probability of yes; Choice = one option with probabilities. Works on short single-item or pairwise judgments (duplicate findings AUC 0.98 to 0.99; issue mode 96%); fails on multi-hop judgments over large documents and on decisions from counts.
- Reported speed for a command-safety classifier: 70 to 500 ms per call (company-adjacent; outside tests find vendor claims 5 to 6x smaller at the median). Our measured cost: $0.008 per run, 2,011 pair calls = $0.051 total (about $0.000025 per call), 0 failed calls in that run (AB-RESULTS.md).
- Item 1 of the Jev doc: PreToolUse hook for outward actions; after a regex deny list, Jev answers a narrow question; block only when code could not decide AND p > 0.7; "must only ever add a block, never allow". Pitfall: the auto-mode classifier paper reports 81% false negatives under ambiguous authorization; Jev flags 0 of 30 out-of-scope inputs unless a "none" option exists.
- Item 7: tier choice via facet questions mapped by a code table; escalate on failure; needs retry-ledger data.
- Principle: policy stays in code; the judgment model answers narrow questions; code decides. Adapter conventions from p15: `JEV_API_KEY` env var (key only in env, redacted from journals), per-attempt timeout 20 s, retry once on 429/5xx/timeouts, a failed call is never an answer and routes to the conventional fallback, all-or-nothing response validation (`model_mismatch` etc.).
