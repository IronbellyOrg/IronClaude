### Suggested mitigation

- INV-001: Define an absent or unknown session record as "unknown" and block an Agent call without `model` when `inherit_check` is true; log `no_session_model`.
- INV-002: Mark the record stale after any `/model` or fallback signal, block inherit checks on a stale record, and list the picker and `--fallback-model` as cannot-see rows.
- INV-003: Add a `table_date` field and a `model-policy lint --live` that compares the seeded ids with the live alias env and the tier doc, warning on drift.
- INV-004: Keep the observe/enforce switch in a separate small file read first (missing means observe), so a broken policy cannot override observe-first.
- INV-005: Scan scripts and launcher env for `SC_MODEL_STAGE` assignments under the narrow-only rule, and have the helper set the child's stage explicitly.
- INV-006: Let a grant bind to a run id so later launches of the same run reuse it, and warn when a run outlasts its expiry.
- INV-007: Make the helper re-read the policy when its mtime changes, with a REQ that flips the mode inside a loop.
- INV-008: Put a non-model subcommand list (`--version`, `--help`, `mcp`, `doctor`, `update`, `plugin`) ahead of the no-model rule, one REQ each.
- INV-009: Restrict pass 2 to quoted strings that are arguments of `bash -c`, `sh -c`, `eval`, `ssh`, `xargs`, `find -exec` or a heredoc piped to a shell, and add pass-case REQs for grep, echo, git commit and gh.
- INV-010: Treat a set-but-empty variable as unset (`[ -n ]`) in every resolution step, with a REQ using `ANTHROPIC_MODEL=` and `CLAUDE_CODE_SUBAGENT_MODEL=`.
- INV-012: Map frontmatter `inherit` to "check the parent model (record)" and keep the call parameter `inherit` invalid, with a REQ.
- INV-014: When the policy is missing, also block unpinned launches and Agent calls without `model` in the enforce state, not only calls that name a model.
- INV-015: Set the internal timeout to the registration timeout minus 1 s (0.5 s for Edit and Write) and add a REQ that reads hooks.json and asserts the invariant.
- INV-016: Pin bytes and KB=1024, apply the 64 KB block only to launch-shaped commands, and add exact-boundary REQs at 65536/65537 and 262144/262145.
- INV-019: Write owner, flip date and numeric exit criteria per class in the rollout section, plus an owner-decision date if a gate is unmet.
- INV-021: State one merge rule: lower layers may change only `allow` (intersect), `deny` (union), `mode` and numeric caps (take the stricter); every other key is ignored outside the user layer; add a REQ.
- INV-022: List required keys (`stages.default`, non-empty `allow` of known tiers, `ids` arrays); any violation is MP-POLICY-BROKEN; add REQs for `{}` and `allow: []`.
- INV-023: Resolve an unknown, empty or mis-cased stage to `default`, never wider, and log `stage_unknown`.
- INV-024: State that `blind-scoring` allows opus plus the default tiers (or that helpers use a narrowing prefix) and add a REQ with a Sonnet launch inside blind-scoring.
- INV-025: Read grants in one jq call over the newest 50 files with an epoch expiry field, and add `model-policy prune`.
- INV-027: Match the prefilter on command words and variable assignments (word boundary), not on substrings, exempt Edit/Write paths, and add a PATH-stub REQ using a path with `/.claude/`.
