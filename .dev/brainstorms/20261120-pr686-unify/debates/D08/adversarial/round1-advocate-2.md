## Shared-assumption responses

**SA-001 (must the command name equal the role name?): QUALIFY.** Logically no, and the hybrid keeps the skill name and the flags separate from the word. In this case I see no benefit in splitting: the only alternative word for the command is "orchestrator", which R9/R10/R17 and the 63-file collision both argue against. So the command takes the role name, `/sc:coordinator`, because of the owner's rows and the collision, not because the two must match.

**SA-002 (genus noun with a differently named species or command, a layered name): ACCEPT.** This is the proposal below. Genus "coordinator"; species named by qualifiers; Clay's own D:799 term "standing-grant coordinator" is the species name for the script-woken, grant-holding kind. No second noun is needed for the role.

**SA-003 (does the script-woken session need a slash command at all?): QUALIFY.** Yes, one command, but for a narrower reason than I wrote.
