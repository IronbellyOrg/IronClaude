- Workers: no change. They never run `/sc:pr-submit` (never-as-worker list, WC-13) and a worker-recorded Ruling without the person's chat words stays "executor-invented approval".
- /sc:pr-submit: no code change. The limits are contract text only; the checks (end-of-run go record, `push_range_mismatch` halt) are design, not built (Q04 caveats), so the text promises less than a guard would. UNVERIFIED: that the tool's fence behaves as its text says (read, not run).

- Benefits: removes a rule the owner never made; closes the Full Submit contradiction; lets an agent record the owner's go without asking for a file.
