## 3 Revised unified proposal (standalone; the one I would sign)
**Typed wake line.** No, for every repo. A script never types into a Claude session. The coordinator learns of work from the wake file it reads at each `check --wait` return (at most every 5 minutes, FR-28) and from the Orca mailbox if U5 passes; the last-resort alert is the Orca "unread" mark, which types nothing. No key, no code. Scope note for the owner: this does not touch the contract rule where a coordinator types ONE copy of an answer into a worker's terminal after 5 minutes of silence, only on a positively idle prompt (WC:136); that is an agent in a session, not a poll.
**coordinator_autostart.** False for every repo today (absent means false, FR-27). One repo at a time:
 1. Throwaway repo the owner names (candidate IronbellyOrg/orchestrator-sandbox, private; UNVERIFIED that it is registered in Orca or is the intended one; tied to OA-19).
 2. IronbellyOrg/IronClaude after the soak in section 2 point 3, and after Coder 516 or a named hand-made COORD-IronClaude worktree.
 3. Any other repo only on the owner's naming it.
Conditions, all shown in chat before the owner is asked about a repo:
 - C1 owner confirmed the WORKER-CONTRACT wording in chat (OA-7). Master line 71 still says the coordinator is one "the person opened"; FR-27 cites it as WC:70, so recheck the line when editing. While OA-7 is unanswered autostart stays false (DECISIONS.md:1264).
 - C2 U3 (script-started terminal counts as depth 0) and U25 passed and recorded.
 - C3 restart is conditional on the same key (follow-up F5, FOLLOW-UPS.md:16), capped at 3 with a stored counter, and an unreadable process list starts nothing (FR-34, FR-17).
 - C4 the start prompt comes from a pattern-checked builder: repo name, the read-back duty list, the words "self-attested", no GitHub text (SEC-16; IronClaude is public, so issue text is attacker-reachable).
 - C5 the three off switches are tested and each reports `coordinator_absent`.
 - C6 Coordinator worktree origin equals the repo (the watcher already refuses otherwise).
 - C7 the repo's watcher is on (OA-19) and the hold in Clay's comment on Coder 516 is lifted by the owner.
 - C8 (new, fail-safe) the FIRST script-started coordinator on the throwaway runs with CCSESSION_PERMISSIONS=default (that mode exists on master, ccsession lines 123 to 163). If it stalls on a prompt nobody sees, the stall is the measured result and the owner decides; the permission bypass is never the silent default for a script start.

Typing stays refused so the terminal where merge and push goes are typed stays a person-only channel (D06 VERDICT.md:22: a script-typed line cannot be told from a person's).
**Costs (all estimates).** Owner: about 2 minutes per sentence. Live checks U3, U25, U5, idle meaning: about 3 h (four probes; no data). Autostart key, conditional restart, `coordinator_absent`, off switches with tests: about 4 h (size of FR-27, FR-34, FR-17, FR-20; inside stages S14 to S16 per A). Typed half: saved.
