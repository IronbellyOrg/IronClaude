# Agent A — first-principles theories for the H3 calibration miss

## Theory A1: The rubric measures provenance-of-citations, not adequacy-of-evidence-class — so a card built entirely from source-read with no runtime trace can max out "Evidence grounding" anyway

**Claim:** The H3 card was source-read-only (four file reads at the v0.44.2 tag via WebFetch) with zero runtime observation, yet the escalation rubric's "Evidence grounding" dimension awards 1.0 whenever a cited `file:line` "matches a real code path that exhibits the symptom." That anchor language treats source citations and reproducer output as interchangeable, so a card whose entire epistemic basis is "I read the source and inferred dispatch behaviour" can score 1.0 on the load-bearing dimension. Combined with high scores on the other four (which are easy to hit when the hypothesis is structurally simple), the arithmetic mean lands at 0.95. The calibrator inherits the same rubric and cannot push back against an evidence class the rubric explicitly admits as strong.

**Evidence:**
- `/config/.claude/skills/sc-troubleshoot-protocol/refs/escalation-rubric.md:13` — "Cited `file:line` matches a real code path that exhibits the symptom; OR diagnostic command output reproduces the symptom" — the OR makes source-citation and runtime-reproduction equivalent at the 1.0 anchor.
- `/config/workspace/Coder/.dev/troubleshoot/t4-pane-title-20260526-101500/tier2-h3-options-subcommand.md:21-66` — five evidence blocks E1-E5, all WebFetch source reads at the v0.44.2 tag; no command output, no log artifact, no `zellij list-sessions` probe.
- `/config/workspace/Coder/.dev/troubleshoot/t4-pane-title-20260526-101500/tier2-h3-options-subcommand.md:102-107` — the card itself explicitly flags "`start_client_impl` (whose body I did not retrieve)" as the residual risk, and proposes a runnable probe as the empirical follow-up — i.e. it knew an empirical step was missing and still scored 95%.
- `/config/workspace/Coder/.dev/troubleshoot/t4-pane-title-20260526-101500/wave1_5-branch-A.md:80-82` — Branch A itself flagged Q5 (whether `options` starts a session) as "partial / uncertain" with the explicit instruction "empirically verify in CI before relying on it" — H3 then claimed to resolve that uncertainty using the same evidence class Branch A had just declared insufficient.
- `/config/.claude/agents/confidence-calibrator.md:51` — calibrator is instructed to "Read the file at that range and verify the snippet matches" — i.e. confirm provenance, not assess whether the evidence class is sufficient to refute the hypothesis. A faithful calibrator scoring against the rubric anchor reads source, finds it matches, and scores 1.0.

**Per-theory confidence:** 0.80
**Systemic fix (one line):** Split "Evidence grounding" into two sub-dimensions — provenance (citation exists) and class-adequacy (citation type matches the claim's epistemic demand) — so source-only refutations of "does X happen at runtime" claims top out at 0.5.

## Theory A2: Refutation cards inherit Tier-1's confidence ceiling without inheriting Tier-1's calibration discount — the rubric is shaped around CONFIRM-class hypotheses

**Claim:** The rubric was designed to grade affirmative hypothesis cards (here is the cause; here is the fix). Its five dimensions — symptom coverage, reproducibility fit, fix directness, domain coherence — all presuppose a positive claim with a fix attached. H3's verdict is a REFUTATION ("the structural bug claim is false; no fix needed from this card"). For a refutation, "Symptom coverage" is trivially 1.0 (we are not trying to cover symptoms, we are dismissing a mechanism), "Fix directness" is trivially 1.0 (the proposed fix is null / do nothing), and "Domain coherence" stays 1.0 (single domain by construction). The arithmetic mean is then dominated by Evidence grounding and Reproducibility fit alone, which the card scores high (per Theory A1's mechanism), and four-of-five dimensions are essentially gimmes. The 0.95 emerges from the rubric scoring the wrong question for this card shape.

**Evidence:**
- `/config/.claude/skills/sc-troubleshoot-protocol/refs/escalation-rubric.md:11-19` — every anchor in the 1.0 column is framed around a positive cause-and-fix: "Proposed cause explains 100% of the reported symptoms", "Proposed fix touches the exact code identified in evidence", "Single domain (e.g. pure logic bug)". No anchors define what those mean for a refutation card.
- `/config/workspace/Coder/.dev/troubleshoot/t4-pane-title-20260526-101500/tier2-h3-options-subcommand.md:83-89` — under "Proposed fix" the card says "Because the hypothesis is refuted, NEITHER Option A NOR Option B is required to fix the structural shape. The current invocation is structurally correct." A null fix maps to 1.0 on Fix directness because the rubric has no anchor for "this card proposes no fix."
- `/config/workspace/Coder/.dev/troubleshoot/t4-pane-title-20260526-101500/tier2-h3-options-subcommand.md:95-97` — "Fully consistent with the v0.44.2 source" and "Domain coherence" treated as automatic (single domain = CLI parsing). The card narrates itself as scoring high on all five.
- `/config/workspace/Coder/.dev/troubleshoot/t4-pane-title-20260526-101500/REPORT.md:155-169` — REPORT.md cites H3 as "REFUTED at 0.95 confidence" with no caveat about refutation-vs-confirmation asymmetry; the protocol treats H3's 0.95 as equivalent to a CONFIRMED 0.95.
- `/config/.claude/agents/confidence-calibrator.md:49` — calibrator is instructed to apply the rubric "mechanically: one dimension at a time" — no special handling for refutation cards. Mechanical application of a CONFIRM-shaped rubric to a REFUTE card produces inflated scores.

**Per-theory confidence:** 0.65
**Systemic fix (one line):** Add a verdict-aware rubric variant where REFUTE cards must demonstrate a positive alternative explanation that survives the same scrutiny — refuting a hypothesis without proposing what IS happening should be a 0.5 ceiling.

## Theory A3: The calibrator's anchoring-strip is incomplete — the card's narrative structure leaks the formation context back in despite the agent never seeing the upstream trail

**Claim:** The calibrator is designed to defeat self-grading bias by stripping the hypothesis-formation context — the calibrator sees only the finished card and the rubric, not the upstream investigation. But the H3 card's narrative IS the formation context, written down. It cites Branch A by name (`wave1_5-branch-A.md`), quotes Branch A's "partial / uncertain" verdict on Q5, frames itself as "resolving" that uncertainty, and embeds the doc-context-card framing — the calibrator reads all of that. The narrative carries the conclusion forward (E1-E5 all conclude the same thing, with the card's own "convergence from four independent files" claim baked in at line 93). A faithful calibrator dimension-by-dimension scoring still reads the card top-to-bottom, and the card's framing makes high scores feel obvious. The "spot-check evidence citations" step (calibrator.md:51) confirms the snippets match — but does not catch that the citations don't COMPOSE into a refutation, because composition is exactly what the calibrator was told to take from the card.

**Evidence:**
- `/config/.claude/agents/confidence-calibrator.md:21` — "You only see the finished card and the rubric. The card itself is present (you must read it) but the upstream investigative trail is not — that is where the dominant anchoring bias lives." The mechanism explicitly assumes anchoring lives outside the card, not in it.
- `/config/workspace/Coder/.dev/troubleshoot/t4-pane-title-20260526-101500/tier2-h3-options-subcommand.md:43,47,51,63,81` — the card cites Branch A's prior verdicts, doc-context-card framing, and the welcome-layout finding from H1/H2 as supporting evidence for ITSELF. The card pulls the upstream investigation into its own narrative.
- `/config/workspace/Coder/.dev/troubleshoot/t4-pane-title-20260526-101500/tier2-h3-options-subcommand.md:92-93` — "The four primary-source evidence chains (E1 CLI struct, E2 dispatcher, E3 `start_client`, E4 options-merge) converge on the same conclusion from independent files in the same v0.44.2 tag" — the convergence claim is itself anchoring framing baked into the card.
- `/config/.claude/agents/confidence-calibrator.md:34-36` — "Anchoring bias is reduced, not eliminated. The card is still input. Your defense against the residual anchor is mechanical discipline" — the design acknowledges residual anchoring but the only mitigation is "mechanical discipline," which is exactly the kind of cognitive ask LLMs underperform on when the input is well-written.
- `/config/.claude/agents/confidence-calibrator.md:117-118` — "Placebo risk: if the calibrated score consistently matches inline calibration to within ±0.05, the agent is not earning its overhead." The design document itself names this failure mode but provides no enforcement against it. The 0.95 → 0.95 pass-through on H3 is the placebo failure made manifest.

**Per-theory confidence:** 0.55
**Systemic fix (one line):** Calibrator must be required to construct ONE counter-hypothesis from the card's evidence alone before scoring — if it cannot, the card's narrative has captured the calibrator and Evidence grounding is capped at 0.5.
