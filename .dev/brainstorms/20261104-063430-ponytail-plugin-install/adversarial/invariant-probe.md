## Summary

- Total: 31 items (INV-001..INV-031).
- By status: ADDRESSED 11, UNADDRESSED 20.
- By severity: HIGH 4 (all 4 UNADDRESSED), MEDIUM 9 (3 ADDRESSED, 6 UNADDRESSED), LOW 18 (8 ADDRESSED, 10 UNADDRESSED).
- By category: state_variables 6, guard_conditions 8, count_divergence 3, collection_boundaries 4, interaction_effects 5, sufficiency_challenge 5.
- Sufficiency verdict: the consensus alone does not make Ponytail present on every workspace. Each of these breaks it: the package not upgraded or a pinned Coder template (INV-027); Orca using the budget on every run (INV-028); a malformed settings file, a non-dict `enabledPlugins`, or unreadable defaults, each reported as "already installed" (INV-014); `CLAUDE_CONFIG_DIR` set (INV-021); a market key mismatch (INV-008, caught only by the manual M1a). And the claim that `off` is harmless for everyone is false as written (INV-001).

Proposed resolutions for UNADDRESSED HIGH items:

- **INV-001:** In the spec, docs and CHANGELOG, replace "dormant" and "nothing is added" with the real `off` footprint: the band above the prompt, a `git grep` at session start, and a ledger row per turn, Orca workers included. Have M1 observe it. Then let the user decide whether to accept it or to document `/ponytail band off` and the ledger opt-out.
- **INV-027:** Open the PR as "Refs #330", not "Fixes #330". Close #330 only after the template owner confirms the template installs the fork's current version with `claude` on PATH, or after a fresh Coder workspace shows `ponytail@ponytail` in `installed_plugins.json`.
- **INV-028:** Either bring the one-line deadline bound for the `_find_orca` probe (`ius:190`) into this PR, or state in the PR and CHANGELOG that workspaces where Orca's install times out will not get Ponytail until the backlog issue lands. In both cases, check whether Claude Code's background install covers the gap (INV-024).
- **INV-029:** Add a positive check, M1c, in the throwaway HOME: ponytail skills are listed, and `/ponytail lite` returns "PONYTAIL MODE CHANGED — level: lite" with the flag file appearing, then `/ponytail off`. This also gives M1b the positive control it lacks (INV-009).
