## Convergence verdict

**BLOCKED** on 3 HIGH-severity items. All three are the SAME root issue surfaced from different angles: the consensus under-specified the F3 fix as "canonicalize at extraction" without requiring the comparison site (Layer 3 PR-line 355) to also uppercase the window. V3's variant-3-original.md:170-171 contains the missing piece; the merge brief must promote it from "implementation detail" to "mandatory companion to V2's helper".

Remediation: amend the merged proposal to require BOTH:
1. V2's `_canonicalize_identifiers` helper (with `.upper()` at extraction) — addresses F1 + F3 contract.
2. V3's Layer 3 window-upper at PR-line 355: `window_text_upper = window_text.upper(); if not any(ident.upper() in window_text_upper for ident in contract_idents): continue` — addresses F3 enforcement at the consumer.
