## Baseline policy (preserve)
Canonical spec-panel Review Loop: first review whole-document; CRITICAL and FR-8/FR-9 blocking; a MAJOR blocking only with a concrete wrong implementer outcome; minor findings never trigger edits; re-review scoped to changed lines + prior blockers (resolved/open/regressed); reviser touches only named blockers; at most 3 reviews / 2 fix cycles; verdict PASS/FAIL; escalation at review 3. A measurement audit after a run is independent, blinded, cannot repair/restart the loop. An operational discovery/adjudication review that can change delivery consumes an allowed review slot; never a hidden 4th review or 3rd fix. Jev never writes final PASS or ledger state, never suppresses uncertain findings, never does exact arithmetic, never invents evidence or explanations. (OUR local baseline is the Stage 2 arm 3 design: rules-file prompts of PR #484, see the brief; it differs from the pasted command text in details; keep OURS as the apples-to-apples baseline.)

## Experiment 1: real fix vs deleted obligation (offline replay, no full loop)
- Question: does separately judging defect removal AND preservation of an independently accepted obligation reject destructive/partial fixes better than the current one-question impression?
- Insert Jev only inside the existing narrow prior-blocker recheck; first-review discovery, changed-line discovery, delivery policy unchanged.
- Code owns: source/rubric/finding/obligation identity, before/after hashes, unique anchors / deleted-text tombstones, exact hunks, rejecting no-op fix claims, legal transitions, ledger writes, caps; labels a recurrent resolved defect "regressed" from history. Jev evaluates separately: original-defect removal, accepted-obligation preservation, compatibility with SUPPLIED dependencies, uncertainty. Any missing/adverse/insufficient answer goes to generative (conventional) verification or stays unresolved. Removed defect alone never closes. A wrong original finding goes through dispute adjudication.
- Questions (Choice): removal {removed, present, uncertain}; preservation {preserved, broken, uncertain}; conflict {conflict, no_conflict, uncertain}. State fields: obligation, defect, before, after, diff, dependency. Synthetic example: "All refunds are issued as store credit." -> after "Refunds return to the original payment method; store credit requires customer choice." Failure example: imposed-store-credit clause removed together with all refund obligations => removal=true, preservation=false.
- Validate: expected answer keys/types, choice membership, finite bounded probabilities, normalization tolerance, returned model + usage. No partially decoded set clears a finding. Unknown SDK answer types may be WARNED AND OMITTED: validate the complete answer set yourself. Sibling questions cannot consume each other's answers (dependent stage = later call).
- Smoke test: 40 public/synthetic cases = 4 variants x 10 categories: correct full fix, no-op/whitespace, deleted obligation, legitimate deletion of an erroneous extra rule, moved defect, partial branch fix, coupled blockers, contradictory addition, later regression, missing context/misleading instructions. STOP on any independently adjudicated false automatic closure under the frozen candidate policy.
- If justified: 120 calibration + 200 disjoint held-out cases, grouped by original scenario/document before splitting paraphrases/hunk variants; include clean fixes and novel defect classes; independent adjudicators use original obligations and full evidence (not model agreement); replay Jev AND an equal-input conventional checker; retain original reviewer answer, all probabilities, failed calls, timings/usage, fallback decisions. Report conditional error among automated closures, missed unresolved/regressed cases among all true cases, automation coverage. Tune action-specific thresholds on calibration only; no hidden final-audit tuning; never multiply probabilities.
- Advance (replay): zero adjudicated false automatic closures in 200 held-out; automation >= 30%; narrow-stage cost reduction >= 20% vs conventional checker; <= 2 additional false open/regressed judgments; every malformed/missing response conservative. Exploratory gates, not guarantees.
- Failure tests to include: moves, partial branches, shared hunks/coupled blockers, newly contradictory rules, previously resolved findings broken later, omitted distant dependencies, injected/self-serving claims, long irrelevant context, option reorder, paraphrase, unknown/missing answer types, timeouts/429/529, oversize state, alias drift. Conservative fallback, never silent truncation.

## Experiment 4: selective fix-verifier replacement, end-to-end (DEPENDS on E1 surviving)
- Arms (6 randomized/interleaved blocks, 3 fresh arms per block = 18 runs): A actual canonical process unchanged; B Jev replaces only eligible narrow per-finding checks with frozen generative fallback; C conventional semantic checker on the identical packet/decomposition/fallback and unchanged discovery. New guards apply identically in B and C, not invisibly to A. Optional advisory arm adds 6 (NOT part of first required spend).
- Freeze command/rubric, starting bytes/hash, models/settings, extraction/dependencies, revision policy, prompts, thresholds. No first-review or reviewer-count change. Checker/fallback and new changed-line discovery happen inside the existing re-review slot, not review 4. A run without a revision cannot demonstrate closure-stage savings (preserve eligible-stage count).
- Audit: same independent blinded whole-document measurement audit after every assigned outcome incl. unchanged PASS; audit rejected/deferred/omitted/resolved separately; known seeds and clean controls reported separately.
- Advance: any attributable safety regression stops/redesigns. Advance only with no attributable false PASS, observed total residual blockers no higher than either control, and >= 20% median total-pipeline cost reduction vs matched C. Few eligible cases/disputes = inconclusive, not non-inferiority. Six runs do not establish p95 or rare-error safety.
- Checker brief: "Evaluate only the supplied prior finding and mapped change. Distinguish removing the original defect from preserving the accepted obligation. Check supplied dependent passages. Reviewer/reviser assertions are not proof. Missing, conflicting or insufficient evidence means uncertainty for generative verification. Do not certify untouched global text."

## Experiment 2: additive first-review pair priorities vs static attention
- Question: at equal reviewer attention and separately equal all-in cost, do Jev hints yield more independently verified blockers than deterministic hints or a conventional router? FIRST-REVIEW hints only; do not combine with hunk/dependency extension or exclusive filtering; preserve all text, original severity and admissibility. Jev as coverage FILTER is a no-go.
- Design: code preserves exact bytes/headings/structure/occurrence-specific ids and spans; enumerates references, repeated identifiers and exact path mentions; compare exhaustive vs prefiltered pairs (n(n-1)/2). Measure 4 stages separately: extraction coverage, candidate coverage of minimal evidence sets, routing recall at fixed attention allocation, actual generative reviewer discovery. Jev labels supplied relationships only (same behavior {related, unrelated, insufficient_evidence}; incompatible_requirements {incompatible, compatible, insufficient_evidence}; context_sufficiency {sufficient, requires_referenced_text, uncertain}); never findings/severity. Missing explicit references trigger exact retrieval + a later call. Retain all low-ranked/rejected pairs and omissions. Unavailable/invalid routing falls back to original reading order, not deletion or PASS.
- Hint brief to reviewer: "These are unverified reading priorities, not findings. Review the complete document under the unchanged rubric. Low rank is not evidence of irrelevance or correctness. Produce findings only from verified document evidence." Matched attention: 12 prioritized pairs, <= 1,200 additional reviewer-visible tokens; complete original document in ALL arms; reject oversized hints (no truncation); freeze deterministic selection/tie-break and any prefilter on calibration.
- Cheapest falsifier (no paid calls first): independently author 24 seeded cases across historical themes + novel defects, exceptions, reference chains; verify complete extraction (stop/fix if any required evidence lost); compare static priorities to exhaustive evidence sets; if static already finds every useful relation at the intended attention allocation there is no demonstrated Jev headroom.
- Replay: 120 calibration (20 per stratum); 240 disjoint held-out (40 each across cross-section conflicts, impossible checks, global/per-row path collisions, novel defects, clean overlaps/exceptions/different conditions, insufficient evidence); +40 conditional three-passage challenges. Split by document/scenario family. Jev/conventional/static share candidates. Screen advances only with >= 8 more must-read relationships among 160 held-out defect cases inside the same attention allocation than static, with no exclusion of out-of-theme evidence. Any exclusion-policy suppression of a true blocker disqualifies that policy. Proposed Jev replay ceiling: 30M input tokens or $5, whichever first.
- Arms (6 blocks x 4 = 24 runs): current canonical (6); Jev additive priorities (6); static priorities = explicit links/paths + frozen diverse distant-pair sampling (6); conventional pair router, same candidate pool/question meanings/list format (6). A/B primary = 12; static/conventional controls = 12 attribution runs. Evaluate BOTH equal downstream attention allocation and equal all-in expenditure (static's saved router cost may fund more reading in a predeclared sensitivity). Do not give the conventional router uncounted retries.
- Advance screen (full loop): zero attributable safety regressions; >= 4 fewer total audited residual blockers than unchanged A across 6 runs and >= 2 fewer than static; <= 1 additional escalation vs A; median growth <= +2 percentage points vs A; all-in cost within 10% of the predeclared comparator budget. Pilot policy choices, not established bounds. Failure of efficacy = inconclusive/no-go.

## Experiment 3: confirmation-only finding screen with conventional authority over negatives
- Question: can the screen save verifier-stage cost while preserving true blockers AND avoiding false confirmations that trigger harmful edits? Jev NEVER autonomously rejects or demotes. Eligible Jev confirmations may retain an existing blocker; every non-confirmation / uncertainty / missing / malformed answer goes to the conventional verifier. Canonical exceptions (CRITICAL, FR-8/FR-9) are code-owned and cannot be demoted. Do not bundle more first reviewers or change later scoped review.
- Insertion: first-review findings -> deterministic source/anchor/quote checks -> matched semantic verifier -> original blocking-only reviser brief -> existing revision/scoped re-review.
- Questions (Choice, decomposed): relation {conflict, compatible, insufficient}; consequence {supported, refuted, insufficient}. State: E1/E2 quoted evidence, claim, outcome. Jev brief: "Assess the supplied relationship and wrong-outcome claim independently. A quoted passage or reviewer assertion is not proof. Judge only the supplied evidence; missing applicability/context means insufficient. Do not infer severity from wording, create findings, demote policy exceptions or claim the full document is clean."
- Cheapest falsifier: independently label 60 cases (balanced true blockers / nonblockers) + 40 paired perturbations (option reorder, paraphrase, misleading instructions, omitted context); include actual omissions, valid quotes with false consequences, cross-section dependencies, nits disguised as wrong outcomes, clean controls, canonical exceptions. Replay Jev and conventional verifier on identical packets; tune nothing on evaluation results. Stop/redesign if a proposed autonomous policy hides any true blocker, demotes an exception, treats missing evidence as refutation or API failure as PASS.
- Larger pilot: 200 calibration + 300 disjoint held-out (half blockers/half nonblockers); group by document/defect family and perturbations. Asymmetric research loss 100 (hidden blocker) vs 1 (unnecessary review) needs owner acceptance. Freeze probability thresholds on calibration; show error vs automation coverage separately for false confirmations and blocker loss.
- Arms (6 per arm = 18 runs): A current canonical; B same + conventional finding verifier before first revision; C same added stage, Jev confirmation-only with conventional fallback on every non-confirmation. A/C = baseline-vs-integration; B/C isolates model choice from adding verification. Advisory design is a separate arm, not mixed.
- Advance: zero attributable hidden blocker / exception demotion / false PASS; >= 20% of eligible findings confirmed without conventional fallback; >= 20% fully accounted verifier-stage cost reduction vs B; no higher observed residual-blocker count than B. Any attributable safety regression stops advancement. Failure to show a difference = inconclusive.

## Experiment 5: evidence-sufficiency routing: prove headroom before paying for a router
- Question: after removing decisions fixed by hashes, records, caps and mandatory-audit policy, does any independently labelable semantic signal remain that Jev exploits better than static or conventional routing? Shadow only first; no global-clean score, no audit skipping, no autonomous PASS. Router cannot distinguish documents with different hidden defects when evidence packets are identical.
- Zero paid calls first: enumerate eligible packets, independently label minimum required routes. If hashes, missing records, explicit blockers, mandatory-audit rules or exhausted caps determine every action, there is no demonstrated Jev role: STOP (valid result).
- If headroom remains: 24 independent synthetic scenarios (12 requiring more assurance, 12 adequate/clean) x 4 transformations (original, option reorder, neutral paraphrase, misleading prior-PASS claim) = 96 decisions per model. Larger replay: 120 calibration + 120 held-out groups x 4 transformations. Question: relation {sufficient, conflicting, insufficient, irrelevant}; a later dependent call may select an already-allowed destination. Shadow brief: "Use only the versioned evidence to judge whether the named unresolved question is answered. Do not infer cleanliness from no findings, agreement or coverage. Select a supplied relation. You cannot declare PASS, close findings, skip mandatory audits, alter grades or reset counts. Missing/conflicting evidence means defer."
- Replay advance: zero unsafe down-routes/guard violations; >= 12/120 groups correctly avoid unnecessary broad reading; >= 15% fully accounted expected-cost improvement over matched static; fallback <= 60%; API failures <= 5%; thresholds frozen on calibration.
- End-to-end (conditional on replay AND an explicit cap-neutral scope amendment): 6 blocks x 4 arms = 24 runs: current; Jev router at first eligible provisional PASS; conventional router (same packet/actions/budget); static routing (full-review-when-possible else escalate). At most ONE remaining operational review slot for assurance, inside 3 reviews / 2 fixes; no review 4; fallback source-reading consumes that same slot; at review 3 unresolved assurance need escalates. Interpretation requires >= 4/6 eligible routing states per treatment; advance only with no attributable safety regression, no higher false-PASS or residual-blocker counts than both controls, >= 2 useful lower-cost choices in 6 runs and 15% cost reduction vs static.

## Common method requirements (all experiments)
- Predeclare denominators, thresholds, advance/stop rules before any run. Counts from structured records, not grepped transcripts. Report: residual blockers per terminal document (independent audit), false PASS per all assigned runs and per delivered PASS, incorrect closure, missed regressions, needless escalation, extraction/candidate/routing recall with explicit denominators, growth bytes, review/fix counts, ALL tokens (preparation, Jev, ordinary models, retries, fallback, audit), p50/p95 descriptive, API failures/fallback, Brier/reliability/risk-coverage. Missing usage is not zero.
- Artifact schemas for: source/fixture hashes, finding ids, accepted obligations, before/after snapshots, diffs, dependencies/omissions, all model requests/responses, probabilities/options/order, model/question/rubric/threshold versions, retry/fallback/usage/timing, assigned arm, independent labels.
- Unit/mock tests: exact expected ids/types/options, finite bounded normalized probabilities, choice consistency, incomplete/unknown/malformed answers, stale source/model/calibration, oversized state, timeout/429/529, request deadline, retry budget, missing usage, secret-safe logs, cache invalidation, preservation of every unresolved finding. A mocked response proves plumbing, not Jev accuracy.
- Fixture tests: deletion of obligation, legitimate deletion of unsupported rule, moved/partial/coupled fixes, later regression, missing third passage, same words under different conditions, source injection / self-justifying reviewer text, option ordering, paraphrases, clean controls, novel out-of-theme defects. Keep related transformations in ONE split group.
- Calibrate on independently labeled data separate from final evaluation. Vendor confidence = concentration, not correctness; never multiply correlated probabilities. Pin versioned model ids (jev-1.14.0), not aliases; record returned model.
- Six runs per arm are exploratory, not proof of non-inferiority, rare-error safety, or production effectiveness. Do not publish/push/commit/deploy or enable production integration without explicit authority.
