## Insertion points and interaction
Flow: panel -> merge -> ADJ(Sonnet) -> clean VF -> **A1(spec)** -> V1 -> **lint-2 + A2 + A1(rerun)** -> R2 -> **A3** -> V2 -> **lint-3 + A2 + A1(rerun)** -> R3 -> frozen audits.

- **A2 (before panel, and re-run at R2/R3).** Code reuses reqlint's table parser on the 25 check rows + 7 live-check steps; lint-clean rows go to Jev. Question `check_observable`: {can pass, cannot pass, cannot discriminate, insufficient}. Non-"can pass" becomes one UNVERIFIED line in lint-N.md (the file reviewers already get). Code around it: lint stays the control, the scratch-dir executor runs shell/grep/YAML rows and its result overrides Jev on those rows. Fallback: error/insufficient/timeout = no line.
- **A1 (after VF, before V1; re-run after each revise).** Code builds obligation rows (37 + WC rules) and criteria, pairs them by id/command/phase PLUS WC x AC pairing. Question `support`: {supported, partial, unsupported, contradicts-or-defers, insufficient}. Max 12 non-supported pairs, as flag-only lines in the V1 brief and R2/R3 briefs. Fallback: no hint. Never a finding or closure.
- **A3 (after R2 FAIL, before V2).** Per surviving blocker, code packs V1 hunks, R2 re-raise text and `named_not_touched`. Question `novelty`: {new aspect, same defect restated, no relevant change, insufficient}. One flag line in the V2 brief. Fallback: no hint; cap stays 2 fixes.

Order of interaction: A2 feeds recall (before ADJ); A1 and A3 feed the reviser. **Dedup rule:** if A1's re-run already flags the span A3 would flag, emit one merged line (A3 adds only "same approach"), so the reviser never sees two hints for the same blocker. Hints never enter the frozen audits (no model judgment becomes audit truth). A1 hints appear after VF, so they cannot be filtered by VF; that is the risk below.
