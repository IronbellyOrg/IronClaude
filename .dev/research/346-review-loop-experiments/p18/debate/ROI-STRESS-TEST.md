## Scope and actual measured evidence
Jev = the proposed service that answers one bounded evidence-judgment question. No workload frequency, incumbent miss rate, downstream loss, Jev price, accuracy, calibration, batching or latency has been measured. No integration, live comparative experiment or source/config change is approved. No direct displacement is established: retaining an owner or mandatory stage does not prove its variable work can never decrease; contract barriers need an approved amendment; unknown empirical fitness needs measurement.
Decision standard: at matched measured error classes compare FULLY LOADED total cost (equal quality at lower total cost has value); for improved quality compare incremental avoided loss with added all-in cost. Keep dangerous false-pass constraints separate: an economic score cannot authorize erased requirements, false compliance, suppressed blockers or approval bypass.
Terms: incumbent = the current owner/process. Control = a competing conventional or static check. Headroom = error loss the incumbent might avoid. Replay = frozen cases evaluated without changing the live owner. Shadow = non-controlling output. Dangerous false pass = a falsely passing outcome with a safety, requirement, evidence or authority consequence.

## Break-even economics
All recurring amounts per invocation of the host command. F = invocations per period, H = horizon in periods; N = judgments per invocation after a prefilter (N = min(prefilter_ceiling, raw_pairs)); judge_unit_cost, unresolved_fraction, fallback_unit_cost, packet_cost (preparing/validating context), consume_cost (parsing, owner reading), integration_total, evaluation_total_over_H (ALL labeling/replay cost, charged once), maintenance_per_period, saved_incumbent_cost (UNKNOWN), m0/m1 escaped defects before/with the seam, loss_per_escape, false_alarm_rate/alarm_cost, overtrust_rate/harm_loss.
added_cost = N*(judge_unit_cost + unresolved_fraction*fallback_unit_cost) + packet_cost + consume_cost
overhead = (integration_total + evaluation_total_over_H)/(F*H) + maintenance_per_period/F
net_direct_saving = saved_incumbent_cost - added_cost - overhead
quality_value = (m0 - m1)*loss_per_escape - false_alarm_rate*alarm_cost - overtrust_rate*harm_loss
Rules: at matched measured error classes choose the lower fully loaded total cost; for unequal quality compare incremental quality_value with incremental added all-in cost against the unchanged incumbent AND the conventional/static controls AND the Jev-enhanced system. A lower vendor unit price alone cannot win. A favourable average cannot waive dangerous false-pass constraints. Joint confusion counts are required (net escape reduction = incumbent-miss/seam-catch events minus incumbent-catch/seam-induced-miss events); marginal accuracies do not establish it. If a prefilter loses relevant pairs, its misses enter m1: Jev cannot recover pairs it never sees. Raw pairwise counts grow quadratically; any cap requires measured recall.
No double counting: shared schema/harness engineering counts once; case-specific context/labels/preparation are not automatically shared; reuse requires identical immutable evidence/context AND question scope; never reuse a model judgment as independent audit truth; count each observed avoided repair once, and never in both saved_incumbent_cost and quality_value; for overlapping candidates (R-008/R-019/R-012/R-021) measure combined-system outcomes, not summed standalone benefits.
Controls compete: negation rules, vague-criterion lint, explicit-bullet audit, retrieval ranking, ID/path/hash/key checks, trace tables, retry diffs, validator checks establish only their literal metadata property (IDs can match while a task defers the requirement). Charge field/label authoring, user confirmation, prompt-output tokens, engineering and contract revision. 'No-model is not free.' The unchanged incumbent is also a legitimate arm.
Elapsed time has its own ledger: added_elapsed_time = preparation + ceil(N/batch_width)*judge_time + fallback_schedule + consume_join + contention - genuinely_displaced_time. Shadow adds zero critical-path delay only without join/contention.

## Measurements and risks
Hold out by source document, not by pair. Independently blinded labels using complete source/context. Record the incumbent verdict BEFORE showing Jev results. Record per error class: frequency, natural misses and silent accepts, joint catch/miss/induced-error counts, omitted inventory items, false coverage/compliance, lost protected signals, unresolved/error/fallback rates; all failures stay in the denominator. Measure tokens, retries, packet prep, consumption, label/control authorship, fallback schedule, latency, integration/maintenance/re-evaluation cost, prefilter recall. A mock transport validates only harness behavior. Mandatory caller-owned items stay with the owner: hashes, IDs, counts, schema, source identity, flags/caps, graph ordering, retry state, budget policy, user approval, final PASS and root-cause authority.
Risks: false reassurance/anchoring; correlated errors (a second model is not independent assurance); reduced or stale context; invalid baselines (policy contradictions create fictional savings); model/prompt/schema drift (budget recurring evaluation); fallback and false-alarm load; contract erosion; private-data exposure (public/synthetic fixtures first). A successful replay cannot silently amend a closed prompt, remove an owner or authorise production use.
