# Leakage and sycophancy check of the ab5 results (2026-11-10)

Question: fixes per run for ab5 full were 5, 12, 14, 17, 22, 23 (variation only upward from the older arms?). Is there leakage between runs, and is the scoring sycophantic?

## Leakage between runs
* Tool-path audit of all 131 ab5 agent transcripts (1,917 absolute paths in tool inputs): no agent read or wrote another run's files. One reviser listed sibling run directory names (`ls ..`, names only); one re-reviewer of d5f-r4 wrote a diff to a shared name `scratchpad/d.txt` (other agents used the same file name in earlier phases): an isolation weakness, no evidence of cross-reading. Sandboxing is by prompt only; the agents had unrestricted file access.
* Content overlap: mean Jaccard of added spec lines between any two final specs is 0.000-0.003 within and across arms, and does not depend on how close in time two runs started (rho 0.00, n=66 pairs). Copying between runs would show as shared text; there is none.
* Reviewer detection does NOT trend with run order (union of ledger defects raised: rho +0.12 panel, +0.09 full). Conversion of raised defects to fixed defects does: fixed/raised rho -0.94 in both variants (full: 0.76, 0.88, 0.57, 0.48, 0.44, 0.18). Fixed count vs run index: panel -0.93, full -0.89, PN1 -0.71, but ab4/baseline/other non-panel arms ~0.
* Run index is confounded with start time and load: r1/r2 of both variants started together at t=0 with 4 runs in flight; r3-r6 started at +17, +18-21, +21-23, +32-33 minutes with up to 12 runs and 16 agents in flight. The decline sits in the stages after discovery (merge/ADJ/verify/revise), is not explained by leakage (leakage from earlier to later runs would raise later runs), and cannot be separated from a load/time effect with this design. Fixed count also tracks edit volume (rho 0.78 pooled; fixed per 100 changed lines 24-37 across arms), and edit volume falls with index (full: 51, 64, 34, 30, 43, 32 changed lines).
* Consequence: the early two runs of each variant carry the headline. ab5 full without r1/r2: 17, 12, 14, 5 = mean 12.0; PN1 without its first two: 14, 15, 17, 10 = mean 14.0; panel without first two: 7, 9, 6, 6 = 7.0. Treat "full ties PN1" as unproven until runs are randomized in launch order and held at equal concurrency.

## Scorer sycophancy
* Four specs (the two highest and two lowest ab5 scores) were re-scored blind by Opus 5.5 on the same inputs: fixed-vs-not agreement 97% (kappa 0.93), exact status agreement 96%; Sonnet credited a fix Opus did not in 4 of 56 cases (7%), Opus the reverse in 1. Totals: s73 22 vs 19, s74 23 vs 22, s75 5 vs 6, s76 6 vs 6. The ranking is unchanged; Sonnet is slightly generous at the top end (about -1 to -3 fixes on the highest specs).
* Mechanical checks: every FIXED claim sits within 5 lines of a diff hunk (100% in all arms); verbatim quotes in FIXED evidence were found in the revised spec 100% (baseline), 94% (ab4), 90% (PN1), 87% (ab5 full), 67% (ab5 panel). The lower panel rate (paraphrased or original-text quotes) is a scorer-evidence weakness, not a status error as far as the Opus rescore shows.
