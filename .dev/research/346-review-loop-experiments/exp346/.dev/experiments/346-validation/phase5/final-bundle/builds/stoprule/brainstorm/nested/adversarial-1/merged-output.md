## 2. Mechanism

### 2.0 Decisions this variant commits to

<!-- Source: Base §2.0 bullet 1 (original) -->
- Where computation lives: BOTH, split by kind. A script (`stoprule.py`, stdlib only) does everything deterministic: cap and count, quote and citation read-back, ratchet anchoring, hunk coverage, grade merge, verdict, escalation text. ### 2.4 The verdict function (pure over the ledger; `stoprule.py verdict --report R` prints it)

<!-- Source: Base §2.4 (original, modified) - frozen priors per Change #2, reason set per Change #7 -->

```python
confirmed  = [c.id for c in claims if c.final in ("confirmed", "confirmed-audit")]
unresolved = [p.id for p in priors if p.frozen and p.status in ("open", "regressed")
              and p.final != "withdrawn-audit"]  # frozen carried blockers are never re-graded (Change #2)
pending    = [c.id for c in claims if c.final == "unconfirmed"] + uncovered_hunks
reason     = {"confirmed": confirmed, "unresolved-prior": unresolved, "incomplete": pending}
reason     = [k for k, v in reason.items() if v]  # Change #7: FAIL reason set
verdict    = "PASS" if not reason else "FAIL"
```
<!-- Source: Variant C §6 failure table semantics with A and B rules (R2-B §1 C-1, R2-A §1 C-1, R2-C §1 item 5), Change #7, Disposition: merged-from-multiple, Decision basis: X-002 to B at 80%, C-028 to B at 80%; A-007 qualified by all three at 85%; C's third state withdrawn, kept as reason codes -->
Any confirmed blocking finding is FAIL, none is PASS; a missing grade, an uncovered hunk or an unresolved prior is also FAIL, so silence never passes. The verdict is binary; FAIL carries a reason set: `confirmed` (any confirmed claim), `unresolved-prior` (a frozen open or regressed prior), `incomplete` (any `unconfirmed` claim, or an uncovered hunk after the repair). Only `confirmed` and `unresolved-prior` ids enter the Reviser brief. An `incomplete`-only FAIL produces the brief "No confirmed blocking findings: make no spec edit" (section 3.1 bullet 6 and section 4). Infrastructure failure is not a defect, and an unconfirmed item never reaches the reviser. `stalled` (confirmed count not lower than the previous review while at least one remains) is reported in the computed block and is not a halt; the canonical cap is the only halt.
