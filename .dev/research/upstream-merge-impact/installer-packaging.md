### Current distribution and dependency chains
1. [CODE-VERIFIED] **High-impact distribution entry point.** `pyproject.toml:69-87` registers the CLI and pytest plugin, packages `src/superclaude`, and force-includes full `src` and `plugins` trees. The command-copy implementation added by `8c0559ca` is still directly called by both install and update (`src/superclaude/cli/main.py:197-205,381-385`); it now excludes README, preserves existing files without force, and copies from the resolved source (`src/superclaude/cli/install_commands.py:11-64`). Removing that added module without a replacement leaves these imports and callers unresolved. The current regression suite directly requires copying, skipping and forced refresh (`tests/unit/test_cli_install.py:512-576`).

2. [CODE-VERIFIED] **The fork built a complete installer around that entry point.** Install now deploys core files, commands, agents, skills, ccsession, hooks, templates, user setup, and required native Codebase Memory, and combines their success flags (`src/superclaude/cli/main.py:189-275`). Update refreshes the eight framework components and does not invoke the native MCP phase (`src/superclaude/cli/main.py:363-431`). The later fork tests pin both sequences, failure propagation and ccsession-before-hooks ordering (`tests/cli/test_update_command.py:16-25,96-146,173-180`). Thus removing the upstream install/update functions is not merely dropping an unused convenience command.

3. [CODE-VERIFIED] **The namespace change remains a contract.** Both CLI defaults remain `~/.claude/commands/sc` (`src/superclaude/cli/main.py:29-34,346-351`), while direct installer and installed-command enumeration use the same directory (`src/superclaude/cli/install_commands.py:25-27,149-166`). Development sync copies commands to `.claude/commands/sc/` (`Makefile:131-136`), and the current command README describes this installed surface (`src/superclaude/commands/README.md:1-11`). Reverting `ad80f57f` changes fresh install and listing defaults back to the unnamespaced command directory while leaving the fork's current instructions and command references using `/sc:`. It would require an intentional namespace migration, not just an old-patch application.

4. [CODE-VERIFIED] **Packaged resources became canonical source, not expendable duplicates.** The package-first resolution introduced by `42946f84` is intact (`src/superclaude/cli/install_commands.py:96-126`). The fork now says to edit commands there first, regenerate development mirrors, and separately maintain only selected plugin parity (`src/superclaude/commands/README.md:5-11`). `recommend.md` has become a fork-specific refined-prompt builder with only three documented flags and an installed skill handoff, unlike the historical 1,005-line recommendation table copied by `c6e72825` (`src/superclaude/commands/recommend.md:1-58`; historical patch `installer-packaging-c6e72825.patch:318-1328`). Deleting these original added command files would remove today's evolved versions, not restore a better current architecture.

5.
