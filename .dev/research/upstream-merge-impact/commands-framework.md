### Current dependencies and later fork development

#### Entry point to resources to consumers

1. [CODE-VERIFIED] **CLI resource distribution:** `install` explicitly calls the core, command, agent and skill installers; `update` repeats core/command/agent installation with force enabled. The command installer discovers all source Markdown files and copies them; it does not contain the restored command logic itself. Removing a command resource therefore removes the installed entry point while leaving its separate protocol skill behind (`src/superclaude/cli/main.py:189-219,375-397`; `src/superclaude/cli/install_commands.py:29-44,50-62,107-126`). Existing user-installed copies are not automatically deleted by a repository revert: these installers copy and overwrite files but do not reconcile removed commands (`src/superclaude/cli/install_commands.py:50-64`; `src/superclaude/cli/install_agents.py:47-59`).
2. [CODE-VERIFIED] **Fork skill dispatch:** the task protocol names `quality-engineer` as its strict-tier verification worker; troubleshooting selects root-cause, quality, refactoring, security, performance, architecture and deployment agents. Those are agent definitions introduced by `3762d6ab`, so removing their current files leaves real skill dispatch targets missing, rather than merely losing descriptions (`src/superclaude/skills/sc-task-protocol/SKILL.md:311-315`; `src/superclaude/skills/sc-troubleshoot-protocol/SKILL.md:345-360`; historical restored roster `commands-framework-evidence/git-history.txt:143-150`; current inherited agent body `src/superclaude/agents/backend-architect.md:1-56`). 3. [CODE-VERIFIED] **Current research behavior and tests:** research points to `RESEARCH_CONFIG.md` for depth profiles and to research agents for routing. The command tests read both files and assert the four profile names. Deleting the restored core configuration or research command would make these direct file-content tests fail or raise a missing-file error, even before considering user-visible behavior (`src/superclaude/commands/research.md:86-100`; `tests/commands/test_research_command.py:11-15,18-22,34-51`).
