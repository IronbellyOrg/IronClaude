### Current architecture and later fork dependencies

#### Memory documentation is not the implemented memory subsystem

[CODE-CONTRADICTED] **Important: inherited memory instructions target the wrong implementation and data format.** The user guide and memory README promise an always-running `ReflexionMemory`, automatic `reflexion.jsonl`, a 50% overlap threshold, adopted/deprecated status handling, and a `superclaude/core/pm_init/reflexion_memory.py` implementation (`docs/user-guide/memory-system.md:61-103`, `:220-226`, `:264-269`; `docs/memory/README.md:15-45`). Neither promised implementation path exists; a tracked-source search across `src`, `scripts` and `tests` finds only the actual `ReflexionPattern` class, not a `ReflexionMemory` implementation (`docs-verification-evidence.txt:73-76`, `:107-108`). The real code writes `solutions_learned.jsonl`, stores caller-provided error dictionaries with a timestamp, has a Mindbase search stub returning `None`, scans rows in stored order, and matches at 70% using set union (`src/superclaude/pm_agent/reflexion.py:57-82`, `:110-136`, `:138-170`, `:172-244`). The example has `task/mistake/fix` fields instead of the parser's `error_type/error_message/test_name` and returned `solution` fields (`docs/memory/reflexion.jsonl.example:1-15`, `src/superclaude/pm_agent/reflexion.py:138-170`, `:205-214`). Restoring the pre-commit claim that Mindbase was built-in would replace one misleading description with another, not fix this fork.

[CODE-CONTRADICTED] The memory README says passwords, secrets, API keys and personal data are not stored, then tells users to manually redact sensitive entries (`docs/memory/README.md:183-216`). The actual recorder serializes the supplied dictionary without redaction, and the pytest hook supplies error messages and tracebacks (`src/superclaude/pm_agent/reflexion.py:127-132`, `src/superclaude/pytest_plugin.py:188-196`). A targeted documentation correction must remove that guarantee. This is an introduced documentation hazard, not a reason to delete the real error-learning code.
