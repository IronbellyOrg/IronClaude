## 2. Recipe Ledger machinery: over-built for what it must prove (audit agent 1)

What 81 real runs used: the launcher, reviewer runner, scheduler, clock and hang guard, lens render, ledger check with its allowances, the blind judge scripts. Top over-engineered items: (1) 20 partly-met requirements and 12 manual checks that wait for attestations nothing reads (`IMPLEMENTATION-REPORT.md` section 5.1); (2) gates and pre-registration code never used; (3) the ablation; (4) the re-ask path; (5) the freeze and order ceremony, where `git tag` plus `sha256sum` does the same job.

## 3. Model-policy hook: over-built for warn-and-report (audit agent 2)

The design has 63 requirements and four layers. Under the owner's final decision (log and warn, never halt, observation mode, uniform policy, installed files protected, no strict served-model gate), the agent counts about 45 requirements as cut or deferred. Cut as theatre: blocking paths, grants approved by a typed "yes", tamper rules (a read-only installed file does the same), fail-closed paths, latency targets, the 500-transcript replay corpus, the Jev spike gate, the native `deniedModels` floor.

**Smallest version (about 200 lines):**
1. A 10-line policy file listing restricted model ids (Opus), seeded by one entry in `install_hooks.py` (`_SEED_FILES`, line 104).
2. One command `superclaude model-report <dir>...` that scans output JSON files (`modelUsage` keys) and session transcripts (`message.model` per message), sums output tokens per model, flags restricted ids with the file path, always exits 0, and appends incidents to a log. A missing policy file prints a warning and falls back to a built-in list.
3. Optional later: a session-end hook that runs the report on that session's transcript.

Why it fits: the agent counted 3,679 JSON files in the repo with a `modelUsage` key and 915 under `.dev` naming `claude-opus-5-5`; transcripts carry a per-message `model` field. It also catches the 2026-11-15 case (Opus-class reviewers chosen inside a command), which a launch-time check cannot see.
