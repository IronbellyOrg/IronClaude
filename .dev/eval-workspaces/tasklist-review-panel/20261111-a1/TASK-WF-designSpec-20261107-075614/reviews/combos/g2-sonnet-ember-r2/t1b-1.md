## Findings

**Medium (follow-up candidates)**

1. **F1: Wave 0 bullet wording is self-contradictory (Task 9).**
   - An implementer who follows the stated text builds a bullet that "carries no L3 or `draft` condition", and the same task requires it to say that "at L3 with `--merge-guard off`" the line is printed.
   - The test the task describes fails "when it names an L3 or `draft` condition".
   - The intended reading is: the ref-loading part has no gate, and the `off` line is L3-scoped. A naive substring check on "L3" or "draft" would reject the required text.
   - This is Medium because it needs a guess about which reading the implementer picks.
   - Fix: say "no `L3 only` or `draft`-only gate on the ref load" in both the body and the acceptance criterion.

2. **F2: Resume does not say where `applied_edits` and `target_sha` come from (Tasks 4, 8, 9).**
   - Resume rows 4 and 5 "re-enter `release_decision` with `push_completed=True`". That function also needs `applied_edits` and `target_sha`.
   - The plan never says where a resumed run gets them. Only the Wave 6 text of a live run has them.
   - If an implementer passes `applied_edits=0`, release row 7 fires with cause `no_edits` and skips the head check.
   - If an implementer passes the wrong `target_sha`, release row 9 holds and the PR stays draft with no release.
   - This is a requirement the document never states, so it is Medium. Name the source of both values (for example the held cycle's `push_initiated` record and its `fix_applied` events).

3. **F3: "once per cycle id" has no check on the cycle id in the core (Tasks 4, 8, 10, 11).**
   - `engage_decision` rows never compare `cycle_id` with the guard's stored `cycle_id`. Only phase `HELD` gives `NOOP(already_held)`.
   - A second engage call with the same id after phase `RELEASED` falls to row 11 and returns `ENGAGE`.
   - Task 11's `test_guard_engages_at_routed_finding_once_per_cycle` can only prove the `HELD` case.
   - This is Medium because the plan never states what should stop a repeat call. Either add a row, or say that the SKILL's single mint point is the only guard.
