**F2, Medium, missing requirement (held guard reused by a later cycle).**

- The error is on the safe side (the PR stays draft). It needs a held release followed by a crash, and the plan never says how the cycle id follows the draft.
- The repo's later implementation added a `REBIND` action (`cycle_rebound`) for this case, which supports the finding.
