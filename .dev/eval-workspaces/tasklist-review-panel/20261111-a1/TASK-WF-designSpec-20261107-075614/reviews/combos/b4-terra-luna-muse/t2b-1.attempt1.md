### F1. Medium: the Wave 0 test wording can be read more broadly than the required bullet

Grading check: An implementer who follows the stated text as written builds a Wave 0 bullet that both carries no L3 condition and states the at-L3 `--merge-guard off` behaviour, and that bullet is wrong only if the test is written to reject any L3 wording rather than an L3 gate on the resume load.

That sentence needs the extra assumption that the test writer chooses the broader reading. The acceptance wording itself narrows the check to `L3 only` or `draft` gate wording, so an implementer can satisfy both texts. This is therefore Medium, not blocking. The plan should say plainly that the test rejects gating wording for the resume load, not every mention of L3 in the bullet.

### F2. Medium: the byte-identical sentence checks rest on start text that is not, by itself, a full-sentence constant

Grading check: An implementer who follows the stated text as written builds a test comparing the live S5a and Wave 6 pre-push sentences against the literal start text recorded at the pre-build gate, and that test is wrong because a matching start cannot prove the rest of each sentence stayed byte-identical.

That outcome needs the assumption that the implementer does not also use the full pinned sentence constants already present in the existing tests, which the candidate points to indirectly. The plan should state explicitly that the later tests reuse the full pinned constants, with the recorded start text used only to locate them. Until then this is a missing precision, not a stated contradiction.

### F3. Minor: two task-local classification steps are narrower than the plan-wide classification rule

The plan-wide constraint covers new lines containing `gh pr`, `gh api`, or a git write verb. The script and reference tasks name only the `gh pr` and `gh api` cases when adding classification entries. The global constraint and the classification test run in those same tasks would catch a missed git-write line before the task could pass, so no wrong outcome follows from the stated text as a whole. Aligning the task-local wording with the global rule would remove a needless trap for a reader who works from one task alone.
