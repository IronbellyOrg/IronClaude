A check built from starts alone passes after the tail of either sentence is edited, so the acceptance criterion claims a guarantee its own recorded evidence cannot give.
- **F5. The status mapping does not settle a held guard reported with the mode off.** Task 3 imports the first-match status mapping, whose first rule is the off rule, while Task 4 requires a held guard with the mode off at ordinal 3 to be reported held, and Task 8 requires the held report in both modes. The candidate claims a status test for every phase and cause but never names the off-plus-held case, so two implementers can report the same draft-held pull request as `off` or as `held`.

Two file-writing tasks narrow the write-verb classification rule.** The constraints require a classification entry for every new line containing `gh pr`, `gh api` or a git write verb, but the closing steps of Task 8 and Task 12 only require entries for lines matching `gh pr` or `gh api`.
