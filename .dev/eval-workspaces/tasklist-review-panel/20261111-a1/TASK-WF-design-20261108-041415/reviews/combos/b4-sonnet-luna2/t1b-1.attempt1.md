**F1, Medium (missing requirement): a second test file pins the exact lines the plan rewrites.**
An implementer who follows the plan builds new `gh api -X POST` lines and rewritten `gh api` lines in `create.md`, `SKILL.md`, `labels.md` and `issue-worker-t3.md`. They then run only the Task 12 checks.

- **Evidence:** the live tree's allowlist already has entries for the new lines (`test_worker_contract.py` lines 3097 to 3161), so the real change needed this edit.

**F2, Medium (unpassable check on one reading): Task 10's acceptance line drops `user` as an allowed `gh api` path.**

- **The conflict:** Tasks 2 and 3 correctly say paths are `user` or `repos/<R>/...`.

**F3, Medium (unpassable check on one reading): Task 8 promises a new test for every one of Tasks 1 to 5, and Task 3 has none.**

- **Way out:** the implementer can add per-file assertions the plan does not list.

**F4, Medium (missing requirement): the read-back comparison is undefined.**

- **Related gap:** Task 12's UNVERIFIED list omits the read-back shape.
