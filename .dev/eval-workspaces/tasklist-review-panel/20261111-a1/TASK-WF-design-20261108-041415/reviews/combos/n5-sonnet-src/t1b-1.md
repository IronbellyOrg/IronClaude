- Constraints: the skill "writes exactly two things to a created issue besides the issue itself" (issue type and Complexity value).
- Task 2, Task 3 and Task 6 also keep the mode label (`--label`) and the pushback comment (`gh issue comment`, `E-POST-FAILED`).
- An implementer who reads the constraint as a hard cap on writes would drop the comment or the label, and that would be wrong. The tasks make the intent clear, so this is a guess between two readings.
- Fix: say "exactly two classification writes: type and Complexity value".

- The live test file has an extra `SKILL.md` test that is not in Task 8's list.

**F3 (Medium). A rejected `--type` kills the whole create, and no fallback is stated.**
- Wave 5 puts `--type` on the same `gh issue create` call as the title, body and label.
- Any error from that call, including one caused by the type, is STOP `E-CREATE-FAILED`, and no issue is made.
- The plan's "a failed type never stops the run" only applies after the issue exists.
- Before this change, create with a missing label still worked.
- The plan never says whether to retry once without `--type`.
- Evidence for Task 12's UNVERIFIED list: the installed `gh` 2.103.3 does list `--type name  Set the issue type by name`, so the flag exists here. Its error and silent-drop behaviour is still unrun.

**F4 (Medium). The field read-back has no stated way to decide "value absent".**
- Task 1 says to read back with `gh api repos/<R>/issues/<N>/issue-field-values` but never says what to compare.
- The POST sends the option name, while the live `labels.md` says a single-select read-back returns an option id and puts the name under `single_select_option.name`.
- An implementer who compares the returned `value` to "Medium" would report `not applied after create` on every successful write.
- The live `labels.md` has an extra "Field read-back shape" section that the plan does not ask for.
- That shape claim comes from the live file, not from a GitHub run.

- The T1 and T2 workers write `flags.md` from the template and stay unchanged.
