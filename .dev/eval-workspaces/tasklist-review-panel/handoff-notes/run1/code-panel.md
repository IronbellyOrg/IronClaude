## 4. Roles
- Reviewer: N reviewers from panel resolve, spawned by the coordinator (a session following commands/spec-panel.md Review Loop + prompts md). Output: report ending in findings-v1 block. In src there is no reviewer agent for this panel (reflect-reviewer.md is a different agent; see 5). Models launched per resolution `launch` field (anthropic-only: opus/sonnet/haiku/fable launcher strings, tier JSON :29; gateway: empty `launch`, :23).
- Merge/"judge": no LLM judge. `superclaude review merge` (merge_cmd.py) + ledger.merge_round (ledger.py:107-298) cluster findings by fingerprint (section + refs) / span overlap +-3 lines (findings.py:367-407), dedupe against existing rows, row.blocking = ANY member blocking (:187, :213-217), severity_max = max. confidence = "overlap" if >=2 distinct reviewers in one round else "single" (:86-90); confidence does not change verdict. So one reviewer's blocking=true on any finding is enough for FAIL (no quorum/majority/calibration).
- Calibrator: none in cli/review. (A blind finding-grader exists only in the stoprule experiment variant: agent list shows finding-grader; its script is not in src.) Calibration in reflect = confidence-calibrator agent (sc-reflect-protocol §11.3).
- Orchestrator/coordinator: the main session following spec-panel.md:256-268; keeps review count, prior-findings file, saved copy (spec-panel.md:261). Verdict/decision computed by script (ledger.py:93-96: PASS; REVISE if n<cap else ESCALATE; exit codes 0/10/11 in ledger_cmd.py:13, 109).
- Reviser: agent given the merged report's `Reviser brief` (ledger.py:22-26, 487-493, REVISER_RULES) + REVISE brief (prompts md:53); returns fixmap-v1. `ledger revise` (ledger_cmd.py:36-71 -> ledger.apply_revision :301-347) sets applied rows touched by a diff hunk to resolved_check; next merge clears resolved_check rows not re-found -> resolved, re-found -> regressed (:235-238, :254-258). `--old` must hash-match the last reviewed doc (:309-314). A rejected/untouched fix map entry leaves row open.
- Human: `ledger defer --lid --reason` marks deferred and drops it from brief_ids (ledger.py:350-360; ledger_cmd.py:74-91).
- Data contracts: findings-v1 (reviewer->merge), fixmap-v1 (reviser->ledger revise), review-ledger/1 JSON (ledger.py:17, rows: lid, fp, blocking, severity_max, category, confidence, status, anchor(2), span(2), refs, claim, members[], history[]), merged report text (render_merged_report ledger.py:408-494, ends `verdict: PASS|FAIL`; at ESCALATE omits Reviser brief :475-486), review-panel-resolution/1 (--resolution to merge only records model per reviewer, merge_cmd.py:73-83, ledger entries :141-149), review-capture/1.
