# FU-002 — Eliminate ReflexionPattern test pollution via REFLEXION_OUTPUT_DIR env-var override + autouse safety net

## Task Overview

Every `uv run pytest tests/` invocation currently re-creates pollution in `docs/mistakes/test_*-<today>.md` and appends entries to `docs/memory/solutions_learned.jsonl` because `ReflexionPattern.__init__` defaults `memory_dir` to `Path.cwd() / "docs" / "memory"` (reflexion.py:66) and unconditionally `mkdir`'s both that directory and the sibling `docs/mistakes/` (reflexion.py:73-74). The pollution stems from three distinct vectors: (1) the `reflexion_pattern` fixture in `src/superclaude/pytest_plugin.py:71-81` returns a bare `ReflexionPattern()`; (2) the `pytest_runtest_makereport` hook in `src/superclaude/pytest_plugin.py:160-184` constructs `ReflexionPattern()` for any failing `@pytest.mark.reflexion`-marked test; (3) 7 of 9 tests in `tests/unit/test_reflexion.py` (L17, L25, L39, L52, L73, L118, L165) call bare `ReflexionPattern()` inside the test body, bypassing the fixture entirely. The baseline pollution as of 2026-05-18 is 84 files in `docs/mistakes/` plus 588 polluted lines in `docs/memory/solutions_learned.jsonl`. This task lands the recommended Option C fix from `research/02-test-fixtures.md`: (a) add a `REFLEXION_OUTPUT_DIR` env-var resolver to `ReflexionPattern.__init__` with precedence `explicit memory_dir param > env var > cwd default` (preserving cwd behavior for external consumers); (b) upgrade the `reflexion_pattern` fixture to use `tmp_path` explicitly via `monkeypatch.setenv`; (c) add an autouse safety-net fixture in `tests/conftest.py` that sets `REFLEXION_OUTPUT_DIR` to `tmp_path / "docs" / "memory"` for every test (production-mirroring layout so `mistakes_dir = memory_dir.parent / "mistakes"` resolves to `tmp_path / "docs" / "mistakes"`); (d) cleanse the pre-existing 84-file + 588-line pollution baseline; (e) add a regression test that asserts `docs/mistakes/` file count and `docs/memory/solutions_learned.jsonl` size are unchanged after the test session (dynamic snapshots, not hard-coded numbers). Per-phase QA gates (PER_PHASE) and a unit-test validation phase are encoded per the BUILD_REQUEST.

## Key Objectives

The following objectives MUST be achieved by this task:

1. **Production env-var resolver landed:** `src/superclaude/pm_agent/reflexion.py` exposes a documented `REFLEXION_OUTPUT_DIR` override with precedence `memory_dir arg > env var > cwd default`; backward-compatible (purely additive).
2. **Pytest plugin fixture upgraded:** `src/superclaude/pytest_plugin.py:71-81` `reflexion_pattern` fixture uses `tmp_path` + `monkeypatch.setenv` to redirect writes; `pytest_runtest_makereport` hook coverage verified via the env-var resolver.
3. **Autouse conftest safety net installed:** `tests/conftest.py` has an autouse fixture that sets `REFLEXION_OUTPUT_DIR=<tmp_path>/docs/memory` for every test so any bare `ReflexionPattern()` construction (including the 7 in `tests/unit/test_reflexion.py`) redirects automatically. The `docs/memory` layout mirrors production so `mistakes_dir = memory_dir.parent / "mistakes"` resolves to `<tmp_path>/docs/mistakes`.
4. **Pre-existing pollution cleansed:** 84 polluted `docs/mistakes/` files removed, `docs/memory/solutions_learned.jsonl` restored to a clean baseline, both committed in Phase 1.
5. **Regression test landed:** A new test (e.g., `tests/unit/test_reflexion_pollution_guard.py`) using DYNAMIC pre/post snapshots (NOT hard-coded "84" or "588") asserts no new files appear in `docs/mistakes/` and no new bytes appear in `docs/memory/solutions_learned.jsonl` during the test session.
