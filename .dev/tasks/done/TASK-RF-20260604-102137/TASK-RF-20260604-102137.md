# Fix PASS_RECOVERED success predicates in sprint rerun and handoff paths

## Task Overview

This task fixes three same-class success-predicate couplings in the sprint CLI's rerun and handoff path so the success-family status `PASS_RECOVERED` is handled consistently with `TaskStatus.is_success`. The critical bug is in rerun merge-back: a rerun target that serializes as `"pass_recovered"` is currently judged as not passed by a literal `"pass"` comparison, causing merge-back to be skipped even though the model layer defines `PASS_RECOVERED` as successful.

Scope decision: fix all three verified coupling sites for completeness because they are the same class of defect and are independent of PR #124: (1) critical rerun merge-back predicate in `_rerun_targets_passed`, (2) high-severity handoff validated-success predicate while preserving the successful gate requirement, and (3) low-severity investigation-summary `last_pass` display predicate. The task must land on a new branch off `origin/master` in an isolated worktree, add RED→GREEN regression coverage for the critical and high-severity sites, run full sprint validation and CI ruff gates, and open a fork PR against `IronbellyOrg/IronClaude` only.

## Key Objectives

- Fix `_rerun_targets_passed` so raw serialized task statuses are coerced to `TaskStatus` and checked with `.is_success` in a None/invalid-safe way.
- Fix `is_validated_success` so serialized handoff statuses use the same success-family semantics while preserving the existing `GateOutcome(...).is_success` requirement.
- Fix the investigation-summary `last_pass` predicate so success-family enum values are displayed consistently.
- Add required RED→GREEN regression coverage in `tests/sprint/test_rerun_tasks.py` and `tests/sprint/test_resume_contract.py` for `PASS_RECOVERED` behavior.
- Validate with `uv run pytest tests/sprint/ -q`, `uv run ruff check src/ tests/`, and `uv run ruff format --check src/ tests/`; do not use any `python -m` command.
- Commit, push, and create a fork PR using the mandatory `gh pr create --repo IronbellyOrg/IronClaude --base master --head <branch>` shape.
