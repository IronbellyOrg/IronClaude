# Orca terminal observer, release 1 (`superclaude observe`, worker ledger and JSON snapshot)

Source: ./source.md
Goal: A read-only `superclaude observe` command in `src/superclaude/cli/observe/` that shows the Signal Bridge worker ledger built from `orca orchestration worker-list --json` at 160, 116 and 80 columns, with the "human questions not observed" notice, a plain-text record export, and a versioned additive-only JSON snapshot validated by a schema test, all covered by headless tests in `tests/observe/`.

## Task 2: Build the sanitizer `sanitize.py`

Depends on: Task 1

Create `src/superclaude/cli/observe/sanitize.py` and `tests/observe/test_sanitize.py`, following `ARCHITECTURE-SPINE.md` AD-9, `adapter-contract.md` section "Paging, errors, sanitizing" and tests T29 and T44 in `acceptance-tests.md`. Write it in this package: do not import `canvas.py`, and treat `ANSI_ESCAPE_RE` in `src/superclaude/cli/eval/pty_stream.py` as too weak. `sanitize(text, mode="line")` keeps printable characters only. It removes CSI and OSC sequences (7-bit and 8-bit introducers; OSC ended by BEL or ST or unterminated through the end of the string), DCS, SOS, PM and APC strings, any other ESC plus the next character, the C1 range U+0080 to U+009F (including the 8-bit `\x9b`), C0 controls and DEL, and Unicode `Cf` format characters (bidi controls such as U+202E included). Line mode replaces each newline with one space; block mode keeps newlines (used only for `stage.detail`, `stage.activity` and stderr in the inspector). The function always returns `str`.

## Task 4: Build the parser and merge `parse.py`

Depends on: Task 2

Create `src/superclaude/cli/observe/parse.py` and `tests/observe/test_parse.py`, following `ARCHITECTURE-SPINE.md` AD-7 and AD-19 and the "Parsing" and "Identity, duplicates, order" sections of `adapter-contract.md`. Define the `UNKNOWN` sentinel (one object, not `None`, `0`, `False` or `""`), frozen dataclasses `Row` (which also has a `fixture_frozen` boolean, default False, set only by the fixture loader in Task 5 and never by `parse_page`), `Snapshot` and `Coverage`, `parse_page(obj, namespace, cycle, source_rank_base)` and the pure `merge(previous, pages, stopped_by_cap, stopped_by_error, clock)`. Strict envelope: `result` must be an object, `result.workers` a list, `result.page.hasMore` a bool (the string `"false"` fails, JSON null counts as absent), otherwise a shape error and the previous `Snapshot` stays. Optional: `result.scope`, `result.page.total` (a non-negative integer, else `UNKNOWN`), `result.counts` (passed through, never summed) and `result.warnings` (sanitized). Rows are read field by field with absent-tolerant access over the keys listed in `adapter-contract.md` section 3 and `rendering-rules.md` inspector list: `dispatchId`, `taskId`, `runId`, `workerState`, `dispatchStatus`, `terminalState`, `resource.{id, ownershipState, releaseState, worktreeId, ownerDispatchId, originDispatchId, recoveryAttemptCount}`, `projection.{outcome, role, provider.id, host.id, host.kind, workspace.id, workspace.kind, stage.worker, stage.dispatch, stage.activity, stage.detail, nextAction.kind, liveness.verdict, liveness.source, liveness.observedAt, evidence.durable, evidence.liveStatus, evidence.lastObservedAt}`; a missing key or JSON null becomes `UNKNOWN`; every string passes `sanitize` (block mode only for `stage.detail` and `stage.activity`); unexpected keys are counted per row. A non-object row is counted as malformed and skipped. Row identity is `(namespace, dispatchId)`; a row whose `dispatchId` is absent, JSON null, empty or whitespace-only (the `UNKNOWN` sentinel) gets the per-cycle identity `(namespace, UNKNOWN, cycle, source_rank)`, carries the flag `identity unknown`, is never deduplicated or matched across cycles, is not counted as a duplicate and is counted separately (`adapter-contract.md` section "Identity, duplicates, order"); the next cycle that is not PARTIAL replaces the previous cycle's such rows, while a PARTIAL cycle keeps them (`ARCHITECTURE-SPINE.md` AD-7). `merge` keeps a row set across pages and cycles: duplicates within a cycle are dropped and counted; the newer `liveness.observedAt` (compared only with the same field from the other copy, likewise `evidence.lastObservedAt`) wins; an absent or unparsable timestamp, or no common timestamp field, makes the newer cycle win and sets the `order unknown` flag; a backward timestamp sets `conflict (time went back)`; equal timestamps let the newer cycle win; a previous row with a real identity that is not returned this cycle stays with `reobserved=False` and its last-seen cycle; `Coverage` records the per-page totals, any empty-page index, `has_more_at_stop`, the duplicate count and whether `total` changed during the read.

Acceptance criteria:
- `uv run pytest tests/observe/test_parse.py -v` passes.
- T32 (parse half): removing `result`, `result.workers` or `result.page.hasMore`, or giving `workers` a non-list or `hasMore` the string `"false"` or null, yields a shape error and keeps the previous snapshot; removing `result.scope` or `page.total` yields `UNKNOWN` for that field only; removing an inner `projection.*` key yields `UNKNOWN` in that row, not an error.
- T22 and T39: an older `observedAt` never overwrites a newer one; a row with both timestamps missing is flagged `order unknown`; a backward timestamp is flagged `conflict (time went back)`; the duplicate count is exact; the same `dispatchId` under two different namespaces stays two rows.
- A test shows a row with no `dispatchId` keeps a per-cycle identity, is never merged with another such row and is not counted as a duplicate; the same holds for an empty and a whitespace-only `dispatchId`, each such row carries `identity unknown`, and two of them in one cycle stay two rows.
- A test shows a JSON null and an absent key both give `UNKNOWN`, and that `UNKNOWN`, `None`, `0`, `False` and `""` are five distinct values.
- A test shows a row seen in cycle 1 and absent in cycle 2 stays with `reobserved=False`.
- A test shows anonymous rows from cycle 1 are replaced by cycle 2's anonymous rows when cycle 2 is not PARTIAL and are kept when it is PARTIAL, and that rows with a real identity are unaffected either way.
- A test shows extra unknown keys are counted and their names and values do not appear in the parsed row text.

## Task 7: Build the collector `collector.py`

Depends on: Task 5, Task 6

Create `src/superclaude/cli/observe/collector.py` and `tests/observe/test_collector.py`, following `ARCHITECTURE-SPINE.md` AD-6 and AD-20 and the "Bounds per cycle" section of `adapter-contract.md`. Define the frozen `CycleResult` (cycle number, `mode` `fixture` or `live`, fixture variant, last `SourceResult` code, the merged `Snapshot` and `Coverage`, `last_success_mono`, `last_success_wall`, `source.namespace`, and no STALE flag), the `CycleSource` protocol with `FixtureSource(variant)` here (replays the fixture cycles in order and repeats the last; a `{"fail": code}` cycle becomes a failed `SourceResult`) and `LiveSource` from Task 6, and `Collector(source, clock)` with `start()` (one daemon thread waiting on a `threading.Event`, the shape of `OutputMonitor` in `src/superclaude/cli/sprint/monitor.py`), `latest()`, `run_once()` and `stop()`.
