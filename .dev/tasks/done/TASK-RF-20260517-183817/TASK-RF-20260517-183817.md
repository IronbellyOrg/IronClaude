# Implement hook-sync-and-matcher-fix release: verify-sync hook coverage + auggie-mcp matcher gap + cross-consistency assertion

## Task Overview

This task implements the `hook-sync-and-matcher-fix` release end-to-end against master HEAD `516bb46` (verified 2026-05-17). It addresses two confirmed bugs on master plus ships a structural prevention layer and a new pytest harness — bundled as a single PR because each part's acceptance test is another part's catch.

**Part 1 (verify-sync coverage)** extends `make verify-sync` with two new sections — `=== Hooks ===` (bidirectional src↔.claude check for `*.sh` files in `src/superclaude/hooks/scripts/` vs `.claude/hooks/`) and `=== Installer Registration ===` (asserts every `src/`-hook script appears in `_FRESHNESS_SCRIPTS` from `install_hooks.py:43-55`). This closes the silent end-user-install divergence failure mode demonstrated by the live orphan `.claude/hooks/auggie-bash-gate.sh` (61 LOC, no src counterpart).

**Part 2 (matcher gap fix)** adds `mcp__auggie-mcp__` as a middle alternative in three places: the JSON regex matcher at `src/superclaude/hooks/hooks.json:60`, the shell glob case body at `src/superclaude/hooks/scripts/auggie-flag-clear.sh:22`, and the file-header comment at line 2 of the same .sh (rewritten as a 2-line form enumerating all three prefixes). Independent grep verification: `grep -rn "mcp__auggie-mcp__" src/superclaude/hooks/` → **0** hits on master.

**Part 3 (cross-consistency)** adds a `=== Hooks Cross-Consistency ===` Makefile section asserting that the auggie-prefix set in `hooks.json:60` matcher equals the auggie-prefix set in `auggie-flag-clear.sh` case body (modulo regex `.*` vs glob `*` normalization). This is the structural prevention layer that justifies choosing Option 1 (minimal two-file patch) over Option 2 (externalized prefix list) in the post-adversarial-debate design.

**Tests** add a new `tests/cli/test_verify_sync_hooks.py` (~80-120 LOC) covering scenarios V1–V7 from release-spec §9 using a `synced_tree(tmp_path)` fixture and a `_run_verify_sync` subprocess helper that prepends `PYTHONPATH=<tmp_path>/src` to make `uv run python -c 'from superclaude.cli.install_hooks...'` import the mutated module (empirically resolved in research 03).
