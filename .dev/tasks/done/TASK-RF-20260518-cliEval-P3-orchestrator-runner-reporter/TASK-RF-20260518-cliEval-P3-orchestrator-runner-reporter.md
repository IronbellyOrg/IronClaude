# cliEval P3 — Orchestrator + Runner + Reporter + `eval run` Subcommand

## Task Overview

This task implements **Phase 3 of the cliEval release** — the heaviest phase, where the eval harness becomes *alive*. It builds the parallel scheduler (`orchestrator.py`), the per-eval lifecycle driver (`runner.py`), the result-aggregation reporter (`reporter.py`), the `eval run --suite SUITE` Click subcommand, and a minimal 1-eval stub manifest used as the smoke-test gate. The acceptance criterion for this phase REQUIRES a working end-to-end run that spawns a **real Claude Code subprocess** in an isolated HOME, drives it through the lifecycle, writes structured artifacts to `.dev/eval-runs/<ISO>/<run-id>/`, and exits 0 on PASS. This proves the entire harness architecture is viable before E1-E15 are implemented.

The scope is ~440 LOC across 5 production files and 4 test files. The orchestrator mirrors `src/superclaude/cli/prd/executor.py:774-802`'s `ThreadPoolExecutor` + `as_completed` pattern. The reporter mirrors `src/superclaude/cli/sprint/executor.py:190-335`'s `AggregatedPhaseReport.to_yaml`/`to_markdown` shape, swapping "phase" for "eval" and adding `to_json`/`to_junit`. The runner composes `HomeIsolation` (from P1) with the `PtyDriver` (from P1) and the `Expect.*` DSL (from P2). The `eval run` Click subcommand wires it all together with the flag surface defined in design-spec §4. The stub manifest is intentionally minimal (1 eval, no MCP, no hooks-specific logic) — its job is to prove bits move end-to-end. **CRITICAL:** the smoke test (AC-P3.1) is executed via the actual CLI command `uv run superclaude eval run --suite stub`, NOT via pytest fixtures — it must spawn a real `claude` subprocess.

## Key Objectives

The following objectives MUST be achieved by this task:

1. **Orchestrator (~120 LOC):** Build `src/superclaude/cli/eval/orchestrator.py` containing the `RunOrchestrator` class with a `ThreadPoolExecutor(max_workers=N)` that schedules `EvalSpec` objects, submits them to `runner.run()`, collects results via `as_completed`, enforces per-eval timeouts, aggregates failures, and handles SIGINT/SIGTERM cleanup.
2. **Runner (~150 LOC):** Build `src/superclaude/cli/eval/runner.py` containing the `EvalRunner` class implementing the per-eval lifecycle from design-spec §6: build `HomeIsolation` → spawn `PtyDriver` → inject prompts → wait for idle → apply `Expect.*` assertions → capture TTY → teardown.
3. **Reporter (~120 LOC):** Build `src/superclaude/cli/eval/reporter.py` containing the `AggregatedRunReport` dataclass with `to_markdown()`, `to_json()`, `to_junit()` methods that write the full artifact tree (`summary.md`, `summary.json`, `manifest.snapshot.yaml`, `evals/<id>/{result.json, stdout.log, stderr.log, expect-trace.md}`) under `.dev/eval-runs/<ISO>/<run-id>/`.
4. **`eval run` subcommand (~50 LOC):** Extend `src/superclaude/cli/eval/commands.py` to add the `run` subcommand with the full flag surface from design-spec §4: `--suite`, `--parallel`, `--eval`, `--no-mcp`, `--no-pty`, `--output-dir`, `--keep-home`, `--timeout-mult`, `--json`, `--verbose`.
5. **Stub suite manifest (~20 LOC):** Create `src/superclaude/cli/eval/suites/stub.yaml` containing a single minimal eval (no MCP, no hooks-specific assertions — just proves end-to-end bit movement) used by the smoke test.
6. **Test coverage (~250 LOC across 4 files):** Unit tests for orchestrator (`tests/cli/test_eval/test_orchestrator.py`), runner (`tests/cli/test_eval/test_runner.py`), reporter (`tests/cli/test_eval/test_reporter.py`), plus the **real-subprocess smoke test** (`tests/cli/test_eval/test_eval_run_smoke.py`) gated with `pytestmark = [skipif(not _HAS_CLAUDE_BINARY)]`.
7. **End-to-end smoke validation (AC-P3.1):** Invoke `uv run superclaude eval run --suite stub` AS the smoke test (not via pytest fixtures), confirm a real Claude Code subprocess is spawned, the 1 stub eval PASSes, artifacts are written, and exit code is 0.
8. **All 12 acceptance criteria met:** AC-P3.1 through AC-P3.12 from the BUILD_REQUEST are addressed by checklist items in this task.
9. **`make verify-sync` still EXIT=0 (AC-P3.11):** Source-of-truth sync invariant preserved after all changes land in `src/superclaude/cli/eval/`.
