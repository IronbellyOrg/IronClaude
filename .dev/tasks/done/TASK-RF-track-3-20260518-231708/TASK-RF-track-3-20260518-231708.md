# FU-003 — PRD CLI Default Output to `.dev/eval-workspaces/` (config.py:100)

## Task Overview

Phase 1 of TASK-RF-20260518-181333 surfaced stray repo-root directories `prd-test-product/` and `prd-dry-run-test/` after real `superclaude prd run` invocations. Phase 3 added `.gitignore` guards as a retroactive safety net, but the source-of-truth defect was never patched. Track-3 research (T3-R1 hypothesis-overturn, verified independently by the T3 QA gate) established that the original FU-003 stub hypothesis — that `tests/cli/prd/test_prompts.py` was the culprit — is wrong. The test harness at L44 already uses `tmp_path / "prd-test-product"` correctly. The actual root cause is `src/superclaude/cli/prd/config.py:100`:

```python
output_path = Path(output).resolve() if output else Path(".").resolve()
```

Combined with `task_dir_name = f"prd-{product_slug}"` (line 107) and `task_dir = output_path / task_dir_name` (line 108), running `superclaude prd run "..." --product "test product"` from the repo root creates `<repo-root>/prd-test-product/`. This task patches `config.py` to default to `.dev/eval-workspaces/` when `.dev/` exists (falling back to `Path(".").resolve()` only when no sandbox is available, preserving current behavior outside repos), adds a regression test, and applies a 1-line defense-in-depth extension to the existing `reject-workspace-writes.sh` PreToolUse hook (Option A per research recommendation — zero registration delta).

## Key Objectives

1. Patch `src/superclaude/cli/prd/config.py:100` so `output=None` resolves to `<repo>/.dev/eval-workspaces/` when `.dev/` exists, falling back to `Path(".").resolve()` only when no sandbox is available.
2. Add a regression test at `tests/cli/prd/test_config.py` (new file) that exercises the new default and asserts no `prd-<slug>/` is created at the simulated repo root.
3. Apply Option A defense-in-depth: extend `src/superclaude/hooks/scripts/reject-workspace-writes.sh` with one additional regex branch matching repo-root `prd-*/` writes, then `make sync-dev` to refresh the `.claude/` mirror.
4. Validate via `uv run ruff check src/superclaude/cli/prd/ tests/`, `uv run pytest tests/cli/prd/`, and `make verify-sync` (all 6 sections green, Section 5 `=== Installer Registration ===` specifically asserted).
