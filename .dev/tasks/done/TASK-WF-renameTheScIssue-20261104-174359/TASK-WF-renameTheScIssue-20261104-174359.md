# Rename the /sc:issue claim summary file to issue-summary.md and pin worker file names against the subagent report-file block

Source: ./source.md
Goal: No file name that an /sc:issue worker is told to write starts with REPORT, SUMMARY, FINDINGS or ANALYSIS (case-insensitive, `.md`), so Claude Code's subagent Write block (error "Subagents should return findings as text, not write report files.") can no longer refuse claim Wave 4; the claim summary is `.dev/issues/<N>/issue-summary.md` everywhere, `/sc:analyze` reports under `<D>/analysis/` are named like `analysis/analyze-<scope>.md`, and a deterministic test pins both.

## Constraints

- No behaviour change other than the file names and the corrected explanation of why they are chosen. Do not touch the minor notes m1 to m7 or N1 to N3.
- Edit only `src/superclaude/...`, `tests/...` and `docs/...` files named in a task; never edit or `git add` anything under `.claude/` (it is regenerated by `make sync-dev`). Leave `.dev/issues/` alone.
- Do not run `/sc:issue --claim` or `--create`, do not spawn the issue-worker agents, make no gh writes, commits or pushes. UV only for Python.
- `.dev/tasks/` is always staged (`git add .dev/tasks`), this package and its `artifacts/` included. Staging is not committing.
- The tool-input paragraph text below is the single exact text used in all three agent files and in `tests/skills/test_issue_worker_agents.py` (`_TOOL_INPUT_PARAGRAPH`); Task 2 and Task 3 use it verbatim:

  "The files you write under `.dev/issues/` (`scout.md`, `accuracy-check.md`, `issue-summary.md`, the reports under `analysis/` such as `analysis/analyze-<scope>.md`, `flags.md`, `flags-t1.md`, `issue-body.md`, `draft-notes.md`) are input files for the orchestrator's next tool calls (`gh --body-file` posts and `/sc:recommend`), not report files. Claude Code refuses a subagent's Write of any `.md` file whose name starts with REPORT, SUMMARY, FINDINGS or ANALYSIS (in any letter case), which is why none of these names starts with those words. Writing every file your job names with the Write tool is mandatory; returning its content as text instead is a failure (`E-WORKER-NO-OUTPUT`)."
