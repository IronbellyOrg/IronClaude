# Build sc-reflect-protocol Skill (Rebuild /sc:reflect on Tiered Protocol)

## Task Overview

This task rebuilds the legacy `/sc:reflect` command surface (currently 111 lines, built on Serena's `think_about_*` triad — the same representational stack that produces the work as the auditor of the work, structurally biased per Mehta Towards-AI Mar-2026) into a tiered reflect protocol skill. The new skill introduces structural mechanisms single-model self-reflection cannot supply: heterogeneous reviewer ensemble (Tier 2), blind calibration via confidence-calibrator with disjoint-set rule, mandatory evidence-validator gate, 4-category deviation taxonomy, and Wave 7 promotion mutation.
