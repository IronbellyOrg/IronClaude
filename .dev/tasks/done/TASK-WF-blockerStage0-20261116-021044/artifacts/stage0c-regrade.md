## What was measured

Three blind agents each graded all 318 findings of the scored table (`04-historical/master-table.md`, read through the blind copies `blind-table-1.md`, `blind-table-2.md`, `blind-table-3.md`, which show ID, category, description and context only) twice: once applying today's rule text (lines 221 to 231 of `src/superclaude/output-styles/pragmatic.md`, copied to `./artifacts/stage0c-work/in/rule-A.txt`, called text A) and once applying the digest of spec section 4.1 (REQ-01, copied to `./artifacts/stage0c-work/in/rule-B.txt`, text B). In this file A is called the old text and B the new text. 318 findings x 3 agents x 2 texts = 1908 grades, all in `./artifacts/stage0c-grades.jsonl` with agent id, text version and order position. The panel consensus in `05-scoring/consensus.md` (three blind scorers, a finding is a blocker at mean 4.0 or higher) is the reference: it calls 82 of the 318 blockers.

**The table holds only findings that were filed as blocking** (all 318 rows came from reviews that labelled them blocking). So the matrix below can say how many of those a rule text still calls blocking; it cannot say anything about findings that were never filed as blocking.

### How the graders were instructed

Each grader was told to apply only the rule text it was given for each grade, to ignore every other rule or habit about grading review findings in its context (system instructions, style instructions, memory), to judge from the description and context as written, to copy a verbatim phrase of the rule text that decided each grade into a `quote` field, and to read only the two rule files and its own table copy. The graders were not told which text is old and which is new, nor that the table holds only blocking-filed findings.

## Plain reading of the result

- Under the old text the majority of the three agents graded 310 of 318 findings blocking; under the new text 310 of 318. The panel calls 82 of 318 blockers.
- Only 2 findings moved from blocking to not blocking and 2 moved the other way (majority grade). The new text, as these graders applied it, did not cut the blocking share of this table.
- Both texts catch 82 of the 82 panel blockers under the majority grade (recall 1.000 old, 1.000 new) at the price of 228 (old) and 228 (new) findings the panel does not call blockers; agreement with the panel is 0.283 old and 0.283 new.
- So this regrade shows no measurable effect of the new text on this table. It does not show why. Possible reasons, none tested here: the old rule in each grader's context (see the confound section); the table holds only findings filed as blocking and each description states a consequence, which both texts count; graders read each description as true and so find a consequence in almost every row. The result is reported as it came out.

## The old-rule injection confound

Every subagent in this session receives the installed output style, which holds today's rule, through the SubagentStart hook `pragmatic-subagent.js` (registered in `src/superclaude/hooks/hooks.json`; the installed copy `~/.claude/hooks/pragmatic-subagent.js` adds the style text to every subagent unconditionally, with no exemption by agent type). Checked in this run: that script is 22 lines and has no condition, and the Agent tool has no setting that skips the hook, so no way to spawn a grader without the injection was found; the graders were spawned with it. So the new-text arm was graded with the old rule still in each grader's context. The graders were told to apply only the rule text given and to ignore any other review-grading rule; their own reports on whether another definition was in their context are in the agents table above. The confound pulls the new-text grades toward the old-text grades, so the movement counts above are a lower bound on the change, not an estimate of it.

## What this regrade cannot show

- **Lower bound, and no measure of discovery.** The regrade grades findings that were supplied to it. It cannot tell whether a reviewer working under the new text would have found a defect at all, which is the risk that a stricter reading of blocking hides real defects. RT1 (spec section 13.2), the owner's read of the first five runs' Medium lists, and one small planted-defect check run as part of the live RT1 audit after the switch cover what it cannot.
- **The table holds only findings filed as blocking.** Findings that were never filed as blocking, or never raised, are absent, so no false-negative rate can be computed from it (selection bias).
- **Circular labels.** The panel consensus (three blind scorers, ponytail, scoring the same descriptions) is the reference, and it is not an independent ground truth; it was produced by the same kind of model reading the same text as the graders here.
- **Stand-in judge.** In the 5-run test, `08-test/results.md`, the stand-in judge agreed with the panel on 58.5 percent of the 318 findings (majority of five runs; Cohen's kappa 0.27), and the questions S, W and D separated at an area under the curve of 0.73 to 0.75. This regrade grades with a rule text, not with that judge, and nothing here reports a classifier probability.
- **Model agents, not people.** The graders are model agents of this session, not independent human graders, and they carry the old-rule injection above.
- **How grade lines were written.** Grader g2 reported that for most chunks it wrote the grade lines with a shell loop over its list of ids instead of one hand-written block per row (its own report to the executor). Its grades still vary by row (4 not blocking under A, 7 under B) and every quote is a verbatim substring of the rule text, but a loop means the grade for each row was decided first and typed out afterwards; graders g1 and g3 reported nothing on how they wrote their lines.
- **Near-uniform grades.** All three graders called almost every finding blocking under both texts, so the matrix and the movement counts rest on very few findings that any grader called not blocking; they say little about how the two texts differ on findings that are not obviously blocking.
- **Paired design.** Each agent graded each finding twice in one session, so its second grade could be influenced by its first; the order of the two texts was alternated by chunk to spread that effect, and the order table above shows the result.

This result does not measure a classifier and no number in it should be read as evidence that one works.
