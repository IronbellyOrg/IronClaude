# Cosmos-compatible PR submit monitor

Source: ./source.md
Goal: Reliably classify Cosmos reviews for the current commit and dispatch only selected unresolved findings through existing remediation gates.

## Constraints

- Read source sections 1–7 and acceptance cases A1–A16. Work only in this checkout on feature/cosmos-pr-submit; no commits, pushes, PRs, or GitHub comments.
- Preserve the existing FSM, four classification states, ordinal gates, round limits, timeout, severity re-grading, evidence validation, legacy decline behavior, both configured bot identities, and auggie review trigger. No dependencies or provider framework.
- Edit canonical src files, not generated .claude mirrors. Delivery code/tests/docs stay repo-relative. Task evidence belongs in ./artifacts/. Use UV for Python.
- Cosmos marker is observed wire evidence, not a stable public API. Partial, malformed, wrong-head, unsupported or unattributed completion must not become clean or automatic remediation.
