# Add `--revagent <model>` to /sc:auggie-review (rev 3)

Source: ./source.md
Goal: `/sc:auggie-review --revagent opus|sonnet|haiku|fable` passes the chosen model on the internal `auggie-reviewer` spawn and any re-spawn, STOPs on a missing or unsupported value (for example `connect`) before environment checks or any expensive work, records the choice in the audit trail, and leaves behavior unchanged when the flag is omitted.

## Constraints

- Source of truth is `src/superclaude/`; `.claude/` mirrors are regenerated by `make sync-dev` and never staged (source 5, RF8).
- Accepted values are exactly the native Agent tool `model` enum: `opus`, `sonnet`, `haiku`, `fable` (source 3, 4.1). No full model IDs, no backend aliases, no silent substitution, no fallback to default on a bad value (source 4.2).
- `--revagent` never reaches the `auggie` CLI, never reaches the Wave 2 step 4 per-persona Auggie calls, and never changes `--auggie-model` or `AUGGIE_MODEL` (source 4.3, RF2).
- `src/superclaude/agents/auggie-reviewer.md` stays unchanged; no model-routing framework, new transport, or unrelated cleanup (source 5, 7).
- Baseline is `origin/master`; do not import `feat/litellm-gateway-tool-names` changes (source header).
- Committed non-`.dev/` paths are exactly `src/superclaude/commands/auggie-review.md`, `src/superclaude/skills/sc-auggie-review-protocol/SKILL.md`, and `tests/commands/test_auggie_review_revagent.py` (RF8, RF9).
