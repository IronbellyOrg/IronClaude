## Task Overview

This task delivers PR3 of the 5-PR CI rot cleanup. Unlike PR1 and PR2, the lint rules in scope here are **not auto-fixable** by ruff: each violation requires human judgment about a replacement identifier and a per-rename shadowing inspection. The expected scope is approximately 36 manual edits across four rule classes:

- **E741** (ambiguous variable name, ~11 occurrences) — primarily the short identifier `l` used as shorthand for "level" in `src/superclaude/cli/audit/budget.py` (three confirmed occurrences at lines 146, 294, 350) plus additional locations enumerated during discovery.
- **N806** (variable in function should be lowercase, ~20 occurrences) — `UPPERCASE` locals that should be `lowercase_with_underscores`.
- **N811** (constant imported as non-constant, ~3 occurrences) — `from X import lowercase as UPPERCASE` aliases that should drop the alias or use lowercase.
- **F811** (redefinition of unused name, ~2 occurrences) — requires deleting the earlier dead binding, not renaming.

**Hybrid (mixed) granularity pattern.** The checklist uses phase-level granularity for Preparation, Discovery, Verify, Commit, and PR phases, but **per-occurrence (or per-file batch) granularity for the Execute phase**, because each rename needs an independent shadowing check and a per-rename test-suite run to satisfy NFR2 ("verify via test suite after each rename"). The Execute phase items are not enumerated upfront — they are produced **dynamically** by reading the rename-inventory file written in Phase 2 (Discovery) and expanding one Execute item per `(file, current_identifier, proposed_identifier)` tuple from that inventory.

**Escalation gate (NFR4 token budget).** If discovery reveals **>40 total renames**, the task halts before Execute and surfaces the count to the user. >40 renames exceeds the NFR4 per-PR token budget and requires splitting N806/N811/F811 into a separate PR (PR3a/PR3b). Default disposition is no split (all four rules are "manual rename mechanical class" and bundling reduces overhead), but the threshold is enforced.
