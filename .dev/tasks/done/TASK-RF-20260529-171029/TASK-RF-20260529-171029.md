# Layer 5 H3 Subsection-Context Detector for obligation_scanner.py

## Task Overview

Add a fifth meta-context demotion layer (Layer 5) to `src/superclaude/cli/roadmap/obligation_scanner.py` that detects when a scaffold-term finding sits inside a per-milestone H3 subsection whose heading begins with "Risk Assessment", "Integration Points", "Milestone Dependencies", or "Open Questions" — and demotes that finding's severity from HIGH to MEDIUM, guarded by a discharge-intent check that mirrors Layer 4's guard.

The detector uses a pre-scan **line → containing-H3-text** index built from the raw markdown (`_build_h3_index`) because the scanner's existing phase splitter (`_split_into_phases`) silently absorbs H3 subsections into their enclosing H2 milestone chunk — research 05 §0 empirically falsifies the alternative `phase_id`-keyed design proposed in research 01. Layer 5 wires as a new cascade branch in `scan_obligations` immediately after the existing Layer 2 elif (line 337), keyed off the per-line H3 lookup, with `_is_discharge_intent_line(context_line)` preserving genuine obligations like "stub needs replacement" even inside a Risk Assessment subsection.

Re-verification on `.dev/releases/Current/MultiModelSwarm/roadmap.md` must drive the standalone-scanner `undischarged_count` from 8 (post-Fix-1+Fix-3 baseline) to 0 across the six known FP lines (145, 149, 278, 425, 437, 474).
