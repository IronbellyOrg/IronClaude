# Remediate reflect follow-ups F2, F4, F5 (PRD pipeline hardening)

## Task Overview

This task remediates the three optional, non-gating follow-up findings (F2, F4, F5) surfaced by a Tier-2 deep `/sc:reflect` audit of the PRD-pipeline two-atom crash fix. The originally-reported crash is ALREADY fixed (Atoms 1+2 plus F1); these three items are durability hardening for the just-shipped fix and are all low-risk.

**F2 (the only change touching `src/`)** closes a residual same-crash-class robustness gap: `_load_json_required` in `prompts.py` guards only `path.is_file()` and then calls the unguarded `_load_json`, so a present-but-malformed `parsed-request.json` raises an uncaught `json.JSONDecodeError` that escapes `run()` and crashes the CLI — exactly the crash-class the fix closed for MISSING files. The recommended fix adds a sibling `MalformedArtifactError(MissingArtifactError)` raised on a parse failure, which is caught automatically by the existing call-site `except MissingArtifactError` (subclass catch), converting the crash into the same graceful HALT path. **F4** prevents silent drift: the five hardcoded producer-step strings at the REQUIRED-read conversion sites in `prompts.py` duplicate the canonical `_STEP_ARTIFACT_FILES` map in `executor.py` with nothing pinning them in sync; a consistency-guard test closes that gap without runtime coupling (importing the map into `prompts.py` risks a circular import). **F5** strengthens a weak regression guard: `test_e2e_standard_tier_validation_fail_does_not_halt` does not assert scope-discovery's recorded status is `VALIDATION_FAIL`, so it could pass for the wrong reason.

All file:line citations used by this task were re-verified fresh against live source on 2026-06-08. UV is mandatory for all Python operations; source-of-truth edits live in `src/superclaude/cli/prd/` (package code — no `.claude/` sync impact).
