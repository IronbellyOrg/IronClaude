# Fix Reflect Wrapper Marker Leakage Into Verification Subprocess

## Task Overview

This task fixes the reflect-wrapper marker-leakage bug where `superclaude reflect run --fix` correctly exports `SUPERCLAUDE_REFLECT_WRAPPER_ACTIVE=1` into the reflect-audit subprocess for nested-gate suppression, but that marker is inherited by the reflect skill's §6.1 step 5.5 verification-triangle pytest subprocess. When those verification tests invoke the reflect CLI, they hit the `commands.py` recursion-breaker guard and produce false degraded/null-convergence outcomes despite a clean audit.

The fix is deliberately narrow: update `src/superclaude/skills/sc-reflect-protocol/SKILL.md` §6.1.1 so non-mutating verification commands run as `timeout <N> env -u SUPERCLAUDE_REFLECT_WRAPPER_ACTIVE <validated base command>`, while preserving marker propagation for reflect audits and corrective `/task` apply subprocesses. This task also adds a regression source-contract test, runs source-of-truth sync and CI-parity validation, and uses the final POST reflect gate as the end-to-end dogfood proof.

## Key Objectives

1. **Strip the wrapper marker only from verification subprocesses:** Add §6.1.1 control (i) and clarify control (b) so the verb allowlist checks the validated base command rather than fixed `timeout`/`env` wrappers.
2. **Preserve nested-gate suppression semantics:** Do not edit `src/superclaude/cli/reflect/runner.py` or `src/superclaude/cli/reflect/commands.py`; keep the marker set for reflect audit and corrective `/task` children.
3. **Document the contract carve-out:** Add a narrow §3.2 carve-out to the sibling reflect-wrapper contract, or explicitly log a cross-worktree deferral if that edit is unsafe in the current execution context.
4. **Add and run regression coverage:** Add `tests/cli/reflect/test_marker_suppression.py` coverage asserting §6.1.1 contains `env -u SUPERCLAUDE_REFLECT_WRAPPER_ACTIVE`, then run the canonical targeted pytest command.
5. **Validate source-of-truth sync and CI parity:** Run `make sync-dev`, `make verify-sync`, `uv run ruff format --check src/ tests/`, and `uv run ruff check src/ tests/` with green results captured to handoff files.
6. **Dogfood the fixed POST gate:** Run the final reflect wrapper gate after the fix and validation so the task proves the original exit-11/degraded failure no longer reproduces.
