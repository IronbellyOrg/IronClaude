# task-builder `--reflect auto|1|2` — collapse the POST reflect gate into a single 3-mode dial

## Task Overview

This task refactors the **POST reflect gate** in the task-builder skill. Today the skill emits ONE fixed POST reflect item — a manual fresh-session `/sc:reflect --mode post --remediate` HALT item (the penultimate item of the final phase, `SKILL.md:1994-1999`) — for every generated tasklist, from a 4-item typo fix to a 12-subsystem refactor. The driving spec replaces that one-size-fits-all item with a single ordinal **dial** `--reflect <none|0|1|2|auto>` (**default 2**) that picks the POST item's *form* and *rigor* deterministically at build time.

The dial **subsumes** two pre-existing knobs as deprecated read-time aliases: the legacy `POST_REFLECT_GATE: ENABLED|DISABLED` (`SKILL.md:853`) and the sibling wrapper task's proposed `POST_REFLECT_MODE: wrapper|halt`. The resolved effective mode `m` is computed **exactly once**, at A.9 (the single-producer guarantee, FR-9), via a frozen 3-term `auto` predicate that **reuses the existing TCS machinery** (`SKILL.md:2114-2156`) plus a build-time wrapper-availability probe `W`, and is recorded in **one** frontmatter field `reflect_post_mode:`. Five emitted-item forms: `none` (no item), `1` (inline same-session `/sc:reflect --mode post --depth standard`, audit-only), `2` (Bash shell-out to `superclaude reflect run {TASK_FILE}`), and `halt`/`2-degraded-halt` (the **byte-identical** legacy manual item, NFR-2/V15). rf-qa gains a single `TB-Add-9` carrying the V1–V16 assertion matrix, the per-mode active-assertion map, and the MODE-MATCH single-producer invariant.

**Scope is EXACTLY two files** (confirmed by the completeness gate): `src/superclaude/skills/task-builder/SKILL.md` and `src/superclaude/agents/rf-qa.md`.
