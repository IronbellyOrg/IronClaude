# Implement the reflect Tier-2 Fallback Model Ladder

## Task Overview

A 2026-07-05 incident showed that a single transient primary Tier-2 reviewer failure collapses a deep reflect run to Tier-1 (degraded / exit 11) even when a heterogeneous quorum could be restored by dispatching one more reviewer against a different model. This task implements the **Tier-2 fallback model ladder** exactly per the reflect-reviewed component design at `.dev/brainstorms/20260706-035624-reflect-t2-fallback-ladder/design.md`. A post-primary-normalize controller (`run_fallback_ladder`) performs **bounded** T1Model01 → T1Model02 quorum top-up, appending successful fallback `WorkerResult`s to `normalized_workers` **before** `build_reflect_contract` runs, so `reviewer_count`, both diversity axes, and `merge_method` recompute over the augmented set and the **unchanged** verdict chain certifies Tier-2 on its own existing rules.

The design's load-bearing property is **additive-only, verdict-gate-preserving**: `contract.py` (the verdict map `derive_verdict`/`_degraded_reason`) is NOT changed, no `_LOAD_BEARING_BOOL_FIELDS` member is added, `swarm/models.py`'s `WorkerStatus`/`WorkerResult` are NOT changed, and `build_reflect_contract` (which lives in `ensemble.py`, not `contract.py`) gains exactly one additive defaulted keyword-only param `t2_fallback: dict | None = None`. When a genuine failure cannot be repaired, the run STAYS degraded/exit 11 via the existing first-match `degraded-tier1` (T6) trigger — the fallback metadata only explains *why it could not help*, it never flips the verdict. Wiring **real** T1-proxy fallback dispatch requires confirming a dedicated T1 proxy contract and is therefore gated behind a `needs_human_decision` HALT; all stub-transport work proceeds unblocked. This is a reliability/correctness change, NOT a security change.

## Key Objectives

The following objectives MUST be achieved by this task:

1. **Pure fallback engine + circular-import fix:** Create `reflect/fallback.py` with the pure helpers (`classify_outcomes`, `evaluate_quorum`, `plan_next_attempt`, `select_contributing_set`, `make_fallback_slot_factory`) and the one impure controller (`run_fallback_ladder`), and break the `ensemble ↔ fallback` import cycle by extracting the diversity helpers into `reflect/_diversity.py`. **Module-boundary invariant:** `fallback.py` imports ONLY from leaf swarm modules (`swarm.dispatch`, `swarm.normalize`, `swarm.models`, `swarm.preflight`, `swarm.transports`, `swarm.transports.openai_compat` for `TransportEnvError`, and `swarm.commands` for `ModelPoolTooSmallError`) and from `reflect._diversity` / `reflect.models` — it MUST NEVER import from `reflect.ensemble` (which is precisely why `run_fallback_ladder`'s `stamp` is a required-no-default param injected by the caller, not defaulted to `ensemble.py`'s `_stamp_worker_paths`).
2. **Additive contract metadata (no verdict change):** Thread `t2_fallback=` through `build_reflect_contract` in `ensemble.py`, emit the §5/§6 metadata schema, and prove via regression test that the verdict chain (first-match `degraded-tier1` per F6) is unchanged.
3. **Controller wiring behind the flag, stub-first:** Add the 3 `ReflectConfig` fields, thread them through `resolve_config` (+`--no-tier2-fallback` flag, stub-OFF default), capture the F4 run deadline, insert the controller at the `ensemble.py:225→226` seam, and prove the §8 incident + counter-case replay network-free.
4. **Swarm T1 slot resolution (F1/F3):** Add the `T1Model0N` slot family to `swarm/config.py`, generalize `read_env` → `read_env_for_pool` in `openai_compat.py` (thin T2 wrapper preserved), parameterize `_resolve_run_transport_factory`, and add the `resolve_t1_fallback_factory` sibling in `ensemble.py` (GAP-2) with slot-NAME-keyed resolution.
5. **needs_human_decision HALT for real dispatch:** Verify (read-only, names only) the dedicated T1 proxy contract before enabling real fallback dispatch; record the binding on confirmation or write a PENDING Open Question and HALT.
6. **Verification & QA:** Per-phase unit/integration tests + lighter phase-gate QA, a final 7-agent standard-intensity aggregate QA gate, full `pytest -k "reflect or swarm"`, scoped ruff, `make verify-sync`, and the CLI-mode POST reflect wrapper gate.
