## Key findings

1. Documented: hooks from settings files, managed policy settings and plugins fire for tool calls made inside subagents, including `PreToolUse` and `PostToolUse` (S1, S4). The hook header claim `require-orca-worktree-agent.sh:5-6` and `research/03-guards.md:22` / `:328` match the documentation. It is documented host behavior, not observed on this host.
