# cliEval P4 — Wire `eval_group` into `cli/main.py` + Makefile target + `.gitignore` + Ship

## Task Overview

Phase 4 of the cliEval release is the smallest and lowest-risk phase. It wires the `eval_group` Click group built in P1-P3 into the top-level `superclaude` CLI (a 2-line change in `src/superclaude/cli/main.py:369-391`), adds a `make eval-real` convenience target, updates `.gitignore` to keep per-eval HOME directories and TTY logs out of git, adds Click CliRunner-based wiring tests, and ships the result as a commit + PR. Estimated ~50 LOC total: 2 lines in `main.py`, ~5 lines in `Makefile`, ~3 lines in `.gitignore`, ~40 lines in `tests/cli/test_eval/test_wiring.py`.

P4 is the user-visible ship gate for the cliEval harness. P1, P2, and P3 build the harness internals; until P4 lands, the `superclaude eval` subcommand is NOT reachable from the top-level `superclaude` command. After P4 merges, `uv run superclaude eval --help` works, `make eval-real` works as a shortcut, and `.dev/eval-runs/<ISO>/<run-id>/evals/<eval-id>/home/` directories can never accidentally get committed.

## Key Objectives

- Add 2 lines to `src/superclaude/cli/main.py` to import `eval_group` and register it in the `main.add_command()` block (alphabetical position).
- Add the `eval-real` target to `Makefile` (with `eval-real` in the `.PHONY` declaration on line 1) modeled on the `verify-sync` target's structure.
- Append 3 ignore patterns to `.gitignore` for `.dev/eval-runs/**/home/`, `.dev/eval-runs/**/stdout.log`, `.dev/eval-runs/**/stderr.log`.
- Create `.dev/eval-runs/.gitkeep` so the artifact directory exists in fresh checkouts.
- Create `tests/cli/test_eval/test_wiring.py` with three Click CliRunner tests covering: `superclaude --help` lists `eval`, `superclaude eval --help` lists all 4 subcommands, `superclaude eval doctor` exits 0.
- Run `make verify-sync` and the full `pytest tests/ -v` suite; confirm no regressions vs. pre-P4 baseline.
- Commit changes on feature branch `feat/cliEval-P4-wire-and-ship`, open PR titled `feat(eval): cliEval P4 — wire eval_group into main.py + Makefile target + .gitignore`.
