# Remediate Six POST-Reflect Audit Findings in the Reflect CLI Wrapper

## Task Overview

An independent `/sc:reflect --mode post` Tier-2 audit of the just-shipped `superclaude reflect run` wrapper (report at `.dev/reflect/post-reflect-cli-wrapper-20260609172031/REPORT.md`) found one HIGH fail-closed hole and five LOW/MEDIUM robustness gaps. The HIGH finding (F0) directly undermines the spec's central thesis — the wrapper must never green a degraded or incomplete audit — because a non-zero child exit (other than the 124 timeout case) with a present success-shaped contract currently reaches PASS (exit 0). The five lower-severity findings harden the verdict map against malformed-truthy booleans (F2), correct a misleading operator-facing reason slug (F5), fix a CRLF write-back false-negative that downgrades a clean PASS to BLOCKED (F1), repair a dry-run argv preview that drifts from what actually runs (F6), and honor the "sidecar always written" requirement on the config/preflight STOP path (F4).

This task applies each wrapper fix as a small, surgical edit to an existing file under `src/superclaude/cli/reflect/`, paired with one regression test per finding. The operator has already resolved F0 toward fail-closed (block any non-zero child exit code before trusting contract fields) — there is NO wrapper spec amendment in scope. F3 (task-builder frontmatter omitting `start_commit` + `executor_model_class`) is NO LONGER deferred: the operator has DECIDED option (a) — have the task-builder persist these keys at the source. F3 is therefore implemented in its own phase, editing a DIFFERENT file from the wrapper fixes: `src/superclaude/skills/task-builder/SKILL.md` (a SYNCED component, so its phase additionally runs `make sync-dev` + `make verify-sync`, which the pure-Python reflect-package phases did not need). All edits land ONLY in `src/superclaude/` (SoT discipline — never `.claude/`); the F3 phase's changes to SKILL.md are strictly additive (halt-arm POST item text byte-identical otherwise, NFR-3 reversibility).

## Key Objectives

The following objectives MUST be achieved by this task:

1. **F0 (HIGH):** Make any non-zero child exit code route to BLOCKED before trusting a present contract, so the 124 timeout case becomes a subset and the present-success-contract-with-crash-exit pass-leak is closed.
2. **F2 (MEDIUM-LOW):** Route a contract to BLOCKED when any present load-bearing boolean field is not an actual Python bool (malformed-but-truthy values must not bypass the `is True`/`is False` triggers).
3. **F5 (LOW):** Return the reason slug `status-failed` (not the misleading `tier-mismatch`) for a `status: failed` contract that has no other trigger; exit code stays 10 (halted).
4. **F1 (MEDIUM):** Normalize CRLF for splice-point location in the write-back and existing-block reader so a CRLF-saved tasklist no longer downgrades a clean PASS to BLOCKED, while preserving FR-6 body-byte intent.
5. **F6 (LOW):** Render the dry-run claude argv preview so it byte-matches the real `build_command()` flag set and order, WITHOUT constructing `ClaudeProcess` (FR-12 dry-run must never construct it).
6. **F4 (LOW):** Write a minimal BLOCKED `wrapper-result.yaml` sidecar on the config/preflight STOP path when an output dir is resolvable; document the unresolvable case as an accepted skip.
7. **F3 (operator-decided option (a)):** Amend the task-builder SKILL (`src/superclaude/skills/task-builder/SKILL.md` — a DIFFERENT, SYNCED file from the wrapper) to persist `executor_model_class:` and `start_commit:` into generated frontmatter and add the `EXECUTOR_CLASS` field to the `POST_REFLECT_GATE` BUILD_REQUEST schema (resolving the dangling `{EXECUTOR_CLASS}` placeholder), plus a Critical Rule note — so the wrapper resolves `--executor-model` and `<BASE>` from frontmatter in the common path and reflect's executor-disjoint guarantee fires.
