# Technical Design Document — sc:reflect Tier-2 Reviewer Ensemble Swarm Re-Wiring (FR-RH2)

## Task Overview

This task produces a **Heavyweight Technical Design Document (TDD)** specifying HOW to re-wire the `sc:reflect` Tier-2 adversarial reviewer ensemble so that a headless `superclaude reflect run` can produce a faithful multi-reviewer adversarial pass. The current headless Tier-2 path is architecturally broken: the single `claude -p` wrapper relies on in-process `Task` fan-out that fails on subagent→agent nesting, and NFR-7 (the no-nesting guard) forbids the only in-process alternative. The result is a guaranteed degrade to Tier 1 with zero adversarial reviewers and a `single-reviewer-fallback` verdict.

The TDD specifies the chosen solution: re-route the Tier-2 reviewer ensemble through the **swarm dispatch library** via an in-process library import (a new `cli/reflect/ensemble.py` that imports and composes `dispatch_wave1` + `_resolve_run_transport_factory` + `reduce_wave3`), fanning reviewers out across external `T2Model0N` proxy workers, with `/sc:adversarial` Mode A as the downstream scorer, a new `reflect-review` swarm lens, a non-mocked `--transport stub` integration proof plus a one-reviewer negative witness, and an explicit NFR-7 reconciliation on the record.

The task follows the RF TDD pipeline: Phase 1 preparation, Phase 2 parallel deep investigation (1 PRD-extraction item + 8 codebase research agents R01-R08 + 1 web research agent WEB-01), Phase 3 completeness verification (research gate), Phase 4 web research confirmation, Phase 5 synthesis (9 template-aligned synth files) + synthesis gate, Phase 6 assembly (rf-assembler → report-validation lens-based QA → source-fidelity gate → qualitative review), and Phase 7 present & complete. The final document is written to `.dev/reflect-hardening/issue-2-headless-ensemble/tdd.md` (user-pinned destination — NOT the default `docs/` path). The single most load-bearing deliverable is the **OI-1 swarm ResultContract → reflect contract field-correspondence table** (built from R02 + R05), which sizes `ensemble.py`'s mapping layer and is the §22 Q1 BLOCKING gate that must resolve before FR-RH2.3 code.
