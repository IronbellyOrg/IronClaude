# FR-RH2 — Re-route the headless sc:reflect Tier-2 reviewer ensemble through the swarm dispatch library

## Task Overview

`superclaude reflect run --depth standard|deep` cannot today form a faithful Tier-2 adversarial reviewer ensemble. It launches ONE `claude -p` child running `/sc:reflect --mode post … --tier 2` (`runner.py:392-428` `_audit_once`) and relies on that single child's own in-process Task fan-out to spawn the reviewers. Subagent→agent nesting is forbidden, so the inner fan-out never forms: the run degrades to `merge_method: single-reviewer-fallback`, `tier_reached: 1`, with zero adversarial reviewers. NFR-7 forbids the only in-process alternative (`Task(`/`subagent_type` inside the reflect package), making the failure architecturally guaranteed, not incidental. The defect is invisible to CI because the runner test harness mocks `ClaudeProcess` (`conftest.py:98-138`) and copies a hand-authored `pass.yaml` whose line 4 literally reads `tier_reached: 2` into `return-contract.yaml` — "Tier 2 works" is a fixture constant validated against itself.

This task re-routes the Tier-2 ensemble through the **swarm dispatch library**, reused **in-process**: a new `cli/reflect/ensemble.py` driver imports and composes `dispatch_wave1` (`swarm/dispatch.py:334`), `_resolve_run_transport_factory` (`swarm/commands.py:612`), and `reduce_wave3` (`swarm/reduce.py:555`) — all plain synchronous `def`s that route through `ParallelExecutor` + `Transport`, never `Task(`/`subprocess`. It fans out N external OpenAI-compatible proxy workers (`T2Model01..NN`), which sidestep the `claude -p` nesting defect and provide genuine model-class diversity. A new `reflect-review` swarm lens (mirroring `lenses/bare_review.py`) supplies per-reviewer reflection briefs. Swarm normalizes + mechanically concats the per-reviewer artifacts; reflect's existing `sc-adversarial-protocol` Mode A scores them (swarm's `merge.py` stays a mechanical concat, never the adversarial verdict). The fix is proven with a NON-MOCKED stub-transport integration test (`--transport stub`, zero network I/O, real `dispatch_wave1`→`reduce_wave3`→`derive_verdict`) plus a one-reviewer negative witness that must FAIL the positive assertions.

What deliberately stays the same: the 4-state verdict map and exit codes (`pass→0, halted→10, degraded→11, blocked→2`), the `return-contract.yaml` shape and `reflect_post:`/`wrapper-result.yaml` write-back, the Tier-1 grounded single-agent pass, and swarm's merge boundary.
