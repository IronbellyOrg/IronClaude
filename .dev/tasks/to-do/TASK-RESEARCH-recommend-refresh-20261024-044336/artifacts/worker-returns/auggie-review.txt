### Current command contract

[CODE-VERIFIED] Required targets are a PR number/URL, `--diff <base>...HEAD`, or `--snapshot <path>`. Unresolvable targets stop. Activation is explicit invocation or a programmatic command call, not conversational “review” keywords. The command delegates to `sc:auggie-review-protocol`. Evidence: `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/commands/auggie-review.md:13-30,63-73`.

[CODE-VERIFIED] Defaults are `--depth standard`, `--focus all`, remediation offer enabled, and PR posting enabled for PR targets. Useful controls include `--no-post-pr`, `--no-remediation-offer`, `--output-dir`, and `--auggie-model`. `--revagent opus|sonnet|haiku|fable` changes only internal reviewer agents; quick/standard depths warn because no internal reviewer runs. It must not be described as changing Auggie's model. Evidence: `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/commands/auggie-review.md:45-57`.

[CODE-VERIFIED] The contract produces a review report, raw findings, and audit information. It does not edit reviewed source. PR mode can write review comments without another confirmation; remediation requires acceptance, and execution remains user-driven. Standard remediation consumes workflow's existing pre-review rather than running it twice. Evidence: `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/skills/sc-auggie-review-protocol/SKILL.md:308-342`.

### Comparison with recommendation surfaces

[CODE-VERIFIED] The guide correctly includes local branch review with mandatory `--no-post-pr`, but only inside the broader “review work and open a pull request” workflow. There is no standalone Auggie PR/diff/snapshot review row in the routing block. Thus a review-only request should not inherit commits, pushes, or PR creation. Compare the command's three targets above with `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/core/HOW-WE-WORK.md:303-325`.

[CODE-VERIFIED] Matching a guide row bypasses both cache paths and semantic ranking. Unmatched requests can use the cache; cold discovery reads candidate source. Therefore guide coverage directly affects whether review-only requests reach live discovery. Checkout source takes precedence over installed duplicates. Evidence: `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/skills/sc-recommend/SKILL.md:39-67,100-135`.

[CODE-VERIFIED] The classifier combines adversarial debate, reflection, and code review under `adversarial-review`. Dispatch validates only the cached row's selected source file, then returns its stored envelope; it does not distinguish PR posting, snapshot scope, or remediation consent. This is a verified conflation risk, not a demonstrated erroneous recommendation. Evidence: `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/cli/recommend/prompts.py:50-67` and `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/cli/recommend/dispatch.py:103-136`.

[CODE-VERIFIED] Surface freshness hashes discovered paths plus guide contents; per-row freshness hashes one candidate file. A protocol/ref-only edit can therefore leave a command-backed row valid when command and guide bytes are unchanged. The remediation handoff is a concrete dependency affected by this gap. Evidence: `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/cli/recommend/cache.py:63-103` and `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/cli/recommend/dispatch.py:116-124`.

[CODE-CONTRADICTED] Deep review currently selects MDTM remediation automatically, regardless of actual remediation complexity. That conflicts with the user's desired policy reserving MDTM for the most complex, long-running workloads. It is existing behavior, not an already-completed policy update. Evidence: `/config/workspace/IronClaude/.dev/worktrees/RecommendUpdate/src/superclaude/skills/sc-auggie-review-protocol/refs/remediation-handoff.md:5-14`.

### Acceptance/regression scenarios

[UNVERIFIED] Proposed regression cases:
