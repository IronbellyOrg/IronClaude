### Current command contract

[CODE-VERIFIED] Required input is `--workflow <skill-name-or-path>`, resolving to a skill directory containing `SKILL.md`. Optional flags are `--name`, `--output`, and `--dry-run`. The name is derived when omitted; the documented output default is the derived CLI module directory. Validation rejects missing, invalid, ambiguous, unwritable, or colliding inputs (**C:23-74**).

[CODE-VERIFIED] The useful deliverable is a workflow decomposition and pipeline specification, followed on a full run by a reviewed release specification and panel report. The protocol explicitly prohibits generating code files directly, executing the pipeline, or modifying original primitives. Its pipeline-spec reference independently confirms that Phase 2 produces specification documents, not runnable code (**P:103-105,150-152,448-458**; **PS:7-13**).

[CODE-VERIFIED] `--dry-run` still produces analysis/specification-stage contracts, but skips release-spec synthesis and panel review. Its return contract reports `status: dry_run`, zero quality scores, and `downstream_ready: false`. It is not synonymous with “no files written” (**C:35**; **P:568-577**).

[CODE-VERIFIED] The protocol requires user review after analysis, approval before synthesis, and final approval before delivery. Resume metadata identifies resumable substeps and preserved artifacts. The slash command exposes no `--resume` option, so recommendation must not invent one (**P:105,152,393,517-565**; **C:23-35**).
