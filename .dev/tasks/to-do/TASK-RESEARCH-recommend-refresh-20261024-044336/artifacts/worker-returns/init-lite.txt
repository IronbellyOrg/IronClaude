### Current command contract

[CODE-VERIFIED] `/sc:init-lite` audits project-local context surfaces: root guidance and MCP configuration, project settings, Markdown commands, skill entry files, and agent Markdown. It estimates weight using `ceil(bytes / 4)`. It is not a runtime measurement of what a session actually loaded, an exact tokenizer, or an automatic context optimizer. The implementation discovers file sizes and renders a manual-advice report. C:14-43; I:65-112,129-174.

[CODE-VERIFIED] `--context-optimized` is mandatory. Optional flags are `--project-root`, `--output`, `--dry-run`, `--scaffold`, and `--force`. The default writes a generated report; only `--dry-run` guarantees no writes. `--scaffold` explicitly opts into two advisory guidance files. Existing context inputs remain protected, including under `--force`. Relative output paths resolve against the selected project root. C:23-35; P:35-66; I:283-358.

[CODE-VERIFIED] The command hands off to `Skill sc:init-lite-protocol`, whose frontmatter uses that exact colon-form name. The filesystem directory is named `sc-init-lite-protocol`; that difference must not be “corrected” by recommendation generation. The protocol prefers the mechanical CLI and tells users not to invoke the protocol directly. No implementation-planning or execution handoff is part of this audit. Repeating the audit overwrites marked reports; there is no progress ledger to resume. C:47-60; P:1-5,18-33,59-73.

### Proposed recommendation changes

[UNVERIFIED] **MUST: Add a specific context-audit route to the existing authoritative guide table.** This is proposed policy, not current behavior. Target G’s Routing table and a short explanatory section. Route requests for project-local context-weight inventory, non-destructive context audit, or advisory context-guidance scaffolding to `/sc:init-lite --context-optimized`. Use supporting-task level `-`, not an implementation level. The report-only default fits the guide’s existing `changes_files: no` definition, but the explanatory note must explicitly distinguish report writes from zero-write dry-run. Basis: G:297; C:23-43.

[UNVERIFIED] **MUST: Preserve flags according to intent.** Preview-only requests receive `/sc:init-lite --context-optimized --dry-run`. Explicit advisory-scaffold requests receive `/sc:init-lite --context-optimized --scaffold`. Ordinary audit requests receive `/sc:init-lite --context-optimized`. Preserve user-provided root and output values; do not invent paths or add `--force` automatically. Basis: C:28-35,62-78.

[UNVERIFIED] **SHOULD: Expand the Other commands description and synchronize the plugin guide.** State that the command inventories local context surfaces, estimates weight, writes a report by default, supports a zero-write preview, and scaffolds only on request. Preserve the absence/install handling for plugin-only environments. No extra keyword routing table or classifier category is needed. Basis: G:276; M:276; R:54-60,135.

[UNVERIFIED] **MUST: Keep this report-only capability outside the workflow-versus-MDTM implementation decision.** An audit spanning many configuration files is still an audit. If the user later authorizes actual context restructuring, that is a separate implementation request; apply the requested workflow-first policy then. Do not append task-builder merely because the audit inspected many files. Basis: C:81-96; P:75-79.

### Acceptance/regression scenarios

[UNVERIFIED] Proposed checks should establish:

1. “Estimate my project’s Claude context weight” selects init-lite with the required flag and describes the report write.
2. “Preview the context audit; write nothing” includes `--dry-run` and excludes unsolicited scaffold/force flags.
3. “Create advisory project guidance too” includes `--scaffold` without promising automatic migration.
4. “Explain this one configuration file” remains a native/explanation request, not a compulsory audit.
5. “Automatically rewrite my CLAUDE.md” is not presented as an init-lite capability.
6. A pre-existing generic research cache row cannot override the new specific matched route.
7. Plugin-only installations lacking init-lite show a missing capability rather than a runnable ghost command.

These expectations follow C:23-43,91-96 and R:58-65,135; they were not executed.
