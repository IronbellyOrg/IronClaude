# Base Selection: reviewer-card variants (sc:adversarial step 3, Mode A, depth standard)

Generated by `../artifacts/score_variants.py` (deterministic quantitative layer, reconciled qualitative layer). Inputs: `variant-N-original.md`, `qual-pass1.json` (forward order V1,V2,V3), `qual-pass2.json` (reverse order V3,V2,V1), `debate/consensus.md`, the three `reviewer-card-N-calibrated.yaml` files.

ADAPT: the scored artifacts are reviewer cards, not roadmaps, so the quantitative metrics are adapted as follows. RC = share of 9 required output-contract elements present (persona header, findings table, severities, Tier-1 table, slice coverage, notes, self-reported C, a file:line in every finding row, a fix or verifier in every finding row). IC = 1 - (citations the blind calibrator found wrong / citations checked), the card-level measure of internally ungrounded claims. SR = concrete tokens (line refs, ids, numbers, code spans) / (concrete + vague words). DC = internal references (R#-F#, T1 F#) that resolve to a defined finding or to T1 F1-F10, over all. SC = H2 sections / max across variants.
