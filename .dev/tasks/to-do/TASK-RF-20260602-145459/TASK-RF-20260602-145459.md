The change closes four concrete gaps: (1) sc:reflect's largest false-PASS path — UC-2 Regression is today self-reported from the task log, not verified (the §10.4 detector reads "`--rerun-tests` if set", an off-by-default opt-in; FR-4 makes verification default-on and feeds real exit codes through an exit-code → deviation-class taxonomy into `verification_regressions_detected` → `regression_present` → the §14.5.2 condition-4 promotion gate); (2) cold-start runs have no calibration baseline (FR-2 adds an opt-in `--onboard` Wave-0 bootstrap, gated on empty memory, never auto-triggering); (3) the Tier-3 remediation handoff starts cold (FR-3 writes a `reflect/handoff-{slug}-{timestamp}` memory blob before the Wave-6 task-builder spawn, falling back to plain `write_memory`); (4) polymorphic family completeness is ungrounded (FR-1 adds backend-probe-gated, `--with-hierarchy`-opt-in transitive supertype/subtype retrieval).
