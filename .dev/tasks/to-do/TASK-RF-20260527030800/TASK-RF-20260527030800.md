# Implement hybrid cosmetic-remediator C12 (H2 parenthetical strip) + C13 (gap-driven H3 repair) for roadmap pipeline

## Task Overview

The roadmap pipeline halts at `cli/pipeline/executor.py:349-352` ("Remediator claimed success but gate still fails -- fall through to the original FAIL path") whenever opus-flavored heading drift in the generated roadmap markdown produces drift sites that the existing C1-C11 cosmetic remediator cannot detect or transform. The validation REPORT at `/config/workspace/TUIBBS-scp/.dev/troubleshoot/validation-opus-mixed-drift-20260527023700/REPORT.md` empirically confirms that on the failing artifact: (a) the classifier returns `is_pure_cosmetic=True`, (b) 22 cosmetic transforms apply successfully, but (c) `_template_sections_present(remediated_content)` STILL returns `False` because three drift sites — H2 parenthetical (`## Timeline Estimates (gate-bound, not date-bound)`), Resource Requirements H3 rename (`### External library lockset`), and a bare `### Infrastructure` short-form — have NO C-class detector at all and survive into the remediated content. This task adds two new C-classes to `src/superclaude/cli/roadmap/cosmetic_remediator.py` to close that gap: **C12 (H2 parenthetical strip with `_REQUIRED_H2_SECTIONS` safety gate)** and **C13 (gap-driven H3 repair under known parent H2s, initial scope `## Resource Requirements and Dependencies`)**. Both transforms MUST be idempotent, MUST honor the fenced-block guard via `_compute_fenced_indices`, MUST emit `CosmeticViolation` dataclass records with `klass="C12"`/`klass="C13"`, MUST surface audit-log strings via `transforms.append(...)`, and MUST integrate into the existing dispatcher in `apply_cosmetic_remediations` with the strict ordering **C1-C4 → C12 → C11 → C13 → C5+C6 → C7 → C8 → C9 → C10** (the analyst's Important carry-forward: C12 MUST precede C11 because C11's parent-H2 detection at `cosmetic_remediator.py:466` cannot strip parentheticals).

The fix also closes the critical integration-test gap surfaced by Researcher 03 §4: no existing test in `tests/roadmap/` invokes `_template_sections_present` on the OUTPUT of `apply_cosmetic_remediations`. The new `TestPostRemediationGatePasses` class supplies that regression guard, asserting that the TUIBBS-shaped artifact passes the gate after remediation.
