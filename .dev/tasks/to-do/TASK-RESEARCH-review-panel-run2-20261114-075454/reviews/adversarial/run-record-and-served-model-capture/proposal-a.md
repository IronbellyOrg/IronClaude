## 1. The position (one paragraph)

The unified panel gets one truthful per-run record that is neither the manifest nor the cross-run telemetry store. Per run, an append-only `<out>/panel/events.jsonl` (schema `review-run-event/1`) holds one row per agent attempt of any role (reviewer, calibrator, debater, judge, validator, helper, orchestrator) and one row per refused or failed core action. It is written only through one CLI call under an exclusive `flock`; cost (tokens, wall time) lives only on these rows, and the served model and usage come from a transcript adapter that reads the harness transcript, never from the orchestrator's own words. The adapter is package CLI code, so a primitive reaches it only as a `superclaude review record ...` command (this answers OQ-21 and keeps INV-F). When the adapter cannot read a value the field is `null` and `identity_source` stays `requested-pinned`; nothing is estimated. The manifest stays the stage state machine and gains a lock and a revision check, and nothing else. `review-telemetry` moves to `/2` as the cross-run export, derived from the events at publish (a non-reviewer kind, type-checked group values, one live outcome per reviewer run and truth basis); `/1` files stay readable. Memory (`deviation-patterns-*`, `last-pass-*`) is written by one script step at publish, keyed by run id, with a study switch that freezes reads. Hash pointers (`lid`, `fp`, sha256) replace document text, so INV-H becomes enforceable instead of a convention.

## 8. The strongest objection and the answer

Objection (the best case for position B, "extend the existing stores"). The harm is unmeasured, the new surface is large, and the existing stores already almost fit. `review-telemetry/1` has a `model.observed` field and a cost group (`telemetry.py:49, 74-80`) and the E3 harness already fills them from a transcript (`harness.py:549, 553-554`); the manifest could take `usage` in the attempt payload with a one-line change (`manifest.py:353`) and `validate` would accept it (`manifest.py:251-252`); the race has shown zero incidents in 29 manifests; the adapter's availability is itself unverified. Adding a per-run file, a CLI, a schema, a `/2` bump and a memory writer is an effort L change for a problem that has produced no recorded failure.

Answer, in four parts.
1. The B route runs into three pinned behaviours, not one line.
