## 1. The position (one paragraph)

<!-- Source: Base (original, modified) — paragraph replaced per Change 1 (A Round 2 section 4 items 1-4, 7-8; B Round 2 section 4.3 items 1-3). Withdrawn from the base paragraph: `review-telemetry/2`, `record add`, `rev`, `ext{}`, the script-written memory step and the study switch -->
The unified panel gets one truthful per-run record that is neither the manifest nor the cross-run telemetry store. Per run, per-agent observation lives in an append-only `<out>/panel/events.jsonl` (schema `review-run-event/1`). It holds one row per sidechain agent of any role (reviewer, calibrator, debater, judge, validator, helper), `orchestrator_snapshot` rows and, for each merge, one `merged` row per reviewer on success or one `refused` row on refusal. Rows are written only by code, through two commands: `superclaude review record ingest` (the transcript adapter) and `superclaude review merge --events PATH` (action rows from the merge step). Cost (tokens, wall time) and the served model come from the transcript adapter, which reads the harness transcript and never the orchestrator's own words. The adapter is package CLI code, so a primitive reaches it only as a `superclaude review record ...` command (this answers OQ-21 and keeps INV-F). When the adapter cannot read a value the field is `null` and `identity_source` stays `requested-pinned`; nothing is estimated. The manifest stays the stage state machine with its five-key attempt entry and its stage records, and gains only a CLI-level lock. The cross-run record stays `review-telemetry/1`: `validate_record` gains a `strict` mode that `append_record` uses, `load` is unchanged, and one producer, `superclaude review record export`, writes the `reviewer_run` records. Memory is not changed in this slot. Document text stays out of event rows and telemetry appends because event rows have closed keys and typed values and `append_record` runs in `strict` mode, so INV-H is strengthened by those two guards only (section 5, section 9). Points the advocates did not settle, and probe findings the debate did not address, are marked OPEN and listed in section 9.
