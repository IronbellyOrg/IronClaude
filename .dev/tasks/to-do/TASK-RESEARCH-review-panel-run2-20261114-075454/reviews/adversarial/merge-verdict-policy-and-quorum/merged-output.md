## 1. The position in one paragraph

<!-- Source: Base (original, modified) - position paragraph replaced per Change #1 (Debate: round2-advocate-A.md Hybrid bullets 1, 9, 12; round2-advocate-B.md Counter-hybrid terms 1, 9) -->
The shared core computes the round outcome as a pure, deterministic function of three recorded things: the ledger rows (is any row blocking and open or regressed), the round's recorded quorum result, and the policy named by the module. It returns PASS, REVISE or ESCALATE. The default policy, for every panel module, is the any-blocking union: a finding that any complete reviewer types as blocking enters the ledger and fails the round, whatever the other reviewers say, and single-reviewer findings are kept, never discarded, and are marked unconfirmed in the offline analysis (section 2.1). (Whether "complete reviewer" matches what `merge_round` does is open: the shipped rule keeps every parsable finding, see INV-006 in 4.3.)

Quorum is a rule about coverage, not about agreement, and it is a merge-time gate, not a derived outcome. In a profile that sets `degrade` (the spec-review default), a round whose complete reviewers fall below the floor is refused before anything is recorded (section 2.1). The refusal adds no decision value to the ledger. "A review that did not happen never certifies PASS" (INV-I) is claimed in every profile that sets `degrade`; reflect keeps its pinned, PASS-eligible 2-of-3 shortfall (`shortfall: visible`).

No calibrator, debate or grader sits in the default path. Calibration enters only as separate data keyed by finding id (section 2.1) and never gates. The reflect module keeps its legacy calibrate-validate-debate chain (`legacy-adversarial`) as the authoritative policy of that module; any later k-of-n or calibrated policy is likewise a named policy, not a fork of the core.

The default rests on fail-closed asymmetry and on the absence of any measurement, not on measured superiority. The only shipped-behaviour change in the spec loop is a refusal of rounds below quorum. Proposal B's `adjudicated`-as-default for panels of 2 or more is recorded as a hypothesis awaiting a measurement (section 5), not adopted.

## 7. Strongest objection and the answer

Objection: "FX-10: a weak model must not decide alone. <!-- Source: Base (original, modified) - first answer bullet edited per Change #13: unit cost corrected, precondition and FX-10 statement added (round2-advocate-A.md R1, R2, Hybrid bullet 8; round2-advocate-B.md bullet 8 evaluation) -->
Answer, without weakening the objection:
- The costs are asymmetric and the repo rule already prices them. A wrong blocker costs, to the cap, then a human decision (S3: at most 2 fix cycles, then escalate with the open blocking findings; never pass open blocking findings, `pragmatic.md:227` as cited in research/12 section 2.1 [UNVERIFIED here]). A missed real blocker is a PASS on a defective document, which INV-I forbids. The union puts the cost on the side the rules treat as cheaper. That holds only while a Reviser-rejected row has an exit other than a human `defer`: today a rejected row stays open to the cap (section 3.1 item 5), and a later reviewer's `prior` note cannot clear a row (`ledger.py:259-272` [DEBATE-VERIFIED: round2-advocate-B.md code log row 7]), so the exit is a slot C-02 dependency. The default prices FX-10 and does not satisfy it: `support`, `disputed` and `confidence` change no outcome (`ledger.py:86-104` [DEBATE-VERIFIED: round2-advocate-A.md R2]).
<!-- Source: Base (original, modified) - confidence wording corrected: the verdict code never reads it, the Reviser reads the rendered value (round2-advocate-A.md R2, code log row 8) -->
- The calibrator is not a validated filter today: no run was scored (research/07 N-1), it lost its class in 6 of 15 runs (E1-F5), and per-finding `confidence` in the ledger is never read by the verdict code (`ledger.py:86-90`, `:93-104`), although the Reviser reads the rendered value (`ledger.py:429-435, 473`). Replacing an unmeasured filter by an unmeasured filter would add calls and a failure mode without evidence that it helps.
<!-- Source: Base (original) -->
- The usual remedy, a k-of-n agreement filter, rests on voters whose errors are correlated (web-01 B3) and discards exactly the single-reviewer findings that gave the recall gain in SWR-Bench (D1). It is also a policy this design hosts, so adopting it later is a data change, not a rewrite.
- Agreement and verification are kept apart. The evidence gate (a code-backed check that each cited line exists; synth-06 CO-22 keeps both gates) stays in the pipeline and drops unfounded citations before the union; that is verification by code, not another vote.
<!-- Source: Base (original, modified) - last answer bullet: "least-unmeasured default" replaced by the claims-discipline wording of Change #1; section reference updated to the new section 5 numbering -->
- This resolution does not claim the union is right. It claims the union is a default that rests on fail-closed asymmetry and on the absence of any measurement, and that its failure shows up as one number (wrong blockers per row, section 5 item 9) against which any other policy can be swapped in by name.
