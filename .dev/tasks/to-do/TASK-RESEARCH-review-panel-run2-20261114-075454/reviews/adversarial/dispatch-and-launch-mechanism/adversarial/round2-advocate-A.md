## Updated assessment

**Resolution: a named hybrid, "dispatch contract now, id-addressed launch gated" (H-gated). It is neither Variant 1 as written nor Variant 2 as written.**

Why not Variant 1 as written: `v1` has the five defects listed in section 0 of the response (no executor for `agent-class`, ceiling widened before the probe, identity evidence from a different flag set, two maps, and a validator that rejects the extra key). Why not Variant 2 as written: its packaged class-word fill cannot be right for the packaged reflect templates (five reachable models against three words, picked per run id, B-S2); its identity capture is a plan whose hook does not exist; and it offers no way to reach a model that no class word can name, which B itself lists as a residual it accepts. The two designs agree on what has to ship first, so the hybrid is mostly Variant 2's contract with Variant 1's measured extension.

### What ships now (no new launcher, no resolver or ceiling change)

- **S1. Dispatch rule (Variant 2).** Every reviewer is launched with the `launch` word from `panel resolve` as the Agent `model` argument; a missing argument, or `launch: null`, is a dispatch error and not a fallback to the agent default. Tests: a test that the launch instruction built from a resolution JSON carries each reviewer's word, and that a null `launch` is an error (B's item 3); plus the collapse replay over the 15 combo logs with the prediction that it flags run A-r3 and no other (B's item 2).
- **S2. No data, validator, resolver or ceiling change.** `gateway.launch` stays `{}`, `_REFLECT_LAUNCH` and the 3-reviewer cap stay, D4 keeps routing gateway to the legacy rotation. Test: the existing `test_review_panel.py` and `test_review_panel_reflect_profile.py` pass unchanged, and every packaged `reflect-*` template resolves byte-identically under `anthropic-only` before and after, including `tiers_sha256` (M-3 with the stricter reading).
- **S3. Recorder (hybrid of Variant 1's outcome row and Variant 2's capture).** One transcript reader that emits `model_requested`, `model_observed`, `identity_source` and the tool names seen, for whichever transcript it is given. First input is the Agent path's sidechain transcript, reached through `SubagentStop` `agent_transcript_path` (B's spike, item 5, which is still unrun). Where its record lives is slot C-08's decision and is not made here.
- **S4. The dynamic read-only test on the Agent path.** The test that `test_reviewer_readonly_tools.py:12` defers ("producer absent") is Variant 1's M-2 run on `reflect-reviewer` through an Agent call: a brief that tells the reviewer to run a shell command and write a file. Pass if the sidechain transcript has no Bash, Edit or Write call and `git status` is unchanged. This gives the first dynamic evidence for INV-G under either position and costs one launch.
- **S5. Class-word maps live in the workspace, not in the packaged file.** A workspace that wants a gateway class-word panel supplies its own tier file through the existing override (`find_path`: `$SUPERCLAUDE_REVIEW_TIERS`, `<project>/.superclaude/review-tiers.json`, `~/.superclaude/review-tiers.json`, `panel.py:397-419`), where the map can match that workspace's `ANTHROPIC_DEFAULT_*_MODEL` binding.

### What is gated, and what gates it

Nothing below is built until its gate passes. The gates are the ones in `v1` section 6, corrected for the flag set (X-008).

- **G1. Identity and reach under the restricted flags.** Launch one fixed brief through `claude -p --restricted --tools Read,Grep,Glob --strict-mcp-config --mcp-config <grounding servers> --model <id>` (flags from the local `claude --help`, version 2.1.325; command shape not yet run) to five gateway ids that no class word reaches. Include grok-4.7 (in the `reflect-pre` tier4 pool), a tier3 id and one non-first-slot id; three attempts each. Pass if every attempt has an observed `message.model`, every mismatch is recorded as a mismatch (zero unrecorded swaps), and at least one id is served that the Agent path cannot request. Fail if the observed field is empty for gateway ids or a failover cannot be told from a mismatch.
- **G2. Read-only under the restricted flags, and the tool surface.** Same launch on a gateway id and on `sonnet`, with a brief that tells the reviewer to run a shell command and write a file. Pass if the transcript has no Bash, Edit or Write call, `git status` is unchanged, and the init event's tool list contains the grounding MCP tools and excludes Bash (this answers B-W8). Fail if the flag set is rejected for gateway ids, or the MCP tools are not callable in non-interactive mode.
- **G3. No regression.** The resolution of every packaged `reflect-*` template under `anthropic-only` is byte-identical before and after the change.
- **G4. Cost (informational, CO-10).** Same brief and model through both paths, wall time and tokens, three runs each. It does not decide the gate.

If G1 to G3 pass, three changes ship together: the launcher (a caller of `ClaudeProcess`, with a visit-once fallback list and an exclusion list, New evidence N7); the fill of `gateway.launch` with `claude-p` for the ids that passed, with `test_gateway_resolution_prints_launch_null` rewritten in the same commit; and the one-value widening of `_REFLECT_LAUNCH`. D4's Stage 3 successor is edited by whoever owns Stage 3. If G2 fails, V1' is withdrawn, the end state is Variant 2's, and the reason is recorded.

### What this design does not decide

Where the launcher module lives (`cli/review` or an engine; residual R2), where the recorder's rows are stored (C-08), who owns the model-to-class-word map (C-09), and whether a bounded re-ask needs a persisted session (C-06; `ClaudeProcess` always passes `--no-session-persistence`, `process.py:152`).

Still stronger: C-002 (reach by model id; the packaged random-slot arithmetic in B-S2 is new evidence for it), C-003 (a model id, unlike a class word, does not depend on how the launching session was set up), the falsifiable gate structure with a stated fallback (U-002, U-003), and the observation that run A-r3's collapse has no mechanical fix on the class-word path.
