### B3. `merge_cmd.py` (118) - `superclaude review merge`
Options: `--ledger` (required, created on round 1), `--doc` (exists), `--round` (IntRange min 1), `--report REVIEWER_ID=PATH` (repeatable, required), `--resolution` (panel resolution JSON, only for `model` per reviewer), `--out` (required), `--cap` (default 3, used only when round 1 creates the ledger; ignored for an existing ledger). Reads reports with `newline=""` (13-18). Writes merged report FIRST (113-115) and saves the ledger AFTER (116): a failure between the two leaves a merged report with no ledger update. Prints JSON of the merge result minus `_` keys (117-118). Exit: 0 on success whatever the verdict; 1 (`ClickException`) on any refusal incl. "no reviewer produced a valid findings block". The verdict is NOT in the exit code of `merge` (only `ledger verdict`).
