# Evolve audit-only `superclaude reflect run` into a validate→review→auto-fix→verify→promote engine

## Task Overview

This task evolves the **shipped audit-only** `superclaude reflect run` wrapper into a wrapper-orchestrated **validate → review → auto-fix → verify → promote** engine, implementing decisions **D1–D7 / FR-1–FR-10** from `.dev/brainstorms/20260610-053000-reflect-wrapper-autofix/merged-requirements.md` and conforming to the cross-team interface contract at `.dev/handoffs/reflect-wrapper-contract.md` §§2–6.

**Why.** `/sc:reflect` spawned as an Agent/Task subagent silently loses Tier-2 heterogeneous-model fan-out; the wrapper launches reflect as a TOP-LEVEL `claude --print` subprocess so Tier-2 fans out. The audit-only v1 only HALTs on deviations. This evolution adds a **bounded, safe-class-gated auto-fix loop** + **promote-by-default** so a clean or mechanically-repairable tasklist completes with zero human intervention, while anything a human must decide still HALTs (honoring `feedback_human_decision_items_must_halt`).

**The new wrapper surface is ONLY:** the fix-loop orchestration, the recursion-breaker marker, `--base`, the promote-default flip, the pure AUTO-FIXABLE/HUMAN-REQUIRED classifier, and consuming a new `remediation_task_path` contract field (skill bump `1.3.0 → 1.4.0`). **Hard thinness boundary (NFR-1):** no reflect-logic duplication — waves, tiers, the 4-category taxonomy, and promotion mechanics stay in `sc-reflect-protocol`. No imports from `cli.sprint`/`cli.roadmap`; zero `async`; the only subprocess-launch path is `ClaudeProcess`.

**CANONICAL BASE (critical).** The work lands on the **AUDIT-ONLY** reflect CLI as it exists in worktree `wrapper-onto-master` (built on current `origin/master`): `src/superclaude/cli/reflect/{commands,config,runner,contract,models}.py` + `src/superclaude/cli/main.py` reflect registration + `tests/cli/reflect/`. The `--reflect <none|0|1|2|auto>` DIAL (this `reflectWrapper` branch's commits `ecadfe47`/`879bb64f`; PR #157 closed) is **ABANDONED** — do NOT build on it, extend it, or reference it. Phase 1 creates a fresh feature branch off `origin/master` mirroring `wrapper-onto-master`.

**BOOTSTRAP EXEMPTION (critical).** This tasklist BUILDS `superclaude reflect run`; it MUST NOT end with a `superclaude reflect run` terminal gate (that command does not exist until this tasklist completes — a "superclaude: no such command" failure). The POST reflect item (penultimate, immediately before the Done status update) is the **inline same-session** `/sc:reflect --mode post` audit (CLI-independent), NOT a `superclaude reflect run` shell-out.

**All R-research file:line anchors below are stated against the canonical (audit-only) base.** The executor MUST re-read each cited file at the resolved line in the freshly-branched checkout before editing (lines may shift; the research was captured against `wrapper-onto-master`).

## Key Objectives

The following objectives MUST be achieved by this task:

1. **Fix-loop + flags (D1/D2/D3/D5/D6):** `commands.py` gains `--fix/--no-fix`, `--max-fix-iterations` (default 2), `--base`; `--promote` default flips False→True; the `SUPERCLAUDE_REFLECT_WRAPPER_ACTIVE=="1"` → exit 0 self-suppress guard sits at the GROUP/eager-callback level (so it pre-empts Click `exists=True` validation of the tasklist arg).
2. **Config precedence (D6):** `config.py` `_resolve_base` honors `--base > frontmatter start_commit > git merge-base HEAD master`; `resolve_config` threads `base_override`, `fix`, `max_fix_iterations` into `ReflectConfig`.
3. **Bounded fix-loop (D1/D3/FR-1/FR-3):** `runner.py` extracts `_audit_once()` and wraps it in a bounded audit→classify→apply→re-verify loop; the apply step runs `/task <remediation_task_path>` as a SECOND top-level `ClaudeProcess` with `env_vars={"SUPERCLAUDE_REFLECT_WRAPPER_ACTIVE":"1"}`; sidecar records `fix_iterations`/`fix_converged`.
4. **Carve-out classifier + field surfacing (D4/FR-8):** `contract.py` gains a pure `classify_fix()` (HUMAN-REQUIRED off `regression_present`/`needs_human_decision`/`user_decision_required`/`unauthorized_deviation_present`/`regression>0`; AUTO-FIXABLE = drift/necessary only) and surfaces `remediation_task_path` onto `ReflectResult` via `_make_result`.
5. **Models (D1/D3/D6/FR-8):** `models.py` adds `ReflectConfig` fields (`base_override`, `fix`, `max_fix_iterations`) and `ReflectResult` fields (`fix_iterations`, `fix_converged`, `remediation_task_path`), all defaulted so the 5 hand-built construction sites stay valid.
6. **Skill contract deltas (FR-8/FR-9):** `src/superclaude/skills/sc-reflect-protocol/` emits `remediation_task_path: <abs>|null` in §9.1, bumps `contract_version 1.3.0 → 1.4.0` at ALL 5 literal sites (incl. the §18 grader assertion), and auto-authors the corrective file headlessly under `--print --remediate` without the interactive yes/no accept; then `make sync-dev`.
7. **Tests (all 9 ACs):** `tests/cli/reflect/` covers marker self-suppression (+negative control), AUTO-FIXABLE-vs-HUMAN-REQUIRED matrix, bounded-loop non-convergence→exit10 with `(N+1)`-audit/`N`-apply call-count assertions, O1 promote vs O2 `--no-promote` prompt assertions, `--base` precedence + de-range invariant, and thinness guards (no `cli.sprint`/`cli.roadmap` import, no `async`/`await`, apply-launch-only-via-`ClaudeProcess`); new fixtures at `1.4.0` with `remediation_task_path`.
8. **Verification (NFR-5 + all ACs):** lint + `ruff format --check` + `uv run pytest tests/cli/reflect/` + `make verify-sync` all pass; `pipx install --force` exposes `superclaude reflect run` with the new flags; conformance verified against contract §§2–6 and merged-requirements §8 (the 9 ACs).
