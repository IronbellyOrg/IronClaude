### B.5 `validate_approvers(path)` (cycle.py:298-361) - the approvers file rules
Return `frozenset[int]` or `ConfigError("approvers_invalid")`:
1. `os.lstat` fails -> "missing or unreadable" (l.306-311). Not a regular file (symlink is refused because lstat does not follow) -> "not a regular file" (l.312-313).
2. Open with `O_RDONLY | O_NOFOLLOW | O_CLOEXEC | O_NONBLOCK` (l.318); the opened inode `(st_dev, st_ino)` must equal the lstat inode -> "changed while it was being checked" (l.327-330); fstat must be regular (l.331-332).
3. Owner must equal `os.geteuid()` (l.333-336); mode must not have `S_IWGRP | S_IWOTH` (group- or other-writable refused) (l.337-340). NOTE: read bits are NOT checked; a world-readable 0644 file passes.
4. Size cap `_APPROVERS_MAX_BYTES = 1024 * 1024` (l.75): reads `cap + 1` bytes; more than 1 MiB -> "too large" (l.341-349). Must decode as UTF-8 (else "cannot be read as UTF-8 text").
5. Line grammar (l.350-358): split on `"\n"`; a line whose `strip()` is empty, or that STARTS with `#` (no leading-whitespace comments), is ignored; every other line must fullmatch `[1-9][0-9]{0,19}` (`_APPROVER_LINE`, l.73): decimal id, no leading zero, 1 to 20 digits, NO surrounding whitespace, NO trailing comment, NO `\r`. Violation -> "holds a line that is not an account id". Note the id range is not capped at 10**20-1 here (20 digits max by regex; max 99999999999999999999 = 10**20 - 1, so equal).
6. No ids -> "holds no account id" (l.359-360).
`approvers_summary(path)` (l.364-368): `(mtime as "%Y-%m-%dT%H:%M:%SZ" UTC, id count)`; calls `validate_approvers` again. Used only by `check-config`.

### C.3 Key Takeaways (C)
- `status` is a pure local read: no lock, no `gh`, no `orca`, never reads `audit.jsonl`. Health = a real, stop-free, exit-0 cycle completed within 900 s. Disabled, not-enabled, locked and dry-run cycles never make it healthy.
