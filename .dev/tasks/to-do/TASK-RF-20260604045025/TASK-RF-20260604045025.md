# Fix CI hermeticity: commit canonical audit fixtures + rewrite brainstorm skill-availability test

## Task Overview

This task applies two independent, small, pre-reproduced fixes that both make a clean-CI checkout pass tests that currently fail due to non-hermetic dependencies on local state. **Bug A (data/gitignore):** six canonical evidence-pack `.log` fixtures under `.dev/releases/complete/task-builder-merge/artifacts/D-00{56,57,59,60}/` are caught by the blanket `*.log` rule in `.gitignore` and were never committed; a clean CI checkout therefore lacks them, so the `CanonicalFixtureParity` audit tests fail (`test_canonical_log_present` asserts the file exists, and the `canonical_log_text` fixture does a bare `read_text` that raises `FileNotFoundError` when missing). The audit tests are CORRECT — only fixture availability differs in CI. The fix is a tightly-scoped `.gitignore` negation that un-ignores exactly these fixtures, followed by committing the six fixtures plus the `.gitignore` change as one atomic commit. **Bug B (broken test):** the brainstorm skill-availability test patches the module attribute but then calls a local import binding of the same name, so the patch is a no-op and the real `$HOME`-coupled function runs (passing or failing depending on whether `~/.claude/skills/sc-brainstorm-protocol` happens to exist). The test is WRONG. The fix rewrites that one test (test-only) into a HOME-redirected pair that exercises the real function against a controlled `tmp_path`. No production code logic changes anywhere in this task.

All file:line claims used by this task were reproduced live during the `/sc:troubleshoot` Tier 1 diagnosis (test runs + `git check-ignore`); every claim in the research is to be treated as CODE-VERIFIED.

## Key Objectives

The following objectives MUST be achieved by this task:

1. **Un-ignore the 6 canonical fixtures (Bug A, part 1):** Append a tightly-scoped negation `!.dev/releases/**/artifacts/**/fixture-*.log` AFTER the blanket `*.log` line in `.gitignore`, and verify via `git check-ignore` that the 6 fixtures become UN-IGNORED while `twine.log` and `.dev/releases/**/results/phase-*-output.txt` STAY ignored (no leak).

3. **Rewrite the brainstorm skill-availability test (Bug B):** Replace the broken, environment-coupled `test_skill_not_available_returns_false` with a HOME-redirected pair (absent → False, present → True) that exercises the real function; leave `test_fallback_activates_with_warning` and the `from unittest.mock import patch` import untouched; modify NO production code.
