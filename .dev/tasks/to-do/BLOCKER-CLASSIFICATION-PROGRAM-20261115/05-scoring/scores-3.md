## Threshold
Threshold: 4
Score 4 is where an implementer would very likely produce a wrong result or hit a gate that cannot pass (unpassable acceptance check, contradictory instructions, missing required part, guard reported wrongly). Those make the next phase stall or ship wrong, so they must be rewritten and re-reviewed.
Score 3 is a real weakness that an implementer can usually work around (weak test, vacuous check, docs wording, single-check bug); it should be recorded and offered as a follow-up issue.
Rows at or above 4: 125 of 318 (11 at 5, 114 at 4). Rows at 3: 153. Rows at 1-2: 40.
Score 5 is reserved for bypass of a safety control (push to main, upstream reach, credential exposure, data loss, approval-gate self-approval) or a plan that cannot run at all.
