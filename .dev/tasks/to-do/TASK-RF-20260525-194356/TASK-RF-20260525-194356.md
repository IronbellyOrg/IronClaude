# Implement superclaude init-lite --context-optimized

## Task Overview

This task implements the context-optimized init-lite feature as a safe, non-destructive workflow. The resulting CLI command must audit only project-local SuperClaude context surfaces, estimate their context weight deterministically, write a generated context audit report by default, optionally scaffold advisory project-guidance files under the target project's `.dev/superclaude/` tree, and never rewrite or mutate existing target-project context inputs.

The feature must preserve IronClaude source-of-truth discipline: all command and skill source changes are made under `src/superclaude/`, dev mirrors are refreshed only through `make sync-dev`, and sync is verified with `make verify-sync`. The implementation must include focused tests for CLI behavior, registration, installer protocol-skill handling, report/scaffold invariants, dry-run no-write behavior, no target-project `.claude/` writes, and required validation commands.

## Key Objectives

The following objectives MUST be achieved by this task:

1. **Add safe CLI support:** Implement `superclaude init-lite --context-optimized` with `--project-root`, `--output`, `--dry-run`, `--scaffold`, and `--force` behavior matching the gate-passed research decisions.
2. **Add command and protocol source:** Create a thin `/sc:init-lite` command source and backing `sc-init-lite-protocol` skill source under `src/superclaude/`, with bulky templates or examples in lazy refs only if needed.
3. **Fix installer mapping when using protocol naming:** Update installer behavior so `sc-<command>-protocol` maps to `commands/<command>.md` and is not installed as a standalone skill when the matching command exists.
4. **Protect target projects:** Ensure no execution mode rewrites existing `CLAUDE.md`, `.mcp.json`, `.claude/settings.json`, `.claude/commands/**`, `.claude/skills/**`, or `.claude/agents/**`, and ensure `--dry-run` writes nothing.
5. **Validate with tests and sync checks:** Add focused tests, run required UV/make validation commands, sync dev mirrors through `make sync-dev`, and verify sync with `make verify-sync` without instructing staging of `.claude/` generated mirrors.
