### 1.1 Rule contract: what `match` returns
- `match(row, ctx)` returns a `Classification` (the rule applies) or `None` (the rule declines; the next rule is tried). Evidence: `classify` loop classify.py:371-375 ("the first rule that returns a value wins", docstring :370).
- If every rule returned None, `classify` calls `_rule_fallback` directly (classify.py:376-377); the fallback always returns `C_UNKNOWN` with rule "fallback" (classify.py:342).
- Rules are pure: module docstring classify.py:3-5 says no file read, no process, no clock; time comes only from `ctx.now` / `ctx.window_start`.
- Rules 1 and 2 are split into a helper that returns `(Classification | None, tuple[str, ...])` (match, decline notes): `_blocked_contract` :161-188, `_exit_proof` :191-. `classify` calls both helpers a second time only to collect their decline notes (classify.py:378: `notes = list(_blocked_contract(row)[1] + _exit_proof(row)[1] + result.notes)`).
