- OPEN, label `bug`, severity high. Eight observations from a six-worker run (run `run_93bfa00cae2b`, 2026-11-07): timer heartbeats with an unchanged "implementing" status while a session was stuck in autocompact thrash about 4 h; a worker idle at its prompt about 4 h; one file's mtime judged "alive" but the worker was idle; a closing report sent as `status` while the wait listened only for `worker_done`, `escalation`, `question` (unread about 4 h); two answers sent by mailbox that workers did not see for 35-40 min; a permission prompt blocking a worker about 20 min with no message; workers stopping between chain steps; a replacement hitting autocompact thrash again, 46 min.
