# Wire the Sprint CLI per-task execution path + runner-owned typed HandoffRecord (Stages 0-3)

## Task Overview

The Sprint CLI per-task execution pipeline is **half-wired**: the runtime fork in `execute_sprint` already branches into `execute_phase_tasks` -> `_run_task_subprocess` when a phase file parses into `### T<PP>.<TT>` task headings (this path is LIVE), but the supporting machinery built for it is **dead in production** — only tests import it. Isolation env injection (`IsolationLayers`/`setup_isolation`) is never applied on the per-task path; the per-task subprocess hard-codes `turns_consumed=0`; prior-task context (`build_task_context`) is fully implemented and unit-tested but never injected into any prompt; there is no `FileHandoffStore`; there is no per-task resume contract; and the JSONL event sink is lock-free (safe only while execution stays sequential).

This task wires that dead path and hardens it for parallel execution, across four stages. **Stage 0** injects per-path isolation env (with the required per-path merge semantics so the per-phase work-dir scoping is preserved) and replaces the hard-coded turn count with a real stream-json parse. **Stage 1** freezes a typed, versioned `HandoffRecord` schema, builds an atomic `FileHandoffStore`, adds a runner-owned `write_task_complete` ledger event (reconciled with the existing `task_rerun_complete`), wires `build_task_context` into the per-task prompt, adds the `--handoff` flag plumbing, and adds a warn-only heading-regex near-miss probe. **Stage 2** adds the per-task resume contract (validated-success skip predicate, phase-qualified on-disk key, `--resume` CLI surface, back-compat degradation). **Stage 3** makes the JSONL writer and `TurnLedger` concurrency-safe, builds a DAG scheduler reusing the existing `walk_dependencies` dependency primitive, adds the `--task-parallelism` flag, and proves the wall-clock win + zero-corruption under concurrency.

Every implementation phase ends in an rf-qa **task-integrity** gate; the final phase runs an rf-qa-qualitative operational review. After each implementation phase, `uv run pytest` for the touched area and `make lint` must be clean. This is CLI source under the sprint CLI module (NOT skills/agents), so `make sync-dev` / `make verify-sync` do NOT apply.

## Key Objectives

The following objectives MUST be achieved by this task:

1. **Stage 0 — Isolation env injection (H1+H2):** Apply per-path isolation env on BOTH live paths — the per-phase fallback branch KEEPS its phase-scoped `CLAUDE_WORK_DIR` and ADDS only `CLAUDE_SETTINGS_DIR`+`CLAUDE_PLUGIN_DIR`; the per-task branch injects the full `setup_isolation` env set — verified by a serial isolation smoke test and a concurrent-spawn corruption-repro test, with the existing `IsolationLayers` API probe kept green.
2. **Stage 0 — Real turn counting (H1 + Reconciliation/T02.06):** Replace the hard-coded `turns_consumed=0` return with a real count parsed from the stream-json output file, with an e2e test asserting the EXACT count (not merely `!= 0`), folding in / superseding the dead `T02.06` wire.
3. **Stage 1 — Typed versioned HandoffRecord + atomic FileHandoffStore (H4+M7):** Build a frozen-v1, `schema_version`-carrying `HandoffRecord` derived from `TaskResult.to_dict()` plus `produced_artifacts[]`+`consumed_upstreams[]`, persisted by a new `FileHandoffStore` using the atomic temp+replace idiom, with round-trip + forward-compat + missing-read tests.
4. **Stage 1 — Runner-owned per-task ledger event (H3) + context injection (M3):** Add a `write_task_complete` event reconciled side-by-side with the existing `task_rerun_complete`, thread the `SprintLogger` + handoff store + prior results through the executor signatures, and wire `build_task_context` into the per-task prompt per the M3 composition table.
5. **Stage 1 — Flag/config plumbing (M4) + heading-router warn probe (M6):** Add the `--handoff` flag + `handoff_enabled`/`handoff_store` config fields through all three layers, and add a warn-only near-miss heading-regex probe that NEVER reroutes.
6. **Stage 2 — Resume contract (H5+M5+L3):** Add the validated-success skip predicate, the phase-qualified on-disk key, the `--resume <task_id>` CLI surface + composition with `--start/--end`, back-compat degradation against a pre-Stage-1 release dir, and a crash-consistency test treating handoff files (not the JSONL) as authoritative.
7. **Stage 3 — Concurrency hardening + DAG scheduler (H6+M2+M4+L4):** Make `_jsonl` and `TurnLedger` concurrency-safe (covering the Stage-0/1 writer), build a DAG scheduler on `walk_dependencies`/`_dependencies_of`, add `--task-parallelism K`, and prove zero corruption over >=1000 concurrent runs plus a wall-clock win at K=4.
8. **Quality gates:** Pass an rf-qa task-integrity gate at every stage boundary and an rf-qa-qualitative operational review at the end; keep `uv run pytest` for touched areas and `make lint` clean after each phase.
