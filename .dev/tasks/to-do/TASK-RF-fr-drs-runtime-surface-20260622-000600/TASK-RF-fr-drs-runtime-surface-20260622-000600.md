# FR-DRS: Deterministic Runtime-Surface Sweep Module + 3 Integration Paths

## Task Overview

This task implements **FR-DRS** — a greenfield, pure-Python, **LLM-free** module `src/superclaude/cli/reflect/runtime_surface.py` that runs a deterministic 7-step runtime-surface sweep (tag → find-referrers → partition → degrade-oracle → rootwalk → reduce → emit) and computes the six `runtime_surface_*` contract scalars **by construction**, always writing `<output>/artifacts/runtime-surface-ledger.yaml` when a surface is tagged. A controlled 3×before/3×after experiment (2026-06-20) proved a prose-only LLM implementation CANNOT deliver the structured-output guarantee: the ledger was written in only 1/9 quiet-path runs and the LLM improvised scalar names even after the prose forbade them. Moving the structured-emission path into deterministic Python is the only fix. The verdict/prose SAFETY behavior already works and MUST NOT be rebuilt — FR-DRS is scoped narrowly to the **structured mirror**.

Beyond the module itself, the task wires it into three integration paths: **(1) PRODUCT path** — invoke `run_sweep` inside `runner._audit_once` between the contract-author join and `parse_contract`, merge-overwrite the six fields and write the ledger via the reflect-local `_IndentDumper`/`_atomic_write_text`, and add the `contract.py` consumer wiring (token-membership add to `_DEGRADED_COMPONENTS_HALT_SET`, a count-invariant fail-closed guard mirroring the `_LOAD_BEARING_BOOL_FIELDS` block, and the `surface_unreached` derivation that the §5.3 pre-filter reads); **(2) EVAL path** — promote/adapt the existing (untracked, on-disk) `scaffold_iteration.py` + `produce_iteration.py` materializer scripts into a tracked `.dev/eval-workspaces/sc-reflect/` home and insert the `run_sweep` oracle call upstream of `grader.py` so the 5 uc2 cases (ids 37-41) grade a deterministic artifact with zero variance across ≥3 runs; **(3) SKILL.md demotion** — demote §6.1 step 4b/4b′ from LLM-emits-scalars to deterministic-sweep-computes WITH a conditional LLM-fallback keyed on `runtime_surface_sweep_ran` presence, preserving the load-bearing safety sentences verbatim, then `make sync-dev` + `make verify-sync` clean.

The module REUSES (copy/adapt, **NEVER import**) `cli/audit` sources: `_bfs_reachable` (with depth=1 enforced at the call site + partial/dynamic → DEGRADE inversions), the `_TEST_PREFIXES`/`_TEST_INFIXES` marker lists (with the unknown→SOURCE default INVERTED to unknown→DEGRADE), the `_DYNAMIC_PATTERNS` regex data (dynamic→KEEP:monitor INVERTED to dynamic→DEGRADE), and the `_safe_parse` fail-soft AST pattern (None→DEGRADE). Determinism (zero LLM in the structured path) is the acceptance bar.
