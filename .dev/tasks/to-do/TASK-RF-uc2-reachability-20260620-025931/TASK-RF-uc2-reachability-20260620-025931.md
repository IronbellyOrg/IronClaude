# sc:reflect UC-2 Runtime-Surface Reachability Escalation (FR-RSR)

## Task Overview

`sc:reflect` UC-2 (post-execution audit) shipped a PASS on an **unreachable feature** (the motivating FR-S9-04 incident): every leaf mechanism existed, every unit test was green, yet nothing was wired into the production entrypoint. The requirement "user can reach `/ai` and invoke Spawn" was graded PASS at Tier 1 while the implementing symbol's only referrers lived in test files and doc-comments. This blind spot spans four mutually-reinforcing structural planes of the protocol: the §5.3 STOP rubric (no row for it), the §6.1 evidence chain (the reachability signal is fetched then discarded), the coverage algorithm (maps mapping, not reachability), and the §10 deviation taxonomy (no class to file it under).

This task implements the **additive, LLM-free, fail-loud** reachability-escalation capability specified by the FR-RSR TDD. It gathers the reachability signal the protocol already fetches-and-discards (a symbol-anchored tagger + a production-caller sweep extending the existing `find_referencing_symbols` call), gates it through the proven table-wide forbid-STOP pre-filter, classifies each UNREACHED finding onto the existing 4-class taxonomy **by evidence** (no 5th class, no new counter), and surfaces it via six additive contract fields + a per-run ledger. The contract bumps `1.5.0 → 1.6.0` (additive minor: no field renamed, removed, retyped, or re-semanticized). The two load-bearing invariants the executor MUST NOT relax: (1) the tagger is **symbol-anchored, not requirement-anchored** (keys off the diff hunk's resolved symbol kind, never a requirement id that may not yet be mapped); (2) the degrade oracle defaults all dynamic / registry / decorator / reflection / packaging-entrypoint wiring to **DEGRADE → §10.6 Grounding Gap, never a blocking Regression** (reachability is semi-decidable; a false `UNREACHED → Regression` triggers a destructive TurnLedger rollback in the sprint consumer).

Scope is exactly the TDD §18.2 file inventory and no more: **one SKILL.md** (six surgical edits), **one new `refs/runtime-surface.md`** (the code-free source of truth), **two existing refs** touched (`reviewer-spec.md`, `deviation-taxonomy.md`), and **eval coverage** (one active headline case + four MAIN companions, ids 37–41). Source of truth is `src/superclaude/` only; after every SKILL.md/refs edit run `make sync-dev && make verify-sync`; UV for any Python (grader) work. The fix is made falsifiable by the headline eval `uc2-unwired-surface-passes`, which MUST FAIL against the pre-change skill snapshot and PASS against the post-change skill.
