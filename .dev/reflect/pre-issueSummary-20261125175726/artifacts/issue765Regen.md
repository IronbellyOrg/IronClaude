The README cross-reference stays in README lines 392-408, because `tests/core/test_orca_session_launch_guidance.py` reads the README from line 409 to the next `## ` heading, pins the paragraph at lines 420-426 right after line 418, and forbids the phrase "coordinator under another orchestrator" in that span.
- B2 (Blocking (Missing)): nothing connected the changed launcher to the launcher the live check observes. `ccsession-orca` runs the `ccsession` next to its own resolved path, `~/.local/bin/ccsession` links to the installed skill copy, `wire_ccsession` creates links and does not copy the launcher, and a plain `superclaude install` skips an existing skill; only `superclaude update`, `install --force`, `update.sh` or the skill's own `install.sh` replace it, and any of those changes every ccsession launch on the host.
